## 调研结论一句话

jixie 的定位已经从境内股票研究工具演进为**个人多市场量化研究实验室**。当前目标是借系统建设学习量化
理论，用可追溯数据和可复现计算研究中国内地、香港、美国的股票、债券与商品。已有 Factor V2、Agent
受控研究工具和策略 Lab 提供了方法基础；当前战略缺口主要是系统学习路径、跨市场数据语义、研究探索的
可复现收口，以及覆盖组合与风险的分析能力。实盘运营证据是长期目标，不是当前阶段的排期中心。

## 当前边界

- **不另造一套 Notebook 产品**：现有 Agent 对话、只读 SQL、沙盒计算和计算图卡片已经具备 notebook-like
  探索能力。下一步优先把对话中的数据、代码、图表和结论冻结成可复现研究记录；只有出现真实交互缺口时，
  才评估单元格、文件式 notebook 或外部 Jupyter 集成。
- **Python 是正式研究语言之一**：Python 策略适配层已经落地，后续更重要的价值是 NumPy、pandas、
  statsmodels 等分析生态。TypeScript Engine 仍是撮合和市场规则的唯一真相，不复制 Python Engine。
- **分钟级 / tick / 日内暂不产品化**：学习地图可以覆盖市场微观结构和高频理论，但当前数据、回测与执行
  产品仍以日频和中低频研究为主，除非新的学习目标和可信数据条件共同触发重新设计。
- **社区/策略广场/跟单/营销**:个人研究定位,全部不做。竞品的社区本质是获客与内容护城河,与本系统无关。
- **学习机构方法，不建设机构组织系统**：可以学习和实现多资产对冲、算法执行、Barra 风险思想等分析方法；
  多账户权限、合规审批、交易台工作流和机构级运维不是个人研究实验室的目标。
- **中英双语帮助持续投入**：公开帮助负责量化入门、操作路径、指标解释和风险边界，并服务英语使用者；新增
  正式研究能力必须考虑对应帮助和双语内容，不能把文档当作功能完成后的可选收尾。

## 当前战略节奏(供讨论,非执行承诺)

每日信号、市场仪表盘、Agent 受控研究工具和 Factor V2 已提供基础，当前不需要用更多页面证明范围完整。

1. 按 `docs/learning-map.md` 建立理论主题、复现练习和系统能力之间的对应关系；
2. 先统一中港美股债商的身份、时区、交易日历、币种、公司行动和 PIT 语义，再扩充研究结论；
3. 把 Agent 的对话式查询分析收口为可追溯、可重跑、可比较的研究记录，而不是平行重做 Notebook；
4. 深化统计推断、组合构造、绩效归因和风险分析，防止只会生成因子而不会判断证据质量；
5. 保留现有信号和账户链路，但在学习与候选策略成熟前，不把券商接入和自动化执行设为近期主线；
6. 宏观真实 vintage 随日常同步自然积累，不能用新增工程伪造历史 PIT。
