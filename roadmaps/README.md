最初调研认为 jixie 的长板是单策略/单因子的研究可信度，缺口在多策略组合、市场状态、实盘闭环和研究
自动化。到 2026-08-11，每日信号、市场状态、Agent 受控研究工具以及 Factor V2 Phase 0–5 已落地；
当前剩余战略缺口主要是**多策略组合与长期实盘运营证据**，以及按真实需求扩展券商执行和新品种交易。

## 明确不追的方向(调研后再次确认,与既有拍板一致)

- **Python 研究生态**:聚宽/米筐/Qlib 的核心引力是 Python + notebook。jixie 已拍板 code-first TS + agent
  对话式研究,这是差异化而非落后;Python 只保留 3.7 ML sidecar 的口子。
- **分钟级 / tick / 日内**:2026-07-06 已拍定永不做,调研不改变这个判断(T+1 制度性封死、个人零胜算)。
- **社区/策略广场/跟单/营销**:个人研究定位,全部不做。竞品的社区本质是获客与内容护城河,与本系统无关。
- **机构功能**:衍生品多资产对冲、算法执行(TWAP/VWAP)、Barra 全套风险归因、多账户合规——维持不做。
  已完成的 ETF 多资产配置和轻量市场/宏观风险解释服务个人研究，不改变这条边界。

## 当前战略节奏(供讨论,非执行承诺)

每日信号、市场仪表盘、Agent 受控研究工具和 ETF 多资产 Factor 已由后续主线吸收并完成，不再列作未来项。

1. 先让已部署策略和生产维护持续运行，积累回测—信号—人工执行的长期对账证据；
2. 多策略组合层仍是最明确的产品结构缺口，进入执行前须在根 `ROADMAP.md` 收敛范围；
3. 水下/滚动绩效、备源、券商适配和新交易品种继续由真实策略需求拉动；
4. 宏观真实 vintage 随日常同步自然积累，不能用新增工程伪造历史 PIT。
