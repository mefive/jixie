## 调研结论一句话

jixie 在「**单策略/单因子的研究可信度**」上已经超过多数竞品(PIT 财务、幸存者防护、研究卡/holdout/诚实计数、
费后视角、isolated-vm 沙箱——这些连聚宽/米筐都没有做全);真正的战略缺口集中在**研究对象之上的一层**:
多策略组合、市场状态感知、实盘闭环、以及把已有 agent 升级为研究自动化。一句话:**单件研究工具是长板,
「作为一个投资系统运转起来」是短板。**

## 明确不追的方向(调研后再次确认,与既有拍板一致)

- **Python 研究生态**:聚宽/米筐/Qlib 的核心引力是 Python + notebook。jixie 已拍板 code-first TS + agent
  对话式研究,这是差异化而非落后;Python 只保留 3.7 ML sidecar 的口子。
- **分钟级 / tick / 日内**:2026-07-06 已拍定永不做,调研不改变这个判断(T+1 制度性封死、个人零胜算)。
- **社区/策略广场/跟单/营销**:个人研究定位,全部不做。竞品的社区本质是获客与内容护城河,与本系统无关。
- **机构功能**:多资产对冲、算法执行(TWAP/VWAP)、Barra 全套风险归因、多账户合规——维持不做
  (08 号文档里的「轻量风格暴露」是给个人的简版,不是 Barra,边界在该文档内讲清)。

## 建议的战略节奏(供讨论,非执行承诺)

1. **先把主线五(每日信号)跑通**——这是 ROADMAP 已有共识,也是所有战略方向里唯一让系统「活起来」的;
   02(组合层)的最小件(多策略信号合流)应当在设计主线五时一并想清楚,避免返工。
2. **03(市场仪表盘)紧随其后**——它直接服务目标策略(广度择时),且大部分是 SDK 原语 + 一页仪表盘,
   工程量与 7.x 一个卡片相当。
3. **06(AI 自动化)择机启动**——`runFactorAnalysis`/`runQuickBacktest` 已在 ROADMAP 远期列出;
   竞品都在补 AI 能力,jixie 的护城河是「agent + 研究纪律台账」的组合,窗口期内做出来价值最大。
4. 04/05/08 按需求拉动穿插;07 等用户拍板。
