# 05 · 多市场数据战略：语义、来源、版本与质量

> 2026-07-25 初版聚焦境内单源风险；2026-08-12 随目标更新。本文是战略展开，不直接认领任务；
> 当前执行项见根 `ROADMAP.md` 3.1–3.4。原 A 股数据盘点保留在 `docs/design/data-expansion.md`。

## 问题陈述

jixie 的目标已经从境内股票研究扩展到中国内地、香港、美国的股票、债券与商品。最大的风险不再只是“缺一张
表”，而是把不同市场的数据误当成同一种东西：相同代码可能属于不同交易所，同一日期处在不同收盘时点，
本币收益与人民币/美元收益不同，公司行动、财务公告、宏观修订和期货换月也有各自的可得时间。

数据战略的目标不是囤最多数据，而是让每个研究者都能回答：

- 这是什么资产、在哪个市场、用什么币种报价；
- 这个值的单位、频率和经济含义是什么；
- 在研究时点它是否已经可得，后来是否被修订；
- 历史样本是否包含退市、停牌、代码变化和公司行动；
- 从本币转换到基准币时用了哪一天、哪个来源的汇率；
- 相同代码与 spec 重跑发生变化时，究竟是代码、参数还是数据改变了。

## 一、共同数据契约

### 证券与资产身份

统一身份至少显式记录：稳定内部 ID、资产类别、交易所/市场、当地代码、上市/退市日期、交易币种、报价币种
和代码承继。展示代码不是主键，证券、上市地、可交易工具和经济实体不能混为一谈。

跨市场股票还要处理双重上市、ADR、不同股份类别和行业分类版本；债券需要发行人、币种、票息、到期日和
现金流；期货需要合约、乘数、到期、主力映射和连续序列构造。

### 时间与可得性

- 每个交易所有独立日历、时区、夏令时和交易日归属；
- 全球数据必须区分观测日期、源发布时间和系统可用日期；
- 跨市场回测不能在中国收盘时使用尚未形成的美国同日收盘数据；
- 财务与宏观数据保存公告/发布时间和 vintage，修订值不能冒充历史当时值；
- 缺失不等于零，也不能默认前向填充所有 flow/event 字段。

### 币种与收益

至少同时支持：

- 资产本币收益；
- 统一基准币收益；
- 单独的 FX 贡献；
- 对冲与未对冲口径的明确区别。

汇率的来源、报价方向、日期对齐和缺失规则必须冻结进研究 spec。跨市场相对表现不说明币种时，结论视为不完整。

### 公司行动与总收益

股票/ETF 必须区分未复权成交价、研究复权序列和含现金分红的 total return；拆并股、分红、配股和特殊分派
要有可审计事件。债券和期货不能套用股票复权概念，分别按现金流和换月规则构造收益。

## 二、数据源决策矩阵

不在战略文档里永久锁定供应商。每个候选源按当时事实评估：

| 维度 | 必查问题 |
|---|---|
| 覆盖 | 市场、资产、字段、历史起点和退市证券是否完整？ |
| PIT | 是否提供公告时间、vintage、历史成分和公司行动？ |
| 质量 | 单位、时区、复权、异常修订和缺失规则是否可解释？ |
| 许可 | 是否允许本地存储、衍生分析、多人使用和公开展示？ |
| 稳定性 | 限频、分页、重试、服务承诺和历史回补怎样？ |
| 成本 | 订阅、积分、调用和长期保有成本是什么？ |
| 可审计 | 能否用官方或第二来源抽样核对？ |

选择顺序是官方/权威语义优先、PIT 和退市覆盖优先、可本地落库优先，然后才比较字段数量和价格。

## 三、分阶段覆盖

### 第一阶段：基准与可交易代理

先用指数、收益率曲线和流动 ETF / 期货代理覆盖中港美股票、主要债券久期和商品类别。这一层能以较小数据面
学习跨市场相关性、趋势、Carry、资产配置、宏观敏感度、汇率影响和组合风险。

### 第二阶段：香港与美国个股

个股研究必须同时建设证券主数据、退市覆盖、公司行动、历史 Universe、财务公告时间和行业分类。先选择一个
边界清楚的 Universe 做金标准，再扩全市场；不能从“今天仍上市的成分”倒推历史。

### 第三阶段：固收与商品专业数据

按学习问题增加曲线节点、信用利差、通胀、现金流、期限结构、库存/仓单、持仓、连续收益和季节性。每个字段
都保留原始单位和转换过程，不建设一个丢失领域语义的万能宽表。

## 四、版本与可复现

### data revision

正式报告和研究记录需要冻结足以解释结果变化的数据摘要。务实方案可以从表/数据集级同步水位、行数、源版本、
修订批次和摘要 hash 开始，不追求昂贵的逐行血缘。

重跑时至少区分：

- 代码或参数改变；
- 数据覆盖自然延长；
- 上游修订了历史；
- 数据清洗或单位转换改变；
- 运行时/依赖版本改变。

### 本地资产化与备份

抓取成功的原始和规范化数据尽量落库、同步幂等可续传。不可重建的研究史与上游受限数据必须异地备份；本机
单份数据库不构成备份。

## 五、质量审计

每个数据域进入正式研究前至少有：

- 日期覆盖、重复、断档和异常缩量检查；
- 主键、单位、范围和空值率检查；
- 公司行动、退市/状态、财务公告日和宏观 vintage 的 PIT 不变量；
- 跨市场时区、日历和 FX 对齐 fixture；
- 与官方或第二来源的抽样对账；
- 数据更改对既有报告的影响提示。

轻量审计随增量同步运行，全量审计定期运行并留痕。新表若进入 Agent 只读 SQL，必须同步字段、单位和 PIT
说明；用户私有数据永远不进入公共市场数据白名单。

## 当前不做

- 为“覆盖齐全”无研究问题地批量导入所有字段；
- 自动合并多个来源并静默决定哪个是真相；
- 用今天的成分、状态、财务修订或合约映射回填历史；
- 在没有许可结论前公开或再分发供应商数据；
- 因为学习高频理论就立即建设分钟/tick/L2 生产数据链路。
