## 一、竞品分类地图

### A. 国内在线量化平台(Python 云端一体)

| 产品 | 定位 | 核心能力 | 对 jixie 的启示 |
|---|---|---|---|
| **聚宽 JoinQuant** | 个人量化第一入口 | Python IDE + 全套数据 + 日/分钟回测 + **模拟盘** + 实盘(部分券商) | 「回测→模拟→实盘」三级火箭是标准动线;jixie 缺中间的模拟盘层(见 04) |
| **米筐 RiceQuant** | 同上,机构化更重 | 同上 + RQFactor/RQOptimizer(因子与组合优化商业模块) | 因子→组合优化的付费墙,恰是 jixie 3.3/02 可以免费自研的部分 |
| **BigQuant** | AI 量化 | 可视化流水线 + AutoML 选股 + 因子库 | AI 卖点大于实效;jixie 的 agent + 纪律台账路线更诚实(见 06) |
| **优矿 Uqer**(通联) | 数据商附属平台 | 数据深(通联)、研究环境 | 数据深度是它唯一优势 → 映射到 jixie 的 05 数据战略 |
| **掘金 MyQuant** | 本地化 SDK + 终端 | 本地 Python/C++ SDK、仿真、实盘通道 | 「本地跑、云取数」形态与 jixie 天然接近;其仿真撮合值得参考 |

**共性启示**:这些平台的完整动线是「研究 → 回测 → **模拟盘** → 实盘/信号」。jixie 研究和回测两环已强于它们
(它们普遍无 PIT 纪律、无 holdout 台账、成本模型粗糙),但后两环是空白,这正是主线五 + 04 号文档的战略位置。

### B. 个人投资者友好工具(最接近 jixie 定位)

| 产品 | 定位 | 核心能力 | 对 jixie 的启示 |
|---|---|---|---|
| **果仁网** | 无代码选股回测 | 条件选股 + **打分排名组合回测** + **策略组合(多策略配仓)** + 调仓提醒 + 实盘跟踪 | **最值得对标的对象**。它证明了个人用户的终态需求:不是「跑一个回测」,而是「维护一组策略、按提醒调仓」。其「策略组合」= jixie 02 的原型;「调仓提醒」= 主线五 |
| **理杏仁** | 基本面数据工具 | 全市场/个股 **PE/PB 估值百分位**、股债性价比、行业估值、盈利质量时序 | 估值温度计是个人投资者黏性最高的功能之一 → jixie 03 号文档;数据已基本在库(daily_basic + fina) |
| **集思录** | 低风险品种数据 | 可转债/ETF/封基折溢价、轮动数据 | 品种扩展的需求风向标(见 07);其用户画像与 jixie 目标用户高度重合 |
| **TradingView** | 图表 + 警报 | Pine Script、条件警报、全球市场 | Pine 证明「轻量 DSL + 图表」可行,但 jixie 已选 code-first TS,不回头;**条件警报**(价格/指标触发推送)是信号线的自然延伸 |

**共性启示**:个人工具的胜负手是「**持续运转的轻量闭环**」——每天打开有新东西看(温度计/信号/持仓状态),
而不是研究功能的堆砌。jixie 目前打开是「工作台」,缺一个「今天的系统状态」首页(03/04 会多次回到这点)。

## 二、差距总表(按「个人研究系统」口径)

## 三、一个反直觉的调研结论

把竞品按「研究深度」和「运转闭环」两轴摆开:开源框架深而不闭环,在线平台闭环而不深,
**果仁网以最浅的研究深度占住了最完整的个人闭环**——这说明对个人用户,闭环价值 > 研究深度。
jixie 已经在深度象限做到了个人系统的天花板,战略重心应当整体右移:
**接下来每一分工程投入,「让系统运转起来」(信号/组合/仪表盘/对齐)的边际价值都高于「把研究做得更深」。**
这与 ROADMAP「使用原则 1:主径优先于路线图顺序」完全一致,调研只是给了它外部证据。
