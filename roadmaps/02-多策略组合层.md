# 02 · 多策略与组合构造研究

> 2026-07-25 初版讨论真实账户上的多策略运行；2026-08-12 随项目目标更新。当前先研究组合理论和候选
> 策略之间的关系，实盘共享账户、信号仲裁和子账户调度延后。执行状态以根 `ROADMAP.md` 4.4 为准。

## 为什么仍然重要

单个因子、策略或资产即使有稳定证据，也不直接等于一个可承受的投资组合。长期 Sharpe / Calmar 更可能来自
多种低相关收益来源、合理风险预算和对回撤的控制，而不是把一个策略的参数继续调到更漂亮。

组合研究要回答：

1. 候选之间是真分散，还是共享同一市场、风格、期限或流动性风险；
2. 权重变化带来的收益是否足以覆盖估计误差、换手和成本；
3. 组合改善来自稳定结构，还是某段历史中的相关性巧合；
4. 当相关性在危机中上升时，组合还能承受多深、多久的回撤；
5. 更复杂的方法是否真正优于等权和简单风险分配。

## 研究对象

组合输入可以是：

- 冻结因子报告形成的研究收益序列；
- 独立策略的逐日净值或目标仓位；
- 股票、债券、商品及现金等资产收益；
- 不同地区、币种、风格或宏观状态下的风险来源。

输入必须带来源版本、币种、成本口径、时间范围和可投资性说明。不能把样本内挑出的多条曲线当成彼此独立的
“资产”，也不能混用费前与费后、本币与基准币收益。

## 研究阶段

### 阶段一：离线组合诊断

先不改交易引擎，使用冻结收益序列比较：

- 等权、固定权重、波动率倒数；
- 风险预算 / 风险平价；
- 带约束的均值方差；
- 不同协方差窗口、收缩方法和再平衡频率。

每种方法至少展示收益贡献、风险贡献、相关性、集中度、换手、成本、回撤和压力情景。等权始终保留为基线，
复杂优化器不能只报告最优结果。

### 阶段二：滚动与样本外组合

- 权重只能使用当时已经可得的收益和风险估计；
- 用 walk-forward 比较估计窗口、再平衡频率和约束；
- 单独展示危机期相关性、资产缺失和新资产上市后的处理；
- 衡量权重稳定性，防止优化器把估计噪声变成极端仓位。

### 阶段三：组合回测与执行（延后）

只有离线研究反复需要统一撮合时，才设计多策略组合回测。届时必须区分：

- 独立虚拟资金与共享真实现金；
- 子策略分别计成本与合并净订单后的真实成本；
- 同标的冲突、T+1、保证金、币种现金和跨市场日历；
- 研究权重、目标权重、订单和成交四个层次。

每日信号的跨策略资金仲裁属于实盘阶段，不是当前组合学习的前置。

## 完成证据

第一批应选择少量已冻结、经济逻辑不同的候选，用同一数据截止日完成：

- 简单基线与至少两种风险分配方法；
- 样本内 / 样本外和滚动权重；
- 费前 / 费后、本币 / 基准币结果；
- 回撤、恢复期、Sharpe / Calmar 及其稳定性；
- 风险贡献、压力情景和“没有改善”的诚实结论。

## 不做什么

- 不把历史最优权重包装成推荐配置；
- 不按单一 Sharpe 或 Calmar 自动挑组合；
- 不因学习机构方法就建设审批、合规、多账户和交易台工作流；
- 不预先限定只能做多或禁止研究对冲，但实际可交易性必须与理论研究分开说明。
