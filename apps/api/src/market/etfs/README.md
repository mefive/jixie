# ETF 数据

`sync-partition.ts` 只同步上市（L）和退市（D）基础目录，在映射和校验前跳过待上市（P）；价格与复权只下载 [管理员名单](../downloads/README.md) 中的代码。上市／退市日期约束请求窗口。字段省略不清除已知信息，未知空响应不删除历史。

历史份额／规模／净值同步、SDK、研究清单与专用审计已退役。`EtfLatestSize` 只保存最新同日规模快照，供初始化或显式重选；不参与历史研究。旧 `sync.ts`、`recovery.ts` 及 registry 审计已删除；`sync-partition.ts` 仅保留价格与复权低层映射，正式写入口统一走 Maintenance。

[write.ts](write.ts) 显式合并目录、行情和复权；只在已验证完整范围内删除缺席记录，未知空连续序列不删除。

成功且完整的来源响应可以没有某些交易日的行情或复权记录。这些日期以“来源无记录”注记保存，完成来源检查但不推断停牌，不生成价格，也不据此删除已有合法值。已确认的份额折算停牌同样可以没有日线；例如嘉实 159919.SZ 在 2012-11-30 的折算停牌及 12-03 复牌见[基金公告](https://pdf.dfcfw.com/pdf/H2_AN201211280005620515_1.pdf)。失败、截断、非法 OHLC 和未经核验的日历仍阻止完成。消费者只读取真实行，核验水位与最大观察日分开。

维护协调与覆盖见 [Maintenance](../../maintenance/README.md)。

退市代码留在已保存名单中，只补退市日及以前的价格／复权；退市日缺失、非法或早于回补起点时跳过该代码并报告缺口，其他代码继续。`download-range.ts` 为名单查询、同步窗口和缺口摘要提供同一边界。人工通过 `pnpm data clean` 预览无依赖的旧 P 记录，`--apply` 备份后执行清理；已有行情、复权、规模、历史标记、同步状态／分区、名单引用或上市日期的记录保留并报告。
