# ETF 数据

`sync-partition.ts` 下载上市（L）和退市（D）基础目录，先过滤待上市及上市日晚于本轮目标的记录，再解释交易属性。范围外资料缺少基金分类不构成本轮错误；范围内无法解释的字段仍保存未接纳诊断，不猜测 T+0 属性。

价格与复权只下载 [累计名单](../downloads/README.md) 中的代码，从上市日开始，退市者采至明确的生命周期边界。上市日晚于目标日时直接跳过，不报错。来源返回的已知范围外日期在数值校验前过滤；非法日期或错误身份仍记录问题。

[write.ts](write.ts) 显式合并目录、行情和复权，来源完整无记录不补价格、不推断停牌，也不擦除已存在的合法历史。退市日缺失、非法或早于上市日时，不猜日期，保留受阻原因。

采集、事务与恢复见 [Ingestion](../../ingestion/README.md)。历史份额／规模／净值研究接口已退役；每日规模仅用于历史 Top N 选取，不额外持久化规模历史。
