# 下载名单

ETF 目录同步上市和退市资料，跳过待上市记录；下载名单只保存代码。`MarketDownloadList` 每类一行，空数组也表示已初始化；`EtfLatestSize` 每只 ETF 最多一条，只保留最近一次完整同日快照。没有代理分类、首选备选或研究准入。

| 服务器命令 | 行为 |
| --- | --- |
| `pnpm data etf list` | 保存名单、生命周期、下载阻塞原因、规模日期和实际价格覆盖 |
| `pnpm data etf select-top --limit 100` | 上市／退市目录与最新规模读取成功后，只从上市产品原子重选 |
| `pnpm data etf add 510300.SH` | 加入本地已验证的上市 ETF；重复添加幂等 |
| `pnpm data etf remove 510300.SH` | 停止后续下载，保留价格历史 |
| `pnpm data index list` | 查看指数名单与价格覆盖 |
| `pnpm data index add 000300.SH` | 添加境内指数代码；未知名称只展示代码，不猜名称 |
| `pnpm data index remove 000300.SH` | 停止后续下载，保留历史 |
| `pnpm data sync` | 首次初始化，随后沿用名单回补与增量 |

首次 ETF 初始化默认前 100；此后仅显式 select-top 重选。管理员添加或清空的名单不会被日常刷新覆盖。缺失或不大于零的规模单独返回且不参与排名，不补零、不用份额推算；有效规模不足请求数量则拒绝重选并保留原名单。所有下载和校验在提交前完成，失败保留原目录、快照与名单。修改与同步共用维护锁，数据库提交持短发布锁。移出后连旧 pending 分区也不再请求；重新加入可以沿用既有覆盖继续回补，历史窗口从实际上市日期开始。

来源 [ETF 基础目录](https://tushare.pro/document/2?doc_id=385)、[ETF 规模](https://tushare.pro/document/2?doc_id=408)。查询最近十四个自然日内已经过去的 SSE 开市日期，使用最近非空、分页完成、身份唯一且日期一致的快照；源数据分批发布，缺失产品和 null 规模明确报告，不把分页终止等同于所有产品均有规模。当前排名不是历史各时点的规模前 100。

指数首次默认沪深300、中证500、中证1000、沪深300全收益及中证全指；最后一项供现有 marketClose 因子使用。官方估值只请求来源明确支持的代码；其他指数估值缺口在 CLI 单独显示，成分不支持或未发布时报告缺口。保留已有指数元数据，但不再下载完整指数目录；新加代码的未知来源字段为空，不伪造来源。

没有后台管理页面或新管理员角色。修改配置不影响已保存文档、策略或发布因子；旧份额代码直接报错。开发与生产迁移执行另行确认。

退市不会自动移出保存名单；该代码只补到退市日，缺少有效退市日时暂缓下载并在 list 与 sync 缺口中报告原因，其他 ETF 继续。历史行情与复权保留，退市产品不参加新的规模排名。
