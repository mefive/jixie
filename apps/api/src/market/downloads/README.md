# 下载名单

`IngestionSelection` 按品种保存累计代码，不保存规模历史或投资候选池。股票采集全部有效标的；指数沿用固定默认名单及管理员增删；ETF 用历史规模 Top N 累计扩大范围，默认 N=100。

`ingest(D)` 对自然起点至最终目标 D 的每个已结束交易日 t，获取 t 当日完整规模快照，在当时已上市且未退市的 ETF 中按 `total_size` 降序、代码升序取最多 N 只，与已有名单取并集。今天已退市的基金也能参加退市前的历史排名；不足 N、规模为空或完整无记录时不补零、不用份额替代规模、不回退到今天。各交易所仅采用自己的已知开市日期。

每个历史交易日是独立可恢复批次，名单并集与成功收据在同一事务提交。分页失败或排名快照身份／数值不合法时不更新名单，重跑只补未完成日期。累计数量可以超过 N；退出排名不移除，重复执行不增加重复代码。规模仅用于选取，不另建持久表。

名单确定后，从每个标的自然起点补齐合法历史。上市日晚于本轮截止日的标的正常跳过；已退市者保留并只采至已有生命周期边界。累计名单不是历史时点的投资候选池。

| 服务器命令 | 行为 |
| --- | --- |
| `pnpm data ingest --to YYYYMMDD` | 累计各历史交易日 Top 100，再补齐名单内的有效历史 |
| `pnpm data etf list` | 查看累计名单、生命周期和实际价格覆盖 |
| `pnpm data etf select-top --limit 100` | 额外选取最近已发布快照的 Top N，并入已有名单 |
| `pnpm data etf add 510300.SH` | 加入本地已验证的上市 ETF；重复添加幂等 |
| `pnpm data etf remove 510300.SH` | 从当前累计名单移除，保留已入库历史 |
| `pnpm data index list` | 查看指数名单与价格覆盖 |
| `pnpm data index add 000300.SH` | 添加境内指数代码；未知名称只展示代码，不猜名称 |
| `pnpm data index remove 000300.SH` | 停止后续下载，保留历史 |

ETF 的空名单不会关闭自动历史选取；手动移除也不构成永久排除，后续尚未处理的交易日仍可能重新选入。已完成历史日期不会仅因手动移除而重选。指数仍只初始化缺失配置，不覆盖已保存的空名单或人工修改。

显式 `select-top` 查询最近十四个自然日内已经过去的 SSE 开市日期，使用最近非空、完整分页的同日快照；它只额外加入当期候选，不替代 ingest 的逐日历史选取。所有名单修改与同步共用维护锁，提交持短发布锁。来源缺失或不大于零的规模不参与排名；不要求早期市场必须有 N 只产品。

指数首次默认沪深300、中证500、中证1000、沪深300全收益及中证全指。官方估值只请求来源明确支持的代码；不下载完整指数目录，不伪造未知字段。
