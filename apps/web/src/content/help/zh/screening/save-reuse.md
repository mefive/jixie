# 保存并再次运行筛选

保存筛选适合需要定期重复检查的条件，例如“低市盈率、高股息率、按总市值排序”。

保存的是筛选规则，不是当时的结果快照。以后重新打开时，页面会使用当前可用数据再次运行，因此命中股票、价格和快照日期都可能变化。

## 保存当前筛选

![筛选名称、保存按钮和已保存筛选列表](/help/zh/screening/save-reuse-01.png)

1. 先完成筛选，并核对条件、排序和结果。
2. 在下图 **1** 的输入框中填写名称。名称应能说明用途，例如“低估值高股息（价格限制）”。
3. 点击下图 **2** 的“保存筛选”。
4. 等待左侧“已保存筛选”出现新记录。下图 **3** 是该区域。

如果使用相同名称保存不同规则，左侧可能出现难以区分的记录。建议在名称中写出主要差异。

## 再次运行

1. 打开“选股看图”。
2. 在左侧“已保存筛选”中点击名称。
3. 等待条件、快照说明和结果表出现。
4. 核对快照日期和命中数量。

重新打开时使用的是最新可用数据，不会还原保存当天的价格和结果顺序。

## 修改后另存

打开已保存筛选后，可以修改条件或排序。修改不会自动覆盖左侧原记录。

需要保留修改后的版本时：

1. 修改条件并等待查询完成。
2. 输入新名称。
3. 再次点击“保存筛选”。
4. 确认左侧同时保留了原版本和新版本。

## 删除已保存筛选

1. 将鼠标移到左侧对应记录上。
2. 点击右侧的删除按钮。
3. 在确认框中确认删除。

删除的是保存记录，不会删除股票行情数据，也不会删除“历史对话”中的记录。

## 保存前的检查

- 快照日期是否正常。
- 字段、符号、数值和单位是否正确。
- 排序字段和方向是否符合用途。
- 名称是否能与其他筛选区分。
