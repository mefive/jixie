# 查看第一份因子分析结果

分析完成后，先核对样本和研究口径，再看分组图和指标。不要从某个收益数字直接得出交易结论。

## 先核对研究口径

下图中的标记分别是：

1. 有效样本期数、分析年份、等权或市值加权切换，以及因子方向。
2. “研究口径与可复现性”。

![因子报告的样本范围和研究口径](/help/zh/factors/factor-methodology-01.png)

按以下顺序检查：

1. **样本期数和年份**：确认区间与设置一致。月频报告中的“120 月”表示 120 个有效月度观察期。
2. **数据截止**：这是报告实际使用到的最新数据日期，不一定是今天。
3. **有效期数**：查看参与分析的期数和考虑过的期数是否一致。
4. **样本变化**：卡片会显示因子值、成仓/前瞻行情、上市时间、风险状态和流动性过滤前后的数量。
5. **处理口径**：核对最低上市天数、低流动性比例、最少样本、异常值处理和交易成本。
6. **黄色提示**：如果某种历史状态无法可靠执行，报告会明确标记，并且不会拿当前状态回填过去。

代码 SHA-256 是本次因子计算代码的摘要。它用于确认两份报告是否使用同一份实现，不需要用户手工计算。

## 查看分组图

下图中的标记分别是：

1. D1 至 D10 的下一期年化收益。
2. 图表口径说明。
3. 主要统计指标。

![因子报告中的十组收益和主要指标](/help/zh/factors/factor-overview-01.png)

图表横轴从 D1 到 D10：

- D1 是因子数值最低的一组。
- D10 是因子数值最高的一组。
- 纵轴是各组“下一期”收益换算后的年化值。

阅读时先看整体顺序，不要只比较 D1 和 D10。各组从低到高大致连续上升，比中间多组杂乱、只有两端差异更容易说明排序关系。

柱状图中的负数不表示因子一定无效。需要看各组之间的相对顺序、不同月份的稳定性、成本和回撤。

## 第一次需要看懂的指标

- **Rank IC 均值**：每一期把因子排名与下一期收益排名做相关，再取平均。正数表示因子值越高，后续收益排名整体也越高；负数表示方向相反。绝对值越大，历史排序关系越明显。
- **ICIR(年化)**：Rank IC 相对自身波动的稳定程度。数值较高表示历史关系较稳定，但不代表未来不会失效。
- **IC>0 占比**：有多少期的方向为正。接近 50% 表示方向并不稳定。
- **多空 D10−D1 年化**：假设做多最高组、做空最低组得到的历史年化差异。这是研究构造，不等于普通账户可以直接实现。
- **多空 Sharpe**：多空收益相对波动的比值，需要和最大回撤一起看。
- **多空最大回撤**：多空净值从阶段高点到之后低点的最大跌幅。
- **最高档月换手**：最高因子组每月更换股票的比例。越高，交易成本和实际执行难度通常越大。

截图中的具体数字会随数据更新和分析设置变化。用户自己的结果不需要与截图完全相同。

## 建议的阅读顺序

1. 核对因子名称、频率、区间和中性化。
2. 核对数据截止和有效样本。
3. 查看 D1 到 D10 是否有较连续的顺序。
4. 查看 Rank IC 的正负和大小。
5. 查看 IC>0 占比和 ICIR，判断历史稳定性。
6. 查看多空最大回撤和最高档换手。
7. 继续向下查看费前与费后净值，确认成本影响。
8. 换一个合理区间或中性化方式重新运行，检查结论是否过度依赖单一设置。

## 不要根据一份报告直接交易

一份报告只能提供历史证据。正式使用前还需要检查：

- 是否反复尝试了很多因子和参数，只保留最好的一份。
- 是否留出了没有参与调整的样本外区间。
- 是否存在无法执行的历史过滤。
- 多空构造是否依赖现实中难以完成的融券。
- 费后结果是否仍然成立。
- 因子是否集中在少数行业或小市值股票。
