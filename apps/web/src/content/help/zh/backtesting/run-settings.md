# 设置回测参数

启动参数决定回测使用的日期、资金和成交成本。相同策略使用不同参数，结果也会不同。

## 打开启动参数

1. 打开一个策略。
2. 点击结果区域右上方的“编辑启动参数”图标。
3. 检查所有字段后，再点击“运行回测”。

下图中的标记分别是：

1. 起始日期。
2. 结束日期。
3. 初始资金，单位为万元。
4. 基础滑点，单位为 bp。
5. 冲击系数。
6. “运行回测”按钮。

![回测工作台中的日期、资金、基础滑点、冲击系数和运行按钮](/help/zh/backtesting/run-settings-01.png)

## 起始和结束日期

- 起始日期决定从哪一天开始读取历史数据和计算净值。
- 结束日期决定回测在哪一天停止。
- 区间内必须包含可用的交易日和策略所需的数据。
- 比较两次结果时，应先确认日期区间是否一致。

区间太短可能没有足够机会触发规则；区间太长则会增加运行时间，也可能跨越规则并不适用的市场环境。

## 初始资金

“资金”使用万元为单位。例如，填写 `200` 表示初始资金为 200 万元。

资金需要足以完成策略要求的交易。资金变化还可能影响：

- 能否买入一手股票。
- 每次交易占账户的比例。
- 冲击成本的估算。
- 最终成交数量和换手率。

## 基础滑点

基础滑点用于模拟计算价格和实际成交价格之间的偏差，单位为 bp。

- `1 bp` 等于 `0.01%`。
- 数值越大，模拟成交价格通常越不利。
- 将滑点设为 0 会得到更乐观的结果，不能代表真实交易没有价差。

## 冲击系数

冲击系数用于模拟订单规模相对市场成交额较大时的额外价格影响。订单越大、标的流动性越低，影响可能越明显。

第一次使用可以保留默认值。比较策略时，应使用一致的成本设置，不要只给某个策略使用更低成本。

## 策略参数

代码中的 `params` 是策略自身参数，例如每次买入数量、均线周期或调仓数量。它们与日期、资金和成本不是同一类设置。

修改代码中的参数后，需要重新运行回测。需要同时比较多组参数时，使用“参数扫描”；详细说明会在进阶部分提供。

## 如何检查设置

运行前确认：

- 起始日期早于或等于结束日期。
- 资金单位没有填错。
- 滑点和冲击系数没有被意外设为 0。
- 代码中的证券和日期范围都有可用数据。
- 本次比较使用了相同的成本口径。
