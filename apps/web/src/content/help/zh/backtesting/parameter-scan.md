# 比较多组策略参数

参数扫描用于把同一段策略代码中的数值参数换成多组取值，分别运行回测并比较结果。它适合检查结果是否只在某一个特殊数值上较好。

## 开始前

策略代码需要在 `params` 中声明数值参数，并通过 `ctx.params` 使用。例如，回看天数和每次买入数量可以分别声明为 `lookback` 和 `shares`。

参数扫描不会改写策略代码，也不会覆盖工作台“结果概览”中的普通回测结果。一次最多扫描两个参数、25 组组合，后台按顺序运行。

## 填写扫描设置

1. 打开已经保存的策略。
2. 确认代码中包含可扫描的数值参数。
3. 点击顶部的“参数扫描”。
4. 在第一维选择参数，并用逗号填写至少两个数值。
5. 需要比较两个参数时，勾选“扫描第二个参数”，再填写第二组数值。
6. 需要检查样本外表现时，勾选“同时运行样本内 / 样本外”并选择切分日期。
7. 确认组合数量后，点击“开始扫描”。

下图中的标记分别是：

1. 第一组参数和值。
2. 第二组参数和值。
3. 样本内、样本外切分开关。
4. “开始扫描”按钮。

![参数稳健性扫描中的两组参数、样本切分和开始按钮](/help/zh/backtesting/parameter-scan-settings-01.png)

例如，第一维填写 `2, 3`，第二维填写 `100, 200`，会运行 `2 × 2 = 4` 组组合。

## 等待扫描完成

扫描期间打开结果区域的“参数扫描”标签。页面会显示当前运行日志。不要刷新后重复提交相同扫描；等待当前任务完成或明确显示失败。

组合越多、日期越长、策略处理的证券越多，所需时间越长。

## 查看扫描结果

下图中的标记分别是：

1. 历史扫描，可以重新打开以前完成的扫描。
2. 对比指标，例如年化收益或 Sharpe。
3. 参数组合图。
4. 每组参数的明细表。

![四组参数扫描结果的指标选择、组合图和明细表](/help/zh/backtesting/parameter-scan-results-01.png)

查看结果时：

1. 先确认历史扫描的完成时间。
2. 检查页面显示的组合数量、代码标识和数据截止日期。
3. 选择要比较的指标。
4. 在图表中观察相邻参数的结果是否接近。
5. 在表格中核对每一组具体数值。

示例截图使用较短区间，因此年化收益数值只用于演示页面，不应用来评价策略。

## 使用样本内和样本外

勾选样本切分后：

- **样本内**用于观察和选择参数。
- **样本外**用于检查选定参数在未参与选择的后续区间中是否仍有表现。
- **全样本**显示整个日期范围的结果。

不要根据样本外结果反复修改参数，再把同一段数据继续称为样本外。这样会让样本外区间也参与选择。

## 如何判断参数是否稳健

优先关注：

- 相邻数值是否得到大致一致的方向。
- 收益改善是否同时伴随更深回撤或更多交易。
- 结果是否只在一个很窄的数值上突然变好。
- 样本外结果是否明显弱于样本内。
- 成本提高后结果是否仍能维持。

参数扫描不能证明策略未来有效。它只能帮助发现参数敏感和过度拟合的迹象，还需要结合交易明细、不同市场阶段和合理成本检查。
