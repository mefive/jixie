# 运行股指期货策略

股指期货使用保证金交易，一手合约代表的名义金额通常远高于保证金。它可以做多或做空，也可能因为较小的指数变化产生较大的账户变化。没有期货经验时，先用历史回测认识手数、保证金和换月，不要把回测结果当作实盘建议。

## 创建策略时写清楚什么

在新建策略的描述中至少说明：

- 使用哪个股指期货，例如沪深 300 股指期货。
- 做多、做空或根据什么条件切换方向。
- 每次交易几手。
- 什么时候开仓、平仓或调仓。
- 回测日期和初始资金。

策略生成后，检查代码是否声明了正确期货代码。产品中的 `IF.CFX` 表示沪深 300 股指期货主力连续代码，不是某一个固定到期月份。

## 运行前检查

1. 确认策略只使用预期的期货品种。
2. 确认正手数表示买入，负手数表示卖出。
3. 确认初始资金足以覆盖保证金和费用。
4. 检查回测区间是否跨越合约到期和换月日期。
5. 检查滑点和手续费设置。
6. 点击“运行回测”。

期货一手不是一股。不同品种的合约乘数、保证金比例和价格不同，不能直接用股票数量理解。

## 查看期货成交

回测完成后打开“交易明细”。下图中的标记分别是：

1. 参与运行的期货策略代码。
2. 成交汇总。
3. 数量／手数、价格、金额、手续费和滑点列。
4. 期货成交记录。

![股指期货回测中的策略、成交汇总和实际月合约记录](/help/zh/backtesting/futures-trades-01.png)

成交记录中：

- `IF.CFX` 是策略使用的主力连续代码。
- “实际 IF2606.CFX”等内容是当天真正映射到的月合约。
- “数量／手数”中的 `1` 表示一手。
- 红色“买”和绿色“卖”表示成交方向。
- 成交金额是合约名义金额，不等于实际占用保证金。

## 为什么示例出现四笔成交

示例策略本身要求开仓一次、之后平仓一次，但回测区间跨过主力合约换月。系统先卖出旧月合约，再买入新月合约维持同一方向，因此交易明细出现额外的移仓记录。

检查连续合约策略时，不要把所有额外成交都当成策略重复下单。先查看每笔记录旁的“实际月合约”，判断是否发生换月。

换月会增加成交次数、手续费和滑点，也是实盘中需要承担的成本。

## 保证金、名义金额和风险

- **名义金额**大致由期货价格、合约乘数和手数决定。
- **保证金**是为持有合约占用的资金，不是最大可能亏损。
- **做多**在指数下跌时可能亏损。
- **做空**在指数上涨时可能亏损。
- 保证金不足时，实盘可能需要追加资金或被强制减仓；历史回测不能消除这类风险。

不要因为保证金占用低，就把剩余现金全部视为可以无风险使用的资金。

## 结果检查顺序

1. 确认期货品种和实际月合约。
2. 检查开仓、平仓和换月记录。
3. 检查手数、方向和名义金额。
4. 检查手续费、滑点和换手。
5. 查看最大回撤和期末权益。
6. 重新使用更高成本测试。
