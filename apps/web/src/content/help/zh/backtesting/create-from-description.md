# 用策略描述创建回测

新建策略时，可以先用一句或几句话写清交易规则。页面会把描述转换成策略代码；真正参与回测的是生成后的代码，因此发送后必须核对，不能只看对话回复。

## 描述中应包含什么

尽量写清：

- **交易什么**：证券名称或代码。
- **什么时候交易**：每天、每周、每月，或满足某个条件时。
- **买入条件**：价格、估值、排名或其他明确规则。
- **买入多少**：股数、手数、持仓数量或资金比例。
- **卖出条件**：清仓日期、持有天数、止损或排名变化。
- **重复买入规则**：已经持有时是否继续买入。

例如：

`只交易沪深300ETF（510300.SH）：每月第一个交易日买入100股；如果已经持有就不重复买入。`

不要只写“做一个好策略”或“帮我赚钱”。这类描述没有可执行的证券、时间和数量规则。

## 输入并发送描述

1. 打开“回测工作台”。
2. 点击“新建”。
3. 在输入框中写完整规则。下图中的 **2** 是输入位置。
4. 按回车键发送，或点击输入框右侧的发送按钮。
5. 等待策略名称、回复和代码出现。

下图中的标记分别是：

1. 新建策略页面。
2. 策略描述输入框。
3. 页面提供的示例。
4. 直接编写代码入口。

![在新建策略页面输入证券、时间、数量和持有规则](/help/zh/backtesting/strategy-description-01.png)

示例适合了解描述格式。点击示例后也要检查生成代码是否符合自己的需求。

## 核对生成结果

下图中的标记分别是：

1. 根据描述生成的策略名称。
2. 用户描述和页面回复。
3. 实际参与回测的策略代码。
4. “运行回测”按钮。

![根据沪深300ETF定投描述生成的策略名称、对话和代码](/help/zh/backtesting/strategy-generated-01.png)

运行前至少检查：

1. 证券代码是否为 `510300.SH`。
2. 调仓周期是否为每月。
3. 是否只在没有持仓时下单。
4. 买入数量是否为 100 股。
5. 代码中是否有意外的其他证券或卖出规则。
6. 顶部日期、资金和成本是否正确。

截图中的代码使用 `ctx.period('monthly')` 区分月份，并在持仓为 0 时买入 100 股。即使不熟悉全部代码，也应找到证券、周期、方向和数量这几个关键值。

## 描述与代码不一致

不要直接运行。可以在左侧继续写明：

- 哪一项不对。
- 应改成什么值或规则。
- 哪些内容保持不变。

例如：

`把每月买入数量改为200股，其他规则不变。`

等待代码更新后，再重新核对。需要理解具体写法时，可以打开[策略 SDK](/docs)。

## 页面没有生成代码

1. 查看左侧是否显示错误。
2. 确认描述中有明确的证券、条件和数量。
3. 删除无法取得的数据条件，改用产品已支持的字段。
4. 重新发送一次更明确的描述。
5. 仍然失败时，记录原始描述和错误信息。

没有生成可用代码时，不要运行默认代码来代替原规则。
