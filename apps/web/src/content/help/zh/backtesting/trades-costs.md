# 查看交易明细和成本

交易明细用于核对策略实际成交了什么。收益图正确显示并不表示每笔交易都符合原规则，运行后应抽查成交日期、方向、数量和成本。

## 从结果打开交易明细

1. 回测完成后，点击“交易明细（数量 笔）”。
2. 查看结果区域内的成交摘要和列表。
3. 需要更宽的表格时，点击右上方的“页面打开”。下图中的 **4** 是该按钮。

下图中的 **1** 是成交摘要，**2** 是筛选条件，**3** 是成交列表。

![回测工作台中的交易明细标签、摘要、筛选和页面打开按钮](/help/zh/backtesting/trades-01.png)

## 使用完整交易明细页

完整页面更适合检查列较多的记录：

1. 页面标题显示当前策略名称和成交笔数。
2. 顶部摘要显示标的数量、买卖笔数、总成交额、手续费、滑点和平均单笔金额。
3. 可以按标的、方向和资产类型筛选。
4. 成交记录显示每笔交易的详细字段。

![完整交易明细页中的策略、成交摘要、筛选和成交记录](/help/zh/backtesting/trades-page-01.png)

## 各列含义

- **标的**：证券名称、代码和资产类型。
- **日期**：策略实际成交日期。
- **方向**：买入或卖出。
- **数量／手数**：股票和 ETF 使用数量，期货使用手数。
- **价格**：计入滑点后的模拟成交价格。
- **金额**：这笔成交的名义金额。
- **手续费**：佣金、印花税和其他显性费用。
- **滑点**：模拟成交价格偏差造成的损耗。

## 筛选成交

成交很多时，可以：

1. 按标的只查看一只证券。
2. 按方向只看买入或卖出。
3. 按资产类型区分股票、ETF 和期货。
4. 清除筛选后恢复全部记录。

筛选只改变页面显示，不会重新运行回测，也不会改变结果。

## 如何核对规则

抽查时至少确认：

- 第一笔成交日期是否符合策略的开始条件。
- 买卖方向是否与规则一致。
- 数量是否受到资金和最小交易单位影响。
- 是否出现预期之外的重复成交。
- 手续费和滑点是否为合理的非负数。
- 总成交笔数是否与策略频率大致一致。

如果代码要求交易但列表为空，先检查日志、日期、证券数据、资金和交易限制。

## 没有交易明细

没有成交时不会出现交易明细标签。常见原因包括：

- 条件在区间内没有触发。
- 资金不足。
- 证券没有可用数据。
- 下单数量不符合交易单位。
- 订单受到涨跌停或其他交易规则限制。

成交为 0 不是策略表现良好的证据，应先解决没有成交的原因。
