# Sign in

Sign in with a verification code sent by email. You do not set a password. An email address that has been used before goes directly to verification; a new address also needs an invitation code.

## Before you start

- Make sure the email address can receive messages.
- Have an invitation code ready if this is a new address.
- Enter the verification code soon after it arrives.

## Enter your email

1. Open the sign-in page.
2. Enter a complete address, such as `reader@example.com`, in **1**.
3. Select the Continue button marked **2**.

![Email field and Continue button on the sign-in page](/help/zh/getting-started/login-01-email.png)

An existing account proceeds to verification. A new address proceeds to the invitation-code step.

## Enter an invitation code for a new address

1. Enter the invitation code in **1**.
2. Select the button marked **2** to send a verification code.
3. If the email address is wrong, use the link marked **3** to change it.

![Invitation-code field, send button, and change-email link](/help/zh/getting-started/login-02-invite.png)

If the invitation code is invalid or expired, the page displays an error and does not send a verification code.

## Enter the verification code

1. Open the verification email.
2. Enter the six-digit code in **1**.
3. Select the sign-in button marked **2**.
4. To enter the email again, use the link marked **3**.

![Verification-code field, sign-in button, and restart link](/help/zh/getting-started/login-03-code.png)

After a successful sign-in, your email and the Log out action appear in the upper-right corner.

## Common problems

### No verification email

Check the spam folder and the spelling of the address. Wait briefly before requesting another code, and only use the newest code.

### The code is rejected

It may be expired or belong to an earlier request. Restart sign-in and use the newest email.

### The page asks for an invitation code

The email address has not been registered. A valid invitation code is required before the verification email can be sent.
