# Continue validation in Factor or Strategy

Research supports editable exploration. To validate a factor or trading rule, open Factor or Strategy, create a draft manually, extract the algorithm and review its code, then explicitly start analysis or a backtest.

Research no longer promotes versions, generates drafts from execution snapshots or displays source handoff cards. Saved Factor and Strategy source remains; code using removed data interfaces fails and should be revised against the current data catalog.

Factor publication fixes current code and a matching successful report. See [Publish a factor](/docs/help/factors/publish-factor).
