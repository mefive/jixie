# Use conversations

Chats preserve the query process so that you can review it or ask a follow-up. Saved screens preserve reusable criteria. They serve different purposes.

## Start a conversation

![New chat, input, chats, and saved screens](/docs/images/help/zh/screening/conversations-01.png)

1. Select New chat, marked **1**.
2. Enter a stock, ETF, or criteria request in **2**.
3. Press Enter.
4. Wait for the turn to finish.

After the first message, the conversation appears under Chats, marked **3**.

## Reopen and continue

1. Select the item under Chats.
2. Wait for the previous content.
3. Enter a follow-up in the input at the bottom.
4. Press Enter.

State the intended change explicitly, for example:

- `Change the PE(TTM) upper limit to 20`
- `Add dividend yield above 4%`
- `Sort by turnover from high to low`

After the result appears, verify the conditions displayed by the page.

## Chats and saved screens

| Item | Chats | Saved screens |
| --- | --- | --- |
| Stored content | Questions, replies, and result process | Fields, operators, values, and sorting |
| Main use | Review and ask follow-ups | Rerun fixed rules on current data |
| Location | **3** | **4** |
| Delete effect | Does not delete saved screens | Does not delete chats |

To keep criteria from a conversation, give the screen a name and select Save screen.

## Delete a conversation

1. Move the pointer over the conversation.
2. Select its delete button.
3. Confirm deletion.

The deleted chat cannot be restored from the sidebar. Screens saved separately remain.

## Common problems

### No chat appears on the left

A chat is created only after content is sent. A draft in the input does not create one.

### Results changed after reopening

Query cards obtain current data when rendered. Check the snapshot date before comparing differences.
