# Save and rerun a screen

Save screens that you expect to check repeatedly, such as low PE, high dividend yield, sorted by market capitalization.

The saved item contains the rules, not a frozen copy of the rows. Reopening it runs against the currently available data, so matches, prices, date, and order can change.

## Save the current screen

![Screen name, Save screen button, and saved list](/docs/images/help/zh/screening/save-reuse-01.png)

1. Complete the screen and verify its conditions, sorting, and result.
2. Enter a descriptive name in **1**, such as “Low valuation, high dividend (price limit).”
3. Select Save screen, marked **2**.
4. Wait for the item under Saved screens, marked **3**.

Avoid indistinguishable names for different rules. Include the main difference in the name.

## Run it again

1. Open Screener.
2. Select the name under Saved screens.
3. Wait for the conditions, snapshot summary, and table.
4. Check the snapshot date and match count.

The page uses current data. It does not restore the prices or row order from the day it was saved.

## Save an edited version

You can edit a saved screen after opening it. Those edits do not silently overwrite the original.

To keep the edited version:

1. Edit the conditions and wait for the query.
2. Enter a new name.
3. Select Save screen.
4. Confirm that both versions appear on the left.

## Delete a saved screen

1. Move the pointer over the item.
2. Select its delete button.
3. Confirm deletion.

This removes the saved rules. It does not delete market data or conversations.

## Check before saving

- The snapshot date is reasonable.
- Fields, operators, values, and units are correct.
- Sort field and direction match the intended use.
- The name distinguishes this screen from others.
