# Ask the factor Agent to run an analysis

While editing a custom factor, ask the Agent to analyze the current source or an explicit candidate. Specify dates, frequency, universe or assets, forward horizon and relevant settings. Code, parameters and results are saved in an accessible factor report.

For example:

> Analyze the current profitability factor monthly from 2020-01-01 through 2025-12-31 with size neutralization. Explain coverage, Rank IC, turnover and net results.

The system does not reserve a protected date range or require a analysis settings. An identical active task is reused; after completion you can run another analysis.

## Check the result

1. Open the report returned by the Agent from retained reports.
2. Check source, dates, data cutoff, sample and costs.
3. Read IC, grouped returns, turnover and net results.
4. If the Agent also proposes code, confirm which candidate the report actually evaluated.

The Agent can analyze, while publication remains an explicit user action in the workbench. Historical results do not prove future validity; review overfitting when repeatedly changing a candidate.

Use [embedded analysis](/docs/help/research/embedded-analysis) for additional calculations on existing results.
