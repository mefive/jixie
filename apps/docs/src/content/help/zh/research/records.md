# 研究文档与运行记录

左侧“研究文档”保存当前可编辑的 Markdown/Python Cell、依赖状态和同一文档的 Research Agent 对话。打开文档时会
恢复已保存源码和输出；未重新执行的修改会保持 stale，不会假装仍是当前结果。

## 当前文档

- 标题和 Cell 源码可以继续编辑，并由文档级自动保存保护。
- 单 Cell、受影响分支和 Agent 授权运行属于探索过程，会更新当前 Cell 输出。
- Agent 变更以持久化审核记录保存；刷新页面不会丢失待审核、已接受、已撤销或冲突状态。
- 删除文档会删除该文档、Cell、对话和运行历史，但不会删除市场数据以及已经独立创建的 Factor 或 Strategy。

## 完整运行与封存版本

“干净运行全文”会冻结当时的文档 revision、Cell 顺序与源码、依赖 DAG、runtime 版本和本次输出，形成不可变
`ResearchExecution`。运行期间继续编辑当前文档不会改变这份快照。

每次完整运行都进入文档内运行历史。成功记录可以显式封存并填写版本名、标签和备注；封存只是为已有快照命名，
不会重新运行或改写结果。从快照创建的 Factor/Strategy 会保留来源和回跳链接。

操作顺序：

1. 点击顶部历史图标，打开“完整运行历史”。
2. 核对记录的状态、文档版本、Cell 数量和完成时间。
3. 点击一条记录进入只读快照，检查源码与输出。
4. 成功记录需要作为后续基线时，点击“封存为研究版本”。
5. 填写版本名、标签和备注后确认封存。

![完整运行历史和封存入口](/docs/images/help/zh/research/records-01.png)

完整运行证明“这份源码在这个环境产生了这些输出”，不自动证明方法正确或结论可投资。底层市场数据不会复制进
快照；若以后数据发生修订，应重新干净运行形成另一份快照，并分别审查两次结果。
