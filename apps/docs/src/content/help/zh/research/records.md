# 研究文档与当前输出

> 标为“历史中文界面示例”的图保留当时的结果或状态，数值未重新计算。当前操作请以本文步骤和当前界面图为准。

左侧“当前”列表中的研究文档保存当前可编辑的 Markdown/Python Cell、依赖状态和同一文档的 Research Agent 对话。打开文档时会
恢复已保存源码和输出；未重新执行的修改会保持 stale，不会假装仍是当前结果。

## 当前文档

- 标题和 Cell 源码可以继续编辑，并由文档级自动保存保护。
- 单 Cell、受影响分支和 Agent 授权运行属于探索过程，会更新当前 Cell 输出。
- Agent 变更以持久化审核记录保存；刷新页面不会丢失待审核、已接受、已撤销或冲突状态。
- 删除文档会删除该文档、Cell、对话和运行诊断，但不会删除市场数据以及已经独立创建的 Factor 或 Strategy。

## 搜索、归档和恢复

1. 在左侧选择“当前”或“已归档”。
2. 在“搜索标题或最近内容”中输入关键词。搜索匹配当前列表的标题和内容摘要，不是所有历史输出的全文检索。
3. 暂时不用的研究，在文档条目的管理菜单中选择“归档”。归档会保留源码、输出、对话与运行诊断。
4. 需要继续时切换到“已归档”，打开该条目的管理菜单并选择“恢复”，再从“当前”列表打开。

Agent 或文档运行未结束时，先等待结束再归档。

**1** 按标题或最近内容搜索当前列表；**2** 打开文档管理菜单。

## 永久删除

只有“已归档”条目的菜单提供“永久删除”。核对确认框后才删除；该研究的 Cell、输出、Agent 对话和完整运行诊断都会移除，无法恢复。已独立创建的 Factor 或 Strategy 不会一起删除，但原研究来源可能无法再打开。仅想整理列表时使用归档。

**1** 切换已归档列表；**2** 提供恢复与永久删除。图中只展开菜单，没有执行删除。

![当前界面与操作入口](/docs/images/help/zh/research/document-list-archived.png)

## 当前输出与干净运行

“干净运行全文”重置 Python 会话，按依赖顺序执行当前代码并更新 Cell 输出。编辑后修订不一致的输出会过期，需要重跑。

系统不再保留完整执行快照、正式研究证据或封存版本；没有完整运行历史抽屉。数据修订后重新运行会读取当前数据，不能恢复当时输入。

## 对话中的嵌入分析

[嵌入分析](/docs/help/research/embedded-analysis) 成功后仍可修改重跑，每个草稿只保留最近一次运行。接续 Research 会复制当前代码和参数，运行时重新取数。
