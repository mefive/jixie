# 在 Factor、Strategy 对话中检查数据

可以让 Agent 对已有报告或选定数据做小范围 Python 计算。对话卡片显示表格、图表、数值或错误；点击“查看代码与结果”检查当前 Python 和参数。

## 引用数据

在 Factor 或 Strategy 工作台选择已完成的报告，或通过“引用数据”选择对象、日期、频率和字段。每轮最多引用 8 项。目录选择只是请求范围，实际取数发生在 Python SDK 调用时。报告删除或权限变化后，对应读取会报错。

![数据引用入口](/docs/images/help/zh/research/embedded-reference.png)

证券检索、覆盖和股票池使用专门工具，其他计算使用目录提供的 Python SDK。任意 SQL 不可用。接口缺失时，Agent 应说明缺口，不编造数据。

## 查看和修改

先核对样本范围、日期对齐、缺失值、单位和计算方法，再解释数值。执行成功只说明代码完成，不证明研究方法正确。

代码和参数成功后仍可编辑。点击“修改代码”，保存并运行；重新运行会读取当前数据，替换该草稿之前的普通运行及其 Job。页面展示当前代码；修订不一致时，输出会提示需要重跑。已清理的旧运行链接会显示不存在，不会自动替换成另一份结果。

每次计算最多 16 次 SDK 请求、累计响应 32 MiB、执行预算 30 秒，排队另计。超限、取消、缺数据与计算失败会明确显示。SDK 响应和环境指纹不再留存，不能通过卡片重放当时输入。

## 继续到 Research

“继续到 Research”复制接续时的当前代码和参数，生成可编辑文档；重复点击打开同一副本。成功、失败或取消后的分析都可以复制。副本运行时重新取数，没有 retained/current 输入模式，也不携带旧输入或旧输出。

需要正式因子检验或策略回测时，在对应工作台明确发起。嵌入分析不自动生成或发布 Factor／Strategy。

旧聊天图表只显示标题和停用提示；需要继续分析时，在 Research 重新建立计算。
