# 在 Factor、Strategy 对话中检查数据

在因子研究或策略工作台，你可以让 Agent 对现有数据做一次小范围计算。结果以嵌入式分析卡片留在对话里，包含表格、图表或数值；点击“查看代码、来源与历史”可以检查 Python、参数、实际输入与错误。

它适合回答当前问题，例如“把这份因子报告的十组收益画出来，并计算最高组与最低组的差距”。需要反复扩展方法、整理表格与结论时，从卡片进入 Research，继续写一份可编辑文档。

## 从哪里开始

- 在因子研究页打开预设因子、自定义因子或组合因子，可提问解释定义或已有报告。自定义因子草稿中的代码编写仍由原编辑器负责。
- 在策略工作台打开策略和一份已完成的回测报告，可询问净值、收益、交易等已保存结果。此类分析不会重新执行策略。
- 已选中的完成报告默认随本轮问题引用。取消“引用所选报告”后，本轮不自动绑定它；之前问题保留原来源。
- 需要其他数据时，点击输入框旁的“引用数据”。它与 Research 的数据目录共用选源规则，可以选择对象、日期、频率、字段或一份具体报告。每轮最多引用 8 项。

**引用数据不等于已经取数。** 在 Research 中，目录会插入 SDK 调用；在对话中，它会保存请求的来源和范围，供 Agent 编写明确的 Python 调用。只有运行记录里的“实际使用的数据”证明本次计算读到了什么。

口径尚不明确时，例如币种、复权、样本期或代理指标存在多种选择，Agent 应先解释差异并让你决定。简单事实和小聚合仍可直接查询后回答，不需要每句话都生成卡片。

Python 通过数据目录中的 SDK 方法取数，不能直接读取任意 SQL 查询结果。目录外的简单事实仍可由 Agent 查询；若进一步计算需要尚未开放的数据接口，Agent 应说明缺口，不能把聊天里抄来的数据冒充已留存的完整输入。

当前选源入口：**1** 是对话工具栏，**2** 是数据目录的四类来源。此图展示请求来源，不是成功计算或实际输入留存的证据。

## 怎样读卡片

先看样本范围和处理方法，再看数值。详情中可以核对：

1. 本次运行的代码、参数、运行时间和状态。
2. 宿主的已保存定义、所选报告标识与来源指纹；它不代表编辑器里尚未保存的代码。
3. 实际 SDK 请求的日期、字段、行数或结构化响应、诊断及输入指纹。展开“查看留存输入”可以看原响应预览；界面预览最多 20,000 字符，后端指纹对应完整留存输入。
4. 日期对齐、缺失值、空样本、常数序列、单位和成本如何处理。代码应说明这些方法；“执行成功”不会证明方法正确。

每次嵌入计算最多 16 次 SDK 请求、累计输入 32 MiB、执行预算 30 秒；排队另计。不同 SDK 和输出还有各自限制。超限、缺数据或执行失败应显示错误，不能把未完成的统计解释成零。没有 SDK 请求时，检查代码使用的是常量还是自行构造的数据。

分析先保存再等待 Agent 的最终解释。刷新页面后可恢复卡片；回答失败、停止或断线时，也可从“分析记录”找回已经提交的运行。

## 什么时候固定，怎样修改

第一次成功后，这个版本的代码、参数和上下文固定。此前失败或取消的记录仍然保留；未成功版本可以修改草稿后重试。

成功后点击“修改并创建新版”，编辑 Python 或参数再运行。新版保留父版本关系，原聊天消息继续引用原运行。打开历史查看其他运行不会改写旧答案。

“重新取数运行”会新增运行记录，并读取当前可用数据。它不会覆盖原结果；如果查看的是后来已修改的旧草稿运行，会按那次源码另建版本。要基于原输入继续计算，请进入 Research。

## 继续到 Research

选中一条成功且输入完整的运行，点击“继续到 Research”。系统创建包含说明、参数和原 Python 的可编辑文档；重复点击打开同一副本。

默认选择“使用当时留存的输入”。你可以修改算法或增加对同一输入的计算；SDK 请求必须与原来留存的请求匹配。新增数据或改变取数参数时会报错，不会自动转去读今天的数据。

选择“重新获取数据”后，SDK 才会查询当前数据。切换会让已有 Python 输出过期，并清空解释器状态，需要重新运行。完整运行历史会标明当时的数据模式和原运行标识。原分析保持不变，删除 Research 副本也不会删除原分析。

留存输入可以重做计算，但不保证不同运行环境得到逐位相同结果。普通 Research 文档继续采用自身编辑、依赖和运行记录规则；此功能没有把所有 Research 文档改成冻结 Cell。

## 以前对话里的图表

旧图表保存的是查询和计算代码，没有保存当时的完整点位。重新打开时会使用当前数据库重查，卡片会明确提示；因此图形可能与旧回答不同。当前无数据或执行失败时显示缺失或错误，不会伪造当时结果。新嵌入式分析保留每次运行的结果，不采用这种重查展示方式。

## 怎样进入正式验证

分析卡片回答的是“现有样本里算出了什么”。它不会自动生成新的因子检验报告、启动策略回测、揭示 Holdout、发布因子或操作账户。

需要验证因子候选时，回到因子工作台填写研究卡并运行正式的报告流程；已有因子 Agent 探索报告功能仍遵守其研究卡和 Holdout 边界。需要验证交易规则时，在策略工作台明确运行策略。Research 中完成的研究也可以通过原有封存和交接流程形成 Factor/Strategy 草稿。
