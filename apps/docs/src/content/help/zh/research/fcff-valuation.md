# 用 FCFF 模板研究公司估值

FCFF 是可选研究模板。你也可以直接查询财报、比较指标或自写计算；平台负责数据处理和公式实现，方法、假设和结论由你决定。市场是否兑现估值不是使用本工具的前提。参见[自主分析财报数据](/docs/help/research/financial-data)。

Research 首页的“FCFF 公司估值模板”会建立一份可以查看、修改、完整运行和封存的 Markdown/Python 文档。
模板默认使用五粮液作为真实示例，但示例参数不是平台预测、目标价或买卖建议。

## 模板解决什么问题

模板把估值拆成三类内容：

- 历史事实：估值日当时可得的财报版本、收入、NOPAT、ROIC、再投资、FCFF、市值和股本；
- 用户假设：收入增长、NOPAT Margin、增量资本周转率、WACC、永续增长、终值 ROIC 和股权桥接调整；
- 市场隐含假设：固定其余基准参数后，从当前企业价值反解的一个收入增长率。

公式在文档中公开，重复计算由 `valuation.fcff_scenarios` 和 `valuation.implied_revenue_growth` 完成。
所有输入、桥接调整和敏感性仍可在 Python Cell 中查看和修改；helper 不生成预测。修改参数后，下游结果会标记为“待重跑”。

## 操作顺序

1. 打开“研究”，点击“FCFF 公司估值模板”下的“打开模板”。
2. 在第一个 Python Cell 核对股票、估值日、复查日、预测年数和三套情景。
3. 核对经营必需现金、其他非经营资产和其他优先索偿；系统不会替用户猜这些值。
4. 点击“干净运行全文”。
5. 依次检查历史财务、假设表、三套估值、敏感性、反向估值和下一期财报复查。
6. 需要保存证据时，在“完整运行历史”中打开成功记录并“封存为研究版本”。

更换股票后必须重新审查模型适用性。银行、保险和券商不会套用一般工商业 FCFF 模板。

## 预测和终值

预测期使用以下公开关系：

```text
收入
  × NOPAT Margin
  = NOPAT
  - 收入增加 / 增量资本周转率
  = FCFF
```

终值使用永续增长模型，并用 `终值增长率 / 终值 ROIC` 表达终值再投资率。`终值增长率 >= WACC`、终值
ROIC 无法支撑增长或股本非正数时，该情景会被拒绝。终值占企业价值比例超过模板中显式阈值时会显示警告。

股权价值桥接从 M2 财务内核的市值与企业价值差额开始，再明确加入经营必需现金、其他非经营资产和其他优先索偿。
这些主观调整保留在参数 Cell 中。

## 如何理解场景和反向估值

基准、乐观、悲观三套结果形成的是“情景区间”，不是统计置信区间。敏感性图逐格重新运行同一个 DCF，用来检查
WACC 和永续增长变化对结果的影响。

反向估值按估值函数的驻点划分用户声明的收入增长区间，再逐段求根，检查近邻多解和相切解。只有发现唯一根时才返回隐含增长率；无解、多解、非有限值或估值对该参数
变化过小都会返回诊断。这个结果只是“在其余假设不变时”的一种价格解释，不代表市场只有这一种叙事。

## 复用计算与适用边界

在 Research Python Cell 中可直接调用以下方法，完整参数和返回列见 [Research SDK 参考](/docs/sdk?runtime=research)：

```python
forecasts = valuation.fcff_scenarios(base, scenarios, bridge, forecast_years=5)
implied = valuation.implied_revenue_growth(
    base, scenarios[scenarios["scenario"] == "base"], bridge,
    target_enterprise_value=market_enterprise_value,
)
```

`base` 为一行，包含 `revenue`、`nopat_margin`；`scenarios` 包含情景名称、收入增长率、目标 NOPAT 利润率、
增量资本周转率、WACC、永续增长率和终值 ROIC。`bridge` 为一行，包含 `bridge_adjustment`、`issued_shares`、
`operating_cash_required`。金额用人民币元、股本用股、比率用小数（8% 写作 `0.08`）。

桥接调整已经包含经营必需现金；helper 只从企业价值扣除 `bridge_adjustment`，不会再次加入现金调整。
预测收入按固定增长率变化，利润率线性过渡；收入下降时模型假设能释放资本，这对重资产企业未必成立，需要用户复核。
最多支持 20 个情景、20 个预测年。结果每情景每年一行，汇总估值在各年重复，不能把企业价值列按年求和。
输出保留 `formula_version`；企业价值为零时终值占比为空。

同一流程已用五粮液、美的集团和宁德时代的不同经营形态演练；它们共享计算规则，不共享增长或折现率假设。
历史 FCFF 或再投资不可用时，复查保留缺失原因，不填零；必要经营输入或桥接缺失则停止运行。

主营业务构成目前未接入公开 SDK：样本缺少公告和版本时间，分类层级、改名和部分成本/利润缺失也需要核对。
不能直接加总全部分部行，也不能把收入变化自动解释成销量或价格变化。当前没有独立行业驱动模板或公司目标价页面。

## 下一期财报复查

五粮液示例把 `2025-04-28` 的原情景与 `2026-05-06` 当时可得的 2025 年报并排比较。复查表保留：

- 原悲观、基准和乐观范围；
- 下一年报实际收入、NOPAT Margin、FCFF 和收入增长；
- 实际结果是否落在原范围内；
- 复查日价格对应的新隐含收入增长。

初始数据和复查数据分别按自己的 `as_of` 日期读取，因此后来的年报不会回填到初始估值日。

## 财报异常与指标不可用

财报原始版本不会因异常被改写。指标计算会检查历史时点实际选中的版本；若依赖未解释的负现金资本支出、
不一致的资产负债表或跨表净利润，受影响指标返回空值、`status=invalid`，并在 `missing_reason` 中标明
`accounting_review_required:…`。这表示“当前模型暂不可使用”，不等于断言公司财报错误。

隔离沿实际输入版本传递，包括 TTM 季度和上年资产负债表；无关指标继续可用。负数非流动负债若能解释并对上
负债小计，只提示，不自动拒绝。期初/期末现金勾稽差异也不会直接否定不依赖这两个余额的经营现金流。
遇到这些状态，不得填零、忽略状态或偷偷换用更早财报来生成估值。

## 期限、现金流和市场复核

模板共有29个 Cell，其中24个 Python Cell。除了原估值闭环，还包括：

- 3/5/10年增长持续期：固定历史利润率和其他参数，隔离持续期本身的影响；
- 零增长、终值ROIC等于WACC、持续超额回报三种终值，以及明确的终值再投资；
- 净利润、NOPAT、经营现金流、现金资本开支、净资本开支与FCFF对账；差额不会自动被称为扩张投入；
- 原预测路径滚动一年后的剩余企业价值；这是模型恒等式，不是股东实际收益；
- 3/6/12个月股票与沪深300ETF的同期复权收益、收益差和最大回撤；
- 共同市场截止日的可得财报更新与下一年收入、利润率、FCFF观察阈值。

股票与ETF都使用 `close × adjFactor`，不再叠加分红。缺失配对日期、重复日期或缺失端点会停止；尚未满窗口时显示未观察，不用短窗口代替。收盘价与“供应商市值/财报股本”分列，股本和A/H口径差异不能忽略。
三家公司是已知的事后案例，三个重叠窗口也不是三个独立样本，不能据此声称策略通过样本外检验。

## 年报附注局部调整

原始数据和公共财务内核保持原口径。文档末尾另列年报附注来源、页码、金额单位、保守可得日和文件指纹，并展示调整前后结果。
参数 Cell 的 `classification_notes` 是可编辑研究证据；更换公司或日期时须同步更换这些附注，缺少匹配的年度资料会停止调整。

调整将已识别的理财和金融投资从经营资本中分离，并剔除相应已识别金融收益；现金和交易性金融资产已经在内核中扣除，不能再次加回。
长期理财的总额已经包含一年内到期部分，不能重复相加。租赁索偿只补非流动部分，因为流动部分已在原内核债务里。

原口径和调整口径使用同一年度资产负债表及股本。截止日的“年报锚点”仍是年报余额，不冒充最新季度资产。目标利润率扣减初始年度金融收益的税后收入占比，并在后续复查保持这项换算；它是研究假设，不是公司指引。

另列留存一个月收入的现金、对新增非经营资产折价10%的压力情景。这不是统计区间。税负分配、必要经营现金、金融子业务、其他索偿及租赁再投资仍有缺口；局部调整后的FCFF和估值也不代表审计通过。

## 样本齐全不等于验证通过

“三表齐全”“必要估值输入齐全”“可计算年报FCFF”“可计算最新季度TTM FCFF”是不同检查。
全市场输入审计并不等于逐家公司做过估值，也不等于所有原始值核对过年报。研究结果应同时报告检查日期、分母、缺失原因和市场截止日。
