# 用 FCFF 模板研究公司估值

Research 首页的“FCFF 公司估值模板”会建立一份可以查看、修改、完整运行和封存的 Markdown/Python 文档。
模板默认使用五粮液作为真实示例，但示例参数不是平台预测、目标价或买卖建议。

## 模板解决什么问题

模板把估值拆成三类内容：

- 历史事实：估值日当时可得的财报版本、收入、NOPAT、ROIC、再投资、FCFF、市值和股本；
- 用户假设：收入增长、NOPAT Margin、增量资本周转率、WACC、永续增长、终值 ROIC 和股权桥接调整；
- 市场隐含假设：固定其余基准参数后，从当前企业价值反解的一个收入增长率。

公式保留在普通 Python Cell 中，不通过隐藏估值引擎计算。修改参数 Cell 后，依赖这些参数的结果会标记为“待重跑”。

## 操作顺序

1. 打开“研究”，点击“FCFF 公司估值模板”下的“打开模板”。
2. 在第一个 Python Cell 核对股票、估值日、复查日、预测年数和三套情景。
3. 核对经营必需现金、其他非经营资产和其他优先索偿；系统不会替用户猜这些值。
4. 点击“干净运行全文”。
5. 依次检查历史财务、假设表、三套估值、敏感性、反向估值和下一期财报复查。
6. 需要保存证据时，在“完整运行历史”中打开成功记录并“封存为研究版本”。

更换股票后必须重新审查模型适用性。银行、保险和券商不会套用一般工商业 FCFF 模板。

## 预测和终值

预测期使用以下公开关系：

```text
收入
  × NOPAT Margin
  = NOPAT
  - 收入增加 / 增量资本周转率
  = FCFF
```

终值使用永续增长模型，并用 `终值增长率 / 终值 ROIC` 表达终值再投资率。`终值增长率 >= WACC`、终值
ROIC 无法支撑增长或股本非正数时，该情景会被拒绝。终值占企业价值比例超过模板中显式阈值时会显示警告。

股权价值桥接从 M2 财务内核的市值与企业价值差额开始，再明确加入经营必需现金、其他非经营资产和其他优先索偿。
这些主观调整保留在参数 Cell 中。

## 如何理解场景和反向估值

基准、乐观、悲观三套结果形成的是“情景区间”，不是统计置信区间。敏感性图逐格重新运行同一个 DCF，用来检查
WACC 和永续增长变化对结果的影响。

反向估值先扫描用户声明的收入增长区间。只有发现唯一根时才返回隐含增长率；无解、多解、非有限值或估值对该参数
变化过小都会返回诊断。这个结果只是“在其余假设不变时”的一种价格解释，不代表市场只有这一种叙事。

## 下一期财报复查

五粮液示例把 `2025-04-28` 的原情景与 `2026-05-06` 当时可得的 2025 年报并排比较。复查表保留：

- 原悲观、基准和乐观范围；
- 下一年报实际收入、NOPAT Margin、FCFF 和收入增长；
- 实际结果是否落在原范围内；
- 复查日价格对应的新隐含收入增长。

初始数据和复查数据分别按自己的 `as_of` 日期读取，因此后来的年报不会回填到初始估值日。
