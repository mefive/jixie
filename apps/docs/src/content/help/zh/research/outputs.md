# 查看研究输出

Python Cell 的最后一个表达式或显式展示调用会出现在 Cell 下方。输出可能是文字、数字、表格、原生交互图或 Matplotlib 静态图。判断结论前，先确认输出来自当前源码而不是“待重跑”的旧结果。

## 文字和数值

标量、列表和短文本直接显示在输出区。建议让关键数值带上名称、单位和样本数，避免只留下一个无法解释的数字。

## 表格

pandas DataFrame 会显示为分页表格。页面会限制一次展示的行数和超长单元格，防止大结果拖慢浏览器。

下图中的顶部提示说明原表行数、当前预览行数和被截断的超长单元格；底部可以翻页和调整每页行数。

![研究表格的分页与截断提示](/docs/images/help/zh/research/outputs-01.png)

预览截断只影响页面展示，不表示原始计算只产生这些行。需要在结论中引用大表时，应先用代码汇总、筛选或抽样，并在 Markdown 写清处理方式。

## 原生交互图

`charts.*` 会生成产品内的交互图，支持悬停查看值、缩放和图例交互。常见类型包括直方图、箱线图、热力图和事件路径。

```python
charts.histogram(
    monthly_returns,
    column="return",
    bins=8,
    labels={"return": "月收益"},
    title="月收益分布",
)
```

![研究文档中的原生交互图](/docs/images/help/zh/research/outputs-02.png)

图表只是已有数据的呈现。直方图分箱、坐标范围、缺失值和样本区间都会影响读法，应在相邻 Markdown Cell 说明。

## Matplotlib 静态图

需要产品图表尚未覆盖的自定义画法时，可以使用 Matplotlib。静态图不提供产品原生悬停和缩放；同时要控制尺寸、标签数量和分辨率，避免生成过大的图片。

## 输出与快照

- 单 Cell 或受影响分支运行更新当前文档输出，适合探索。
- “干净运行全文”成功后，输出进入不可变完整运行。
- 打开历史快照时，源码和输出只读，不会被当前文档后续修改覆盖。
- 图和表不能单独证明方法正确；要连同源码、输入范围和假设一起审查。

## 常见问题

### 图表没有出现

先看 Cell 是否运行成功，再检查传给 `charts.*` 的列名和数据类型。空表不会凭空生成有效图表。

### 表格只看到一部分

这是预览限制。使用分页查看，或在 Python 中先筛选、聚合并显示与你的问题直接相关的行。
