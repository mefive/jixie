# 使用研究数据目录

“数据目录”用于查找当前研究运行时真正支持的对象、字段和调用方式。不要凭印象猜字段名；先从目录确认，再把生成的代码插入 Python Cell。

## 打开并搜索

1. 打开一份研究文档。
2. 点击右上角的数据图标，打开“数据目录”。
3. 输入对象名称、代码或指标名称，例如“沪深300”“000300.SH”“收盘价”。
4. 选择需要的数据项，核对说明、单位、频率和返回列。
5. 设置页面提供的日期、频率或转换方式。
6. 点击插入代码，把调用写入当前 Python Cell。

插入后仍要检查对象、起止日期和变量名是否符合研究问题。

## 四种数据读取方式

### 单个对象的时间序列

使用 `data.series()` 读取一个指数、股票或其他受支持对象随时间变化的数据。

```python
monthly = data.series(
    "index", "000300.SH",
    start="20200101", end="20251231",
    frequency="monthly", transform="simple_return",
)
```

返回表至少包含 `date` 和 `value`。具体参数和列以数据目录中的当前签名为准。

ETF 也使用这一入口，例如 `data.series("etf", "510300.SH", ...)` 返回该产品有本地覆盖日期内的复权收盘序列。目录会同时显示 registry 暴露、主/备角色、数据起止日和代理限制。完整 ETF 名录中的产品只有在本地日线真实存在时才标为可用；“上游有资料但本地没有行情”不会静默返回一个替代产品。

### 一个历史时点的股票截面

使用 `data.cross_section()` 读取某个历史交易日当时可得的 A 股字段。适合检查分布、相关性和候选股票池，不适合替代正式 FactorReport。

### 连续月末的股票 Panel

使用 `data.panel()` 读取一段时间内已完成月末的 PIT 截面。它适合探索多期排序、回归和稳定性。必须明确日期、股票池、字段和缺失值处理；不能把今天看到的最新财务值回填到历史日期。

### 美国国债收益率曲线

使用 `data.yield_curve()` 读取平台审核过的美国国债名义或实际收益率期限序列。曲线、期限和变换有独立白名单，不使用 `data.series()` 猜测收益率表或字段。具体参数、百分点单位和中美市场时区边界见[读取美国国债收益率曲线](/docs/help/research/yield-curves)。

## 时点和修订边界

- 截面和 Panel 使用当时可得数据，财务字段按公告时点对齐。
- 历史指数成分、名称和行业尽量使用对应历史时点的记录。
- 重新运行可能读到后续修订的数据；需要保留结果时，使用“干净运行全文”生成不可变快照。
- 探索代码中的 IC、排序或回归不是已审批的正式因子证据。候选信号应交给 FactorReport 重新验证。

## 使用编辑器提示

输入 `data.`、变量名后的句点或函数参数时，编辑器会显示当前可用的方法、参数和返回列。红色波浪线通常表示方法名、参数或列名与当前 SDK 不一致。先查看提示和数据目录，不要随意删除校验。

## 常见问题

### 找不到想要的数据

换用对象代码或指标的常用中文名称搜索。仍然没有结果时，表示当前目录没有这项能力；不要让 Agent 静默改用“相似”数据。

### 返回空表

检查对象代码、日期范围、数据频率和该字段首次可用时间。截面查询还要检查该日期是不是可用交易日。
ETF 还要检查产品上市日和目录中的本地覆盖起点；不要把同一指数的另一只 ETF 自动替换进来。
