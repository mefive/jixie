# 回答研究口径确认

当问题中的对象、币种、期限或数据形式与平台现有数据不完全一致时，Research Agent 会先显示一张“待确认”卡，而不是自行换成相似数据。你需要明确选择后，Agent 才会继续修改 Cell。

## 为什么需要确认

“美元现货黄金”“沪金主力连续”和“黄金 ETF”都与黄金有关，但交易市场、计价币种、费用和跟踪方式不同。把其中一个静默当成另一个，会改变研究问题。

确认卡会写明原问题、当前可执行选项和每个选项与原定义的差异。它不是推荐列表，也不表示第一个选项更好。

## 回答确认卡

1. 阅读卡片标题和问题，先确认需要决定的是对象、期限、市场还是其他口径。
2. 逐项阅读名称下方的差异说明，包括币种、工具类型、期限和代理限制。
3. 符合研究目的时，选中一个可执行口径。
4. 不愿改变原定义时，选择“不使用代理”。研究会保留当前数据缺口。
5. 页面允许时，也可以在“或者输入你的具体选择…”中写明更具体的要求。
6. 点击卡片右下角的“确认选择”。

![待确认的研究口径选择卡](/docs/images/help/zh/research/clarifications-01.png)

## 确认后会发生什么

- 卡片状态从“待确认”变为“已确认”，选项和回答会保留在研究记录中。
- Research Agent 会根据这次选择开启下一步处理；它仍需提出可审核的 Cell 变更。
- 刷新页面或重新打开文档，已确认记录仍然可见。
- 确认只固定本次研究口径，不证明代理与原对象等价，也不会自动运行 Cell。

![已经保存的研究口径选择](/docs/images/help/zh/research/clarifications-02.png)

## 为什么确认前不能继续输入

“待确认”期间，右侧普通输入框会显示“请先回答上方研究确认问题”并暂停输入。这样可以避免同一轮里同时出现互相冲突的口径和 Cell 提案。先回答当前卡片，再继续补充要求。

## 常见问题

### 没有一个选项合适

选择“不使用代理”，或在允许自定义回答时写明所需对象和口径。不要为了继续流程而选一个不符合问题的代理。

### 选错后能直接改吗

已确认卡片会作为研究记录保留，不能把历史选择静默覆盖。向 Agent 明确说明要更改口径；如果新要求仍有歧义，系统会再次要求确认。

### 确认后为什么还没有结果

确认只是允许 Agent 继续准备变更。你仍要审查 Cell 差异、接受源码并显式运行相关 Cell。
