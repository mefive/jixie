# 建立研究文档和 Cell

一份研究文档由 Markdown Cell 和 Python Cell 组成。Markdown 用来记录问题、事前假设、公式和结论；Python 用来读取数据、计算并生成结果。把两者放在同一份文档中，才能看清“为什么计算”和“实际算出了什么”。

## 新建研究

1. 打开顶部“研究”。
2. 在输入框写下要验证的问题并提交。系统会建立包含 Markdown 和 Python Cell 的研究文档。
3. 已经打开文档时，点击左侧“新建研究”可回到问题输入页。
4. 在左侧“研究文档”中切换已有文档。
5. 点击标题旁的编辑图标可以改名。

下图中的标记分别是问题输入框、“开始研究”和已有研究文档。输入问题并发送后，系统会建立文档并开始处理；不需要先选择模板。

![从问题开始建立研究文档](/docs/images/help/zh/research/new-research-01.png)

## 添加和编辑 Cell

1. 点击两个 Cell 之间或文档底部的“+”。
2. 选择“Markdown”或“Python”。
3. Markdown Cell 点击编辑图标后输入内容，再确认编辑。
4. Python Cell 可直接在代码编辑器中输入。编辑器会提示 Python 语法和当前 Research SDK。
5. 使用每个 Cell 右上角的删除图标移除不再需要的 Cell。如果存在依赖它的下游 Cell，确认框会列出受影响范围。

建议先写 Markdown，再写对应的 Python。例如先写“比较 2020—2025 年沪深300和中证500月收益的相关性”，再在下一个 Python Cell 读取并计算这两条序列。

## 看懂保存状态

Cell 标题栏会显示“未保存”“保存中”或“已保存”。源码编辑后会自动保存，不需要寻找单独的保存按钮。

- “未保存”：本地内容刚发生变化。
- “保存中”：正在写入当前文档。
- “已保存”：当前源码已经保存。

离开页面前应等到“已保存”。如果同一文档在另一处被修改，页面会提示冲突；先核对两边内容，不要反复刷新覆盖其中一份。

## 看懂依赖和待重跑

Python Cell 下方会列出它“定义”和“依赖”的变量。系统据此建立上下游关系。

修改上游源码后，依赖它的下游 Cell 会显示“待重跑”。旧输出仍保留用于对照，但已经不代表当前源码。系统不会因为一次编辑就自动运行全部昂贵计算；需要由你选择运行当前 Cell、受影响下游或全文。

删除仍被引用的上游 Cell 后，受影响的全部下游 Cell 会显示“待修复”并暂停运行。提示会列出缺失变量；在下游源码中移除该依赖，或在其他上游 Cell 恢复同名定义，保存后即可自动解除。

## 常见问题

### 修改了 Markdown，为什么 Python 没有重跑

Markdown 不会执行代码。只有 Python 源码或其依赖发生变化时，计算链才需要重跑。

### 删除 Cell 后结果还在吗

当前文档会失去该 Cell 及其输出。以前成功的完整运行快照仍保持不变，可在“完整运行历史”中回看。
