# 运行、停止和重置研究

研究工作台不会在每次编辑后自动执行昂贵计算。你可以根据改动范围，选择运行一个 Cell、受影响分支或整个文档。

## 运行当前 Cell

点击 Cell 右上角的运行图标，只执行这个 Cell。它适合检查一小段代码，但有两个前提：

- 当前运行环境中已经存在它依赖的上游变量；
- 上游输出不是由已改变的旧源码产生。

如果依赖缺失或已过期，先运行上游，或者改用受影响分支／全文运行。

## 运行当前 Cell 及受影响下游

点击分支图标“运行当前 Cell 及受影响下游”。系统会按依赖顺序执行当前 Cell 和依赖它的 stale Cell，不会运行与这条分支无关的独立 Cell。

![运行当前 Cell 及受影响下游](/docs/images/help/zh/research/run-control-01.png)

它适合修改一个数据读取或计算步骤后的局部验证。运行前仍要查看本次会包含哪些 Cell。

## 干净运行全文

点击顶部“干净运行全文”会：

1. 使用新的干净 Python 环境；
2. 按文档顺序和依赖关系运行全部可执行 Cell；
3. 冻结本次源码、依赖、运行时和输出；
4. 成功后在“完整运行历史”中生成不可变记录。

准备比较、封存或交给 Factor／Strategy 时，应使用干净全文运行。只在当前交互环境里成功，不代表文档能从零复现。

## 停止当前运行

长计算运行时，运行图标会变为停止按钮。点击“停止当前运行”可以中断本次计算。

![停止正在运行的长计算](/docs/images/help/zh/research/run-control-02.png)

中断后，本次未完成的下游 Cell 不会获得新结果。已显示的旧输出可能继续保留，并标为待重跑；修正代码后重新执行。

## 重置环境

点击顶部“重置环境”会清除当前交互式 Python 状态。源码仍在文档中，但内存里的变量和临时对象不再可用。重置后从需要的上游 Cell 开始运行，或直接干净运行全文。

以下情况适合重置：

- 当前结果依赖已经删除的临时变量；
- 包导入或运行状态异常；
- 想确认文档是否依赖未记录的交互步骤。

## 常见问题

### 页面显示旧输出和“待重跑”

这是保护机制，不是自动重算失败。它提醒你源码和输出已经不一致。选择正确的运行范围即可。

### 停止后还能封存吗

不能把未成功完成的全文运行封存为成功版本。修正或缩小计算后重新“干净运行全文”。
