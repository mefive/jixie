# 与 Research Agent 协作

Research Agent 可以阅读当前文档和 Cell 状态，帮助补充研究问题、查找 Research SDK、修改 Cell，并在真实运行后解释输出。它的文字和代码都需要用户审查；提案不会因为生成完成就自动运行。

## 提出明确要求

1. 点击右上角的对话图标打开“Research Agent”。
2. 在输入框说明研究对象、区间、频率、变量、想用的方法和判断标准。
3. 如果要修改文档，说明要改哪个 Cell、保留什么内容以及期望输出。
4. 发送后查看“准备数据”“生成提案”等执行阶段；阶段文字表示当前进度，不表示研究结论已经成立。

Agent 不知道精确对象、数据字段或 SDK 时，应先查询当前目录或说明缺口。不要接受把缺失数据静默换成相似指标的结果。

如果原问题没有精确可执行的数据，但存在有明确差异的代理，Agent 会先显示“待确认”卡。回答前普通输入和 Cell 提案会暂停；先比较差异并确认、选择“不使用代理”或填写具体口径，再继续研究。

## 指定 Cell 上下文

点击 Cell 上的回形针，或把 Cell 拖到 Agent 输入框，即可明确指定本轮问题依据的内容。依赖这些 Cell 的上游 Cell 会自动加入，并与显式附加项分开显示。发送后，这些 Cell 的源码和依赖关系会作为本轮不可变快照保留，不会自动沿用到下一轮。

对话里的 Cell 标签可以定位当前 Cell。当前版本变化后，标签会显示“已更新”；Cell 被删除后会显示“已删除”。点击这两种标签可查看发送时的源码快照；若当前 Cell 仍存在，也可以继续定位到当前版本。在移动端定位时，Agent 面板会自动关闭并返回文档。

## 审查 Cell 变更

Agent 提出修改后，右侧会出现变更卡片，目标 Cell 显示内联差异：

- 红色行是准备移除的旧内容，只读；
- 绿色行是新增或修改内容，可以继续编辑；
- 新建、修改和删除 Cell 分别列出；
- 增加和删除的行数只用于定位，不代表修改质量。

![Research Agent 的 Cell 内联差异审核](/docs/images/help/zh/research/agent-collaboration-01.png)

逐项检查数据字段、日期、公式、变量依赖、缺失值和结论措辞。需要小改时，可直接编辑绿色的新版本，不必要求 Agent 再生成一次相同内容。

## 接受、撤销和拒绝

- 点击“接受当前版本”，保存你最终审查和编辑后的版本。
- 点击“撤销本次 Agent 变更”，恢复审核前的 Cell 内容。
- 对还在待审核的提案，可使用拒绝按钮不应用它。

接受只改变源码，不会自动执行 Cell。接受后输出通常会进入“待重跑”状态。

## 运行提案

点击“运行提案影响的 Cells”显式执行此次修改涉及的分支。一次提案可能包含有限次数的修正尝试；每次尝试都会保留状态和结果，不能把失败尝试隐藏成成功。

运行完成后，可以点击“让 Agent 解释本次运行”。解释应引用真实输出、错误或警告。如果提案没有运行，Agent 不能把预计结果写成已经计算的事实。

![已接受并运行的 Agent 变更](/docs/images/help/zh/research/agent-collaboration-02.png)

## 适合和不适合交给 Agent 的工作

适合：补充公式解释、根据已确认目录生成调用、整理重复代码、提出稳健性检查、解释已有输出。

仍需用户决定：研究问题、事前方向、样本选择、是否接受变更、是否运行、如何解读冲突证据，以及是否进入正式 Factor／Strategy 验证。
