# 阅读因子气象卡片

因子气象卡片按月显示统一方法下的费后多空收益，并提供近 3 月、近 12 月、滚动 IC、覆盖率和换手。先确认选中的月份，再阅读其他数字。

## 选择一个历史月份

卡片底部的月份条从左到右排列历史。红色表示当月结果符合预期方向，绿色表示背离预期方向，颜色越深表示费后多空收益幅度越大。

1. 在月份条上点击一个月份。
2. 卡片上方指标会切换到以该月为终点的结果。
3. 横向月份较多时，可以按住月份条左右拖动。
4. 把鼠标停在月份上，可以查看月份、方向对齐费后收益和原始 IC。

![选择历史月份并查看卡片指标](/docs/images/help/zh/factor-weather/factor-weather-history-01.png)

方向对齐只改变展示符号：高值优先因子保持原方向，低值优先因子把符号反转。原始 Rank IC 仍单独显示。

## 四个主要指标

- **选中月**：该月方向对齐后的费后多空收益。
- **近 3 月**：截至选中月最近最多 3 个月的复合费后多空收益。
- **近 12 月**：截至选中月最近最多 12 个月的复合费后多空收益。
- **12 月均值 IC**：截至选中月最近最多 12 期原始 Rank IC 的方向对齐平均。

近 $n$ 月使用复合收益，不是把月收益直接相加：

$$
R_{n}=\prod_{j=1}^{n}(1+r_j)-1
$$

$r_j$ 是每个月方向对齐后的费后多空收益。历史不足 $n$ 个月时，页面使用现有月份。

## 卡片下方明细

- **原始 Rank IC**：当月因子排名与下一月收益排名的相关性，未按预期方向改写。
- **覆盖率**：最终有效样本占候选样本的比例。
- **最高组换手**：最高因子组相对上月更换持仓的比例。
- **样本**：该月参与分析的股票数量。

覆盖率突然下降时，应先检查财务数据可得性、上市时间、风险状态和流动性过滤。高换手意味着实际交易成本和容量更重要。

## 怎样判断顺风和逆风

建议依次检查：

1. 单月方向是否符合预期。
2. 近 3 月与近 12 月是否一致。
3. 12 月均值 IC 是否同步变化。
4. 覆盖率和样本数是否稳定。
5. 换手是否显著上升。
6. 回到不可变因子报告检查长期分组、回撤和保留段。

短期绿色不自动表示因子永久失效，连续红色也不证明未来继续有效。因子可能经历拥挤、风格切换、数据变化或随机波动。

## 因子气象与因子报告的区别

| 因子气象 | 因子研究报告 |
| --- | --- |
| 固定统一月频方法 | 用户明确选择频率、区间和方法 |
| 持续增加完整月份 | 报告保存后不可变 |
| 用于监测近期状态 | 用于检验定义和研究假设 |
| 不创建样本外结论 | 可以冻结并揭示正式保留段 |

不能因为气象卡片近期表现较好，就把同一段月份当作未参与选择的样本外证据。

## 常见问题

### 为什么只到上个月

当前月份还没有结束。页面只写入完整月份，避免用半个月结果和完整月份比较。

### 为什么预置因子不能改方向

预置因子有固定经济定义和预期方向。允许看到结果后反复切换方向会放大数据挑选偏差。

### 为什么近 3 月和三个单月相加不同

近 3 月按净值连乘计算复合收益，月度收益直接相加只是近似。
