# 开始使用因子气象

因子研究用于判断一个定义在固定样本和方法下是否有历史证据；因子气象用于持续观察已经认可的因子最近处于顺风、逆风、减弱还是恢复阶段。它们是两个独立页面，因子气象不会修改已有研究报告。

## 打开页面

1. 登录后点击顶部的“因子气象”。
2. 页面会显示固定方法：月末调仓、行业加市值中性化、十分位等权、仅完整月份。
3. 已经钉住的预置因子和自定义因子会分组显示。
4. 第一次使用时，点击“钉住因子”。

下图中的标记分别是：

1. “因子气象”页面和固定方法。
2. 预置因子与我的因子分组。
3. 每张因子的月度卡片。
4. 新增卡片入口。

![因子气象页面和已钉住因子](/docs/images/help/zh/factor-weather/factor-weather-overview-01.png)

固定方法保证不同卡片可以横向比较。用户不能在这个页面临时改变分组数、中性化或成本后只保留更好看的结果。

## 钉住一个因子

1. 点击右上角“钉住因子”。
2. 在“因子”中选择一个尚未钉住的预置因子或已发布自定义因子。
3. 预置因子会使用系统固定方向。
4. 自定义因子选择“高值优先”或“低值优先”。
5. 核对方向后点击“钉住并回填”。
6. 等待卡片完成月度历史计算。

![选择已发布因子和预期方向](/docs/images/help/zh/factor-weather/factor-weather-pin-01.png)

方向只用于把颜色和收益统一到“符合预期为正”。系统仍保留原始 Rank IC 和原始分组收益，不会修改因子代码。

## 哪些因子可以钉住

- 预置因子可以直接选择，预期方向由产品固定。
- 自定义因子必须先在因子研究页选择批准报告并发布。
- 仍处于草稿状态的自定义因子会被禁用。
- 多因子合成目前不能钉入因子气象。
- 同一个 Factor 不能重复钉住。

钉住时会再次保存 Factor 代码、名称、方向和方法快照。已发布 Factor 本身已经不可修改或删除；需要迭代时，应复制成新的独立草稿后重新研究和发布。

## 等待首次回填

首次钉住后，后台会从可用历史起点计算到最近一个完整月。长窗口因子可能需要几分钟。可以离开页面，计算不会依赖浏览器持续打开。

卡片显示“计算失败”时，先阅读错误内容，再点击“重新计算”。计算过程中不能取消钉住，避免删除仍在写入的数据。

## 取消钉住

卡片完成或失败后，可以选择“取消钉住”。确认后会删除这张卡片和它的月度观测，但不会删除因子本身或不可变研究报告。

取消钉住不是隐藏操作。以后重新钉住时，系统会按当前方法重新生成历史。

## 需要知道

- 因子气象不是实时选股器。
- 页面只展示已经结束的完整月份，不展示本月半成品。
- 单月变红或变绿不能替代研究逻辑、保留段和成本检查。
- 卡片之间采用统一方法，但因子经济含义仍然不同。
