# 为什么回测不等于未来收益

回测回答的是“这套规则在已有历史数据上会得到什么结果”，不是“以后一定能赚多少”。历史结果好看，只是继续检查策略的起点。

## 历史环境不会原样重复

公司经营、市场参与者、交易制度、利率和流动性都会变化。过去有效的关系可能减弱、消失或反转。

产品中的净值曲线和指标只覆盖设置的回测区间。区间之外的情况没有包含在结果中。

## 未来数据

未来数据是指策略在某个历史日期使用了当时还不可能知道的信息。

例如，用公司后来发布的财务数据决定发布前的买入，就会让回测结果失真。策略只能使用每个历史时点当时已经可获得的数据。

常见误解：只要数据是真实历史数据，就不会产生未来数据。实际问题在于数据何时被策略看到。

## 幸存者偏差

幸存者偏差是只用今天仍然存在的股票回看过去，漏掉已经退市或被剔除的股票。

这会让历史股票池看起来比当时实际可投资范围更好。检查长期选股策略时，应关注股票池是否按历史日期变化。

## 过度拟合

过度拟合是反复修改参数，直到规则恰好适合某段历史。

常见表现包括：

- 只改一点日期，结果就大幅变化。
- 参数稍微改变，收益就消失。
- 规则包含很多只为解释历史异常点而增加的条件。
- 在同一段数据上反复试验，再把最好的一次当作结论。

可以保留一段未参与调参的数据，用它检查策略在未见样本中的表现。

## 模拟成交与真实成交不同

真实交易可能遇到：

- 停牌，无法交易。
- 涨跌停，订单无法按预期价格成交。
- 股票 T+1，当天买入后不能当天卖出。
- 整手交易限制。
- 佣金、印花税、滑点和市场冲击。
- 下单、网络和人工操作延迟。

回测已经模拟的项目也只是估算。资金越大、交易越频繁、标的流动性越低，实际差异通常越值得重视。

## 怎样更谨慎地使用结果

1. 使用包含不同市场阶段的较长区间。
2. 核对每笔交易，确认规则按预期执行。
3. 设置合理的滑点、冲击和费用。
4. 小幅改变日期和参数，观察结果是否稳定。
5. 保留未用于调参的样本外区间。
6. 不因为一项指标突出就忽略回撤、成交数和成本。
7. 把回测结果当作历史证据之一，不当作收益承诺。
