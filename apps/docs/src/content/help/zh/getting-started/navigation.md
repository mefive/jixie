# 页面导航

登录后，页面顶部会一直显示主要功能入口。先熟悉这些入口，再按实际需要进入相应页面。

## 打开主要页面

顶部导航从左到右包含以下入口：

| 页面 | 适合用来做什么 |
| --- | --- |
| 回测工作台 | 编写或生成策略，设置回测参数，运行回测并查看结果 |
| 选股看图 | 按条件筛选股票，查看筛选结果和个股行情 |
| 因子研究 | 检查因子的分组表现、收益表现和历史研究报告 |
| 市场 | 查看主要市场指数、市场宽度和市场状态 |
| 估值 | 查看指数估值水平及其历史位置 |
| 今日信号 | 查看已经保存的策略在最新交易日产生的信号 |
| 使用帮助 | 阅读产品操作说明和量化交易基础知识 |

例如，需要筛选股票时：

1. 点击顶部的“选股看图”。
2. 等待页面显示筛选条件。
3. 设置条件后点击页面上的执行按钮。
4. 在结果列表中点击股票代码，进入股票详情页。

## 切换显示语言

页面右上角提供“中”和“EN”两个选项。

1. 点击“中”，页面显示中文。
2. 点击“EN”，页面显示英文。
3. 语言选择会保存在当前浏览器中，下次打开产品时继续使用上次的选择。

帮助中心也使用同一语言设置。切换语言后，文章标题、目录和正文会一起切换。

## 查看当前账号

页面右上角会显示当前登录邮箱。需要退出时：

1. 确认已经保存正在编辑的内容。
2. 点击邮箱右侧的“退出”。
3. 退出后会返回登录页。

> 如果正在回测工作台编辑尚未保存的策略，离开页面前应先保存，避免丢失修改。

## 使用帮助中心

点击顶部的“使用帮助”可以随时打开本手册。

- 左侧目录用于切换文章。
- 文章右侧目录用于跳转到当前文章的某一节。
- 窄屏设备上，点击正文上方的“文档目录”可以展开文章列表。
- 正文底部会显示上一篇和下一篇，便于按顺序阅读。

需要返回产品时，点击帮助中心右上角的“返回产品”。
