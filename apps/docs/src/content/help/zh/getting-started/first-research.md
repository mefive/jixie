# 第一次完成自然语言研究

研究工作台把日常语言问题转换成版本化、可检查的计算规格。你不需要编写 SQL、Python 或 TypeScript。

## 开始研究

1. 打开顶部“研究”。
2. 输入一个包含对象、区间和目标的问题，例如“沪深 300 和中证 500 过去五年的月收益相关吗？”
3. 系统会先在本地目录核对对象与指标，再选择登记过的研究协议。
4. 查看结果卡中的样本数、相关系数、回归、滚动图、诊断和限制。

模型负责理解问题和解释结果；表格、统计值、公式与 Python 示例来自确定性研究协议。缺少数据或方法时，系统会明确报告能力缺口，而不是临时编造字段或 SQL。

## 研究一个股票池

也可以直接描述横截面条件，例如“找最新可得时点 PE TTM 小于 20、按总市值降序的 A 股”。结果会保存完整的 UniverseSpec，包括：

- 数据时点和历史指数成分时点；
- 上市天数、停牌和风险警示处理；
- 指标版本、单位、缺失值、过滤和排序；
- 数据 revision 与各资格阶段的样本数。

点击结果表中的对象会打开统一对象详情页。重新打开研究记录时，可以用同一份 Spec 确定性重跑。

> 统计关系和条件匹配都不是买卖建议。先确认变量定义、时间方向、样本范围和限制。
