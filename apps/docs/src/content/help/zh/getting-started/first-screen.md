# 第一次完成选股

本例筛选市盈率 TTM 低于 15、股息率大于 3% 的股票，并按总市值从高到低排列。完成后，你会得到符合条件的股票列表。

## 开始前

- 已经登录。
- 知道市盈率和股息率只是筛选条件，不表示股票一定适合买入。
- 本例使用固定描述，便于对照页面结果。

## 输入筛选条件

1. 点击顶部的“选股看图”。
2. 等待页面中间出现输入框。
3. 在输入框中填写：`筛选市盈率TTM低于15、股息率大于3%的股票，按总市值从高到低排列`。下图中的 **1** 是输入位置。
4. 按回车键发送。下图中的 **2** 提示可以使用回车键。

![选股看图页面中的筛选条件输入框](/docs/images/help/zh/getting-started/first-screen-01-query.png)

发送后，页面会先处理筛选条件，再显示结果。不要在结果出现前重复发送相同内容。

## 查看筛选结果

结果出现后，按以下顺序检查：

1. 查看结果上方的条件说明。下图中的 **1** 表示本次查询的条件区域。
2. 查看结果表格。下图中的 **2** 是股票列表，可以核对股票代码、名称和各项数值。
3. 需要保留这次结果时，点击右上角的图钉按钮。下图中的 **3** 是该按钮。

![筛选条件说明、股票结果表格和图钉按钮](/docs/images/help/zh/getting-started/first-screen-02-result.png)

如果表格中出现股票行，说明查询已经完成。结果数量会随数据日期和股票指标变化，因此以后再次运行同一句话时，结果可能不同。

## 如何判断结果是否符合要求

至少检查三件事：

1. 每一行的“市盈率TTM”是否低于 15。
2. 每一行的“股息率”是否大于 3%。
3. “总市值”是否按从高到低排列。

点击股票代码可以打开股票详情页，继续查看价格和估值图表。

## 需要知道

- **市盈率 TTM**：当前总市值与最近十二个月净利润的比值。亏损公司可能没有可比较的市盈率。
- **股息率**：股息相对于股价的比例。历史股息率高不代表未来一定继续分红。
- **总市值**：股票价格乘以总股本。按总市值排序只改变显示顺序，不会增加或删除筛选条件。

筛选结果只回答“哪些股票符合这些条件”，不回答“现在是否应该买入”。

## 常见问题

### 没有结果

条件可能过于严格，或者相应数据在当前日期不可用。先删除一个条件再试，例如只保留“市盈率TTM低于15”。

### 结果与预期不同

先查看结果上方的条件说明，确认数值、比较方向和排序没有被误解。还要核对页面显示的数据日期。
