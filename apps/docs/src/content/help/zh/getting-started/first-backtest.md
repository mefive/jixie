# 第一次运行回测

本例检验“每月第一个交易日买入 100 股贵州茅台”在一段历史区间中的表现。你会设置日期和资金，运行回测，并查看收益、风险和交易明细。

## 开始前

- 已经登录。
- 回测只是在历史数据上执行规则，不是未来收益预测。
- 本例用于熟悉操作，不代表推荐贵州茅台或这项交易规则。

## 描述策略

1. 点击顶部的“回测工作台”。
2. 点击“新建”，或打开新的回测页面。
3. 在输入框中填写：`每月第一个交易日买入100股贵州茅台`。下图中的 **1** 是输入位置。
4. 点击发送按钮，或按回车键。下图中的 **2** 是发送按钮。
5. 如果暂时没有明确规则，可以查看输入框下方的例子。下图中的 **3** 是示例区域。

![回测工作台中的策略描述输入框、发送按钮和示例](/docs/images/help/zh/getting-started/first-backtest-01-prompt.png)

等待左侧出现策略说明、中间出现策略代码，并确认顶部的“运行回测”可以点击。系统生成的规则应与原描述一致；如果说明中出现了不同的股票、数量或频率，应先修改描述，不要直接运行。

## 设置回测参数

1. 点击“编辑启动参数”。
2. 在“起始”中选择回测开始日期。下图中的 **1** 是起始日期。
3. 在“结束”中选择回测结束日期。下图中的 **2** 是结束日期。
4. 在“资金”中填写 `100`，表示 100 万元。下图中的 **3** 是资金。
5. 第一次操作先保留“基础滑点”的默认值。下图中的 **4** 是基础滑点。
6. 检查后点击“运行回测”。下图中的 **5** 是运行按钮。

![回测起始日期、结束日期、资金、基础滑点和运行按钮](/docs/images/help/zh/getting-started/first-backtest-02-settings.png)

日期范围必须包含交易日，初始资金也要足以完成策略要求的买入。设置完成后，等待右侧出现结果。

## 查看主要指标

回测完成后：

1. 先看“结果概览”中的指标。下图中的 **1** 是指标区域。
2. 点击“交易明细（1笔）”核对实际成交。下图中的 **2** 是交易明细标签，括号内是成交笔数。
3. 运行日志位于中间下方。下图中的 **3** 是日志区域；运行异常时先查看这里。

![回测结果指标、交易明细和运行日志](/docs/images/help/zh/getting-started/first-backtest-03-metrics.png)

本次截图中的累计收益为 1.05%，成交笔数为 1。这只说明固定历史区间中的计算结果。换一个日期、资金或成本设置，结果会变化。

## 查看净值曲线

1. 在“结果概览”中选择“净值”。下图中的 **1** 是曲线区域。
2. 红线表示策略净值，蓝线表示沪深 300 基准。
3. 点击上方“回撤”可以切换到回撤图。下图中的 **2** 是结果标签区域。

![策略净值曲线、沪深300基准和结果标签](/docs/images/help/zh/getting-started/first-backtest-04-chart.png)

净值曲线向上不表示过程一直盈利。还要同时查看最大回撤、成交笔数和交易明细。

## 如何判断操作成功

以下内容都出现时，说明本次回测已经完成：

- “结果概览”显示累计收益、最大回撤等指标。
- “交易明细”后显示成交笔数。
- “净值”区域出现策略和基准曲线。
- 页面没有显示运行失败。

如果成交笔数为 0，不能只看收益数字。先检查日期范围、资金、股票代码和买入条件是否有机会触发。

## 需要知道

- **回测区间**决定使用哪段历史数据。
- **初始资金**决定策略可用于交易的起始现金。
- **基础滑点**用于模拟下单价格与计算价格之间的偏差。
- **累计收益**是从回测开始到结束的总收益率。
- **最大回撤**是净值从一个阶段高点下降到之后低点的最大幅度。

详细解释见[回测区间、资金和交易成本](/help/basics/backtest-settings)和[收益和风险指标](/help/basics/performance-risk)。

## 常见问题

### 回测长时间没有完成

先继续等待页面状态变化。仍没有结果时，查看日志和页面错误提示，不要连续点击“运行回测”。

### 没有成交

检查所选日期是否包含交易日、初始资金是否足够，以及规则在这段时间内是否会触发。成交笔数为 0 的结果不能用来评价策略收益。

### 修改后结果没有变化

确认已经再次点击“运行回测”，并核对顶部显示的日期范围是否是刚刚设置的范围。
