# 第一次运行预设因子分析

本页使用“盈利收益率(1/PE_TTM)”完成第一次分析。先使用默认设置和“纯探索”，目的是熟悉完整流程，不是根据一次结果作出交易决定。

## 打开预设因子

1. 登录后，点击顶部的“因子研究”。
2. 点击左侧的“因子库”。
3. 在“预设因子”中点击“盈利收益率(1/PE_TTM)”。
4. 确认该行显示选中状态。
5. 等待中间出现“预置因子,代码只读”，右侧出现分析区间和“运行分析”。

![选择盈利收益率预设因子](/docs/images/help/zh/factors/factor-workspace-01.png)

中间的代码用于说明这个预设因子实际怎样计算。第一次使用不需要修改它。需要修改预设因子时，应使用“复制为自定义”，不要把复制和修改放在第一次分析中完成。

如果以前运行过这个因子，右侧会自动显示最近一份报告；第一次使用时会显示“设好频率 / 区间,点‘运行分析’”。

## 提交第一次分析

1. 先查看顶部摘要，确认当前是“月”频、分析区间正确、中性化为“无”。
2. 点击“运行分析”。
3. 在“运行前研究卡”中选择“纯探索”。
4. 阅读提示，确认这次结果不能在看过以后包装成预先假设。
5. 点击“冻结研究卡并运行”。

![在运行前研究卡中选择纯探索](/docs/images/help/zh/factors/factor-research-card-01.png)

“纯探索”适合第一次查看一个因子。“假设验证”要求在运行前写下假设、预期方向和判断标准，适合已经明确要验证什么的研究。

## 等待分析完成

提交后，页面会显示“运行中”和“计算中”。下图中的标记分别是：

1. 当前分析摘要、报告历史和运行状态。
2. 计算状态。页面说明可以刷新或切换因子。
3. 运行日志。

![因子分析运行中的页面状态](/docs/images/help/zh/factors/factor-running-01.png)

分析期间：

1. 不要连续重复点击运行。
2. 可以在中间“日志”中查看调仓日期、行情加载和计算进度。
3. 可以刷新页面，报告已进入“报告历史”。
4. 等待右侧出现“研究口径与可复现性”、分组图和指标。

出现结果后，本次分析已经完成。报告会保存在“报告历史”中。再次修改区间、频率、中性化或其他设置后，需要重新运行，新的报告才会反映修改。

## 如果没有完成

### 长时间停留在运行中

先刷新页面并重新打开“盈利收益率”。如果任务仍在运行，页面会重新连接。不要在原任务完成前重复提交相同内容。

### 页面显示失败

查看“日志”和右侧错误信息。确认区间内有足够数据，且没有把“最少样本数”等设置得过高。修正后再点击重新运行。

### 找不到运行按钮

先在“因子库”中选择一个因子。未选择因子时，右侧不会出现可运行的分析。
