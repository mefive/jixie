# 设置分析范围和样本处理

第一次运行可以保留默认设置。需要比较两份报告时，必须记录并核对所有设置，不能只比较最终收益数字。

## 打开分析设置

1. 在“因子研究”中选择一个因子。
2. 点击右上方的“更多设置”按钮。
3. 等待“分析设置”浮层出现。

下图中的标记分别是：

1. 调仓频率。
2. 分析区间。
3. 中性化方式。
4. “股票池与缺失值”部分。
5. 股票池、样本覆盖和风险状态设置。
6. 异常值处理。

![因子分析中的频率、区间、中性化和样本设置](/docs/images/help/zh/factors/factor-settings-01.png)

## 频率

- **月**：每月比较一次因子和后续收益。第一次分析建议使用月频，结果较容易阅读，换手通常也低于周频。
- **周**：每周比较一次。样本期数更多，但短期波动和换手的影响也更大。

频率改变的不只是图表显示。它还会改变分组日期、前瞻收益区间和换手计算，因此修改后必须重新运行。

## 正式研究范围和排序范围

“研究范围”支持全 A、沪深 300、中证 500 和中证 1000，并按历史日期读取当时指数成分。“排序范围”决定全市场一起排序，还是在申万一级行业内部排序。行业、市值和流动性诊断只拆解主结果，不改变发布判据。详细操作见[设置 Factor 研究范围](/docs/help/factors/evaluation-scope)。

## 区间

“区间”决定使用哪一段历史数据。建议：

1. 使用包含不同市场阶段的多年区间。
2. 不要只因为某个区间结果更好就不断移动起止日期。
3. 比较两个因子时使用相同区间。
4. 核对结果卡中的“数据截止”日期，不要假定数据已经更新到今天。

区间很短时，月频只有少量观察期，单个极端月份可能明显改变结果。

## 中性化

- **无**：直接比较原始因子数值。第一次运行可先选择“无”。
- **市值**：尽量去除股票市值差异对因子排序的影响。
- **市值+行业**：同时控制市值和行业差异。

例如，小市值股票在某段历史中整体表现较好，而一个因子又偏向小市值股票，那么原始结果可能包含市值影响。中性化用于检查去除这些共同差异后，因子关系是否仍然存在。

中性化不是让结果“变得更好”的开关。中性化前后都要保留并比较，不能只保留收益更高的一份。

## 股票池与缺失值

- **最低上市天数**：排除上市时间太短的股票。
- **剔除低流动性**：每期排除成交不活跃的一部分股票。
- **最少样本数**：当期有效股票少于这个数量时，不使用这一期。
- **窗口最低覆盖**：需要历史窗口的因子，要求窗口内有足够数据。
- **剔除 ST / 风险警示**：排除当时处于风险警示状态的股票。
- **剔除退市整理股票**：排除当时处于退市整理状态的股票。

这些设置影响每一期有哪些股票可以参与比较。第一次使用建议保留默认值，不要为了增加样本随意关闭风险状态过滤。

## 异常值处理

少量特别大或特别小的数值可能显著影响统计结果。页面可以分别处理：

- 因子暴露，也就是股票的因子数值。
- 前瞻收益，也就是分组后观察的下一期收益。

“缩尾 1%”会限制两端极端值的影响，但不会把所有波动抹平。“MAD 截尾”使用样本的中位数和偏差识别异常值。比较报告时必须使用相同处理方式。

## 交易成本

页面按单边设置佣金、卖出印花税和滑点。成本主要用于后面的费后多空结果。交易频率越高、最高档换手越高，成本影响通常越明显。

不要把成本全部设为 0 后直接把费前结果当作可实现收益。

## 完成设置

设置完成后：

1. 点击浮层底部的“运行分析”，或者关闭浮层后点击顶部的“运行分析”。
2. 填写运行前研究卡。
3. 等待新报告完成。
4. 在报告顶部重新核对频率、区间和中性化。
5. 在“研究口径与可复现性”中核对股票池、异常值和成本口径。
