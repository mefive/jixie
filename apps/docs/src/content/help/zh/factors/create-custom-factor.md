# 新建和编辑自定义因子

自定义因子把每只股票在每个比较日期的数据转换成一个数值。可以向左侧的 Agent 描述计算方法，也可以直接在中间编辑代码。

## 开始前

先明确因子要计算什么。至少写清楚：

- 使用哪个字段；
- 数值越大代表什么；
- 数据缺失或不能计算时怎样处理。

本页使用“账面市值比”作为例子。产品中的 `pb` 是市净率，因此账面市值比写成：

$$
\text{账面市值比}=\frac{1}{\text{市净率}}
$$

这里不需要推导公式。只要知道市净率有效且大于 0 时计算倒数，其他情况返回空值。

## 打开新建页面

如果已经在研究工作台封存了一个包含明确时点信号的成功版本，也可以从该快照直接创建草稿。LLM 会把自由研究
重写成受约束的 Factor SDK 代码，Factor 编译器负责拦截无效定义。左侧来源卡片会显示原研究版本、提炼摘要和
待验证项；点击图标可回看原快照。你仍需逐行检查代码并完成 FactorReport、Holdout、成本和容量验证。

1. 打开顶部的“因子研究”。
2. 点击左侧的“新建”。
3. 选择研究方式，填写显示名称和创建后不可修改的唯一 key。
4. 确认创建后，在左下方输入计算要求，或者直接点击中间代码编辑器。

下图中的标记分别是：

1. “新建”按钮。
2. 已创建并自动保存的新因子。
3. 给 Agent 输入要求的位置。
4. 因子代码编辑器。
5. “运行分析”按钮。

![自定义因子的新建页面](/docs/images/help/zh/factors/factor-custom-new-01.png)

使用 Agent 时，应描述实际计算规则。例如：

> 创建账面市值比因子。市净率大于 0 时返回 1 除以市净率，否则返回空值。

Agent 写完代码后仍要逐行检查。它生成的是待确认代码，不是已经验证有效的因子。

## 直接编辑代码

一个可以运行的因子至少包含名称和 `compute` 计算函数：

```ts
export default defineFactor({
  name: '账面市值比（自定义）',
  compute: (bar) => (bar.pb && bar.pb > 0 ? 1 / bar.pb : null),
});
```

这段代码的含义是：

- `name` 是页面上显示的名称，可以使用中文。
- `compute` 对当前股票和当前日期的数据计算因子值。
- `bar.pb` 是市净率。
- 市净率缺失、等于 0 或小于 0 时返回 `null`，该股票在本期没有有效因子值。

下图中的标记分别是：

1. 当前自定义因子的名称。
2. 可以继续向 Agent 提出修改要求的位置。
3. 当前代码。
4. 使用当前代码运行分析。

![编辑完成的账面市值比因子代码](/docs/images/help/zh/factors/factor-custom-edited-01.png)

不要为了让所有股票都有数值而把不能计算的情况写成 `0`。零是一个真实数值，会参与排序；`null` 才表示本期没有可用值。

## 使用财务历史字段

自定义因子可以读取按公告日对齐的 ROE 和毛利率历史。`grossprofitMargin` 的单位是百分比，例如 `35` 表示毛利率 35%，不是 `0.35`。

历史字段遵守时点规则：在日期 $t$ 只能使用公告日不晚于 $t$ 的最新报告。报告发布前的交易日不会提前看到数据，首份可用报告之前返回 `null`。财务历史表现为公告日发生变化的阶梯序列，不是每天重新计算的新财务报表。

需要研究毛利率稳定性时，应先写清窗口和缺失值要求。例如使用最近 504 个交易日的有效毛利率计算波动，并在覆盖不足时返回 `null`。不要把尚未公告的年报或当前网页上看到的最新毛利率回填到历史日期。

## 运行分析并保存当前代码

1. 检查右上方的频率、日期区间和中性化设置。
2. 点击“运行分析”。
3. 在“运行前研究卡”中选择“纯探索”或填写预先假设。
4. 点击“冻结研究卡并运行”。
5. 等待右侧出现研究口径、分组收益和指标。

Factor 在新建确认时就已持久化，草稿编辑会自动保存。提交分析前还会等待当前代码保存完成；分析结束后刷新页面，名称、key、代码和报告仍然存在。

也可以在对话中要求 Agent 为一个明确候选运行探索分析。它会创建同样的不可变报告，但不能启动或揭示正式保留段。具体操作见[让因子 Agent 运行探索分析](/docs/help/factors/agent-explore-analysis)。

2. 本次分析的频率、日期和设置摘要。
3. 研究口径与可复现性。

## 修改后怎样确认

修改代码后应重新运行分析。旧报告仍然对应旧代码，不能用它判断新代码的结果。

建议按以下顺序检查：

1. 因子名称和公式是否一致。
2. 缺失值和异常值是否按预期返回 `null`。
3. 高因子值和低因子值的含义是否清楚。
4. 日志中是否有计算错误。
5. 分组、Rank IC、换手和样本数是否符合预期。

一次分析只说明这段历史数据中的关系。它不证明计算方法有因果关系，也不保证未来收益。

## 常见问题

### 点击运行后显示代码错误

先查看中间日志。常见原因是字段名称错误、括号缺失、没有返回数值或 `null`。修正代码后重新运行。

### 因子值太少

检查所用字段在当前日期区间是否有数据，以及条件是否过严。不要用任意数值填补本来不能计算的股票。

### 修改代码后右侧还是旧结果

旧报告不会自动重算。点击“运行分析”并完成一次新分析。

### Agent 已经写出代码，还需要检查吗

需要。重点核对字段、方向、缺失值和单位，再通过真实分析确认代码可以执行。
