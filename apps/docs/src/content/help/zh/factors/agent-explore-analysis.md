# 让因子 Agent 运行分析

编辑自定义因子时，可以让 Agent 对当前代码或明确候选运行分析。说明日期、频率、股票池或资产、预测周期和需要的设置即可。代码、参数和结果会保存为可打开的因子报告。

例如：

> 用当前盈利质量因子，按月分析 2020-01-01 至 2025-12-31，使用市值中性化。解释覆盖、Rank IC、换手和费后结果。

系统不会自动划出受保护日期，也不要求填写分析设置。相同任务运行中会复用；完成后可再次运行。

## 核对结果

1. 从保留报告打开 Agent 返回的报告。
2. 核对代码、日期、数据截止日、样本和成本。
3. 查看 IC、分组、换手和费后结果。
4. 如果 Agent 同时提出新代码，确认报告实际计算了哪个候选。

Agent 可以分析，但发布版本仍由用户在页面明确发起。一份历史结果不能证明未来有效；反复修改后应自行检查过拟合风险。

额外读取和计算已有结果可以使用[嵌入式分析](/docs/help/research/embedded-analysis)。
