# 因子研究能回答什么

因子是每个比较日期给每只股票计算的一个数值。这个数值可以来自价格、成交、估值或财务数据。因子研究把股票按数值高低分组，再观察各组之后的收益是否存在持续差异。

它研究的是一组股票的历史规律，不是预测某一只股票下一天一定上涨或下跌。

## 用盈利收益率理解因子

“盈利收益率(1/PE_TTM)”可以近似理解为市盈率的倒数：

> 盈利收益率 = 最近十二个月盈利 ÷ 股票总市值

例如，两家公司盈利相同，市值较低的公司盈利收益率较高。页面中的预设因子只对市盈率为正的股票计算这个数值。

研究时，系统会在每个调仓日期完成以下操作：

1. 给当时符合条件的股票计算盈利收益率。
2. 按数值从低到高排序。
3. 把股票分成 D1 至 D10 十组。
4. 观察各组下一期的收益。
5. 在多个历史月份重复计算，再汇总结果。

如果 D1 到 D10 的后续收益大致逐级上升，表示在这段历史样本中，高盈利收益率股票的后续收益整体更高。这个结果只能说明历史关系，不能证明盈利收益率是收益差异的唯一原因。

## 页面可以帮助检查什么

因子研究主要帮助检查：

- **方向**：因子数值较高的股票，之后的收益整体更高还是更低。
- **分组差异**：高分组和低分组之间是否有明显差异。
- **稳定性**：这种关系是否在多数月份都保持同一方向。
- **交易代价**：换手和交易成本是否会明显降低结果。
- **样本口径**：股票经过上市时间、流动性和风险状态过滤后，还剩多少有效样本。

## 因子研究不能说明什么

一次结果好看，不能直接说明：

- 未来仍会保持相同收益。
- 任意一只高分股票都会上涨。
- 忽略成本后仍能获得页面中的收益。
- 多次更换区间和参数后挑出的最好结果是可靠规律。
- 两个数据同时变化，就一定存在因果关系。

先完成一次预设因子分析，再逐项理解设置和指标。不要从编写自定义因子代码开始。
