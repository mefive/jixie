# 保留报告和结果已过期

每个因子保留本人最近提交的分析；已发布或归档版本额外保留发布时绑定的报告。仍在排队或运行的任务会保留到结束。相同分析正在执行时复用任务，完成后可以重新运行。

新分析替代旧的普通结果，即使新分析失败也不会恢复旧报告。被清理报告的链接和 Python `results.factor_report(report_id)` 会报“报告不存在”，相关任务与日志一并删除。需要长期保留一个版本及其结果时，应在成功分析后发布该版本。

## 打开报告

1. 在因子工作台选择因子。
2. 页面默认打开最近分析；若存在多份保留报告，点击“保留报告”切换；“发布绑定”标记指出该版本固定的报告。
3. 核对日期、频率、分析方式、代码与数据截止日。
4. 查看结果和日志。复制页面地址可再次打开仍保留的报告。

报告只向所属用户开放。已完成结果可以直接读取，无需额外揭示。

## 处理过期结果

修改代码或参数不会重新计算旧报告。页面提示结果已过期时，可以按当前设置重新运行，或恢复报告当时的参数。比较不同已发布版本时使用相同的数据口径、成本和样本范围，避免只记录好看的数字。

## 报告问答

问题可以附带一份本人已完成的报告，也可以只问定义。Agent 获得报告摘要；需要额外计算时可使用[嵌入式分析](/docs/help/research/embedded-analysis)。Agent 应明确缺失的信息，不能把解释当成新的因子检验。

## 发布版本

发布时固定当前代码与匹配的成功报告。已发布版本不可编辑；修改需要复制为新的草稿。旧策略继续引用原版本 key。参见[发布因子版本](/docs/help/factors/publish-factor)。
