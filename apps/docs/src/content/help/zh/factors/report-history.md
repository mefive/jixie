# 报告历史和结果已过期

每次因子分析都会生成一份独立报告。报告历史用于保留当时使用的因子代码、分析参数、运行状态和结果，方便以后重新打开和比较。

它不是“最近一次结果”的临时缓存。同一组参数在上一份报告完成后再次运行，也会形成一条新的历史记录，不会覆盖旧报告。

## 打开报告历史

1. 在因子页面右上方找到“报告历史”。
2. 点击按钮打开列表。
3. 找到需要查看的创建时间和参数。
4. 点击记录，页面会恢复该报告的分析参数和结果。

报告记录可能显示以下状态：

- **运行中**：计算尚未结束。刷新页面后仍可通过这条记录继续查看状态。
- **已完成**：报告结果可以打开。
- **失败**：计算没有完成，错误记录仍会保留。
- **已中断**：服务重启或异常退出后，原任务不能继续。可以按相同参数重新运行。

记录还会标明“探索”“Holdout · 未揭示”“Holdout · 已揭示”或“历史”。其中 Holdout 是正式保留段报告，详见[正式保留段和样本外结果](/help/factors/holdout-results)。

下图中的标记分别是：

1. 已计算但尚未揭示的正式保留段报告。
2. 生成它的探索报告。

![报告历史中的探索报告和未揭示保留段报告](/docs/images/help/zh/factors/factor-holdout-history-01.png)

列表中的日期区间、中性化方式和 Rank IC 可以帮助定位报告。比较结果前仍应打开报告，核对完整研究口径。

## 打开历史报告会恢复什么

打开一份报告时，页面会恢复这次运行保存的分析设置，包括：

- 月频或周频。
- 起始日期和结束日期。
- 无中性化、市值中性化或市值加行业中性化。
- 股票池、缺失值、异常值和交易成本等版本化设置。
- 当次运行使用的因子代码快照。

报告中的代码 SHA-256 是代码内容的摘要。两份报告的摘要不同，表示计算代码不同。

历史报告保存的是当次计算输入和结果，但当前数据版本标识尚未完整接入。因此不要把它理解成“无论底层行情以后怎样修订，都能逐位重算出完全相同数字”。

## 为什么出现“当前报告仍基于旧参数”

打开报告后，如果修改分析参数但还没有重新运行，页面会继续显示旧报告，并出现黄色提示。

下图中的标记分别是：

1. 当前草稿已改为市值中性化。
2. “重新运行”会使用新草稿生成新报告。
3. 黄色提示说明屏幕上的结果仍来自旧参数。

![修改参数后当前报告显示为已过期](/docs/images/help/zh/factors/factor-report-outdated-01.png)

“已过期”在这里不是说历史报告失效，也不是说结果被删除。它只表示：

> 当前编辑器或分析参数已经与屏幕上的报告不同。

此时有三种处理方法：

1. 想保留修改并得到新结果：点击“重新运行”，填写研究卡并等待新报告。
2. 不想保留修改：重新打开当前历史报告，恢复它保存的参数。
3. 想比较两种设置：先运行新报告，再从报告历史分别打开两份结果。

修改自定义因子代码时也会出现类似提示。旧报告继续保存当时的代码快照，不会因为编辑器代码变化而消失。

## 正确比较两份报告

先确认两份报告只改变了你打算比较的项目。例如比较中性化方式时，应保持以下内容一致：

- 因子代码。
- 频率和日期区间。
- 股票池和样本处理。
- 交易成本。
- 研究卡中的预期方向和主要标准。

然后依次比较分组顺序、Rank IC、ICIR、换手、费后结果和最大回撤。不要只因为其中一份的单个数字更高，就忽略其他输入也发生了变化。

同样参数重复运行会增加报告条数，但不一定增加“探索变体”数量。探索变体的计数方法见[运行前研究卡和探索变体](/help/factors/research-card)。

## 需要知道

- 报告历史是研究记录，不是交易建议。
- 失败和中断记录不会自动变成成功报告。
- 当前没有单独删除某一份报告的入口。
- 重新运行会新增报告，不会覆盖选中的历史报告。
- 打开旧报告时，日期和具体数字可能与当前最新报告不同。
