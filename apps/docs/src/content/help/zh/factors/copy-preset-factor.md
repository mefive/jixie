# 复制预设因子

预设因子的代码只能查看，不能直接修改。需要调整计算方法时，先把它复制成自定义因子，再编辑副本。

## 开始前

- 已登录产品。
- 已打开顶部的“因子研究”。
- 已经知道要从哪个预设因子开始。

复制只创建一份可以编辑的代码副本，不会修改原来的预设因子。

## 选择并复制预设因子

1. 点击左侧的“因子库”。
2. 在“预设因子”中选择一个因子。下图使用“盈利收益率(1/PE_TTM)”。
3. 确认中间显示“预置因子,代码只读”。
4. 先阅读代码，确认它是要修改的计算方法。
5. 点击“复制为自定义”。

下图中的标记分别是：

1. 因子库入口。
2. 当前选中的预设因子。
3. 只读提示。
4. “复制为自定义”按钮。
5. 预设因子的计算代码。

![选择并复制只读的预设因子](/docs/images/help/zh/factors/factor-custom-copy-01.png)

## 确认复制结果

复制完成后，页面会自动打开新副本。下图中的标记分别是：

1. 页面显示“自定义因子”。
2. 左侧“自定义因子”区域中的新副本。
3. 复制时自动建议、创建后不可修改的 Factor key。
4. 可以编辑的因子代码。

![复制完成后的自定义因子副本](/docs/images/help/zh/factors/factor-custom-copy-02.png)

此时需要知道：

- 副本与预设因子是两个独立因子，修改副本不会改变预设因子。
- 复制的是计算代码，不是原因子的历史报告。副本需要单独运行分析。
- 新副本已经有独立的固定 key，但仍是草稿，发布前不能在策略中引用。
- 可以先修改名称和代码，确认计算方法后再运行分析。

## 接下来怎么做

1. 在中间编辑代码。
2. 点击“运行分析”，使用当前代码生成一份因子报告。
3. 检查代码和报告后，选择批准报告发布 Factor。
4. 发布后可以在策略编辑器的补全列表中选择它；发布后不可再修改。

## 常见问题

### 找不到“复制为自定义”

确认当前选中的是“预设因子”。已经是自定义因子时，不会显示这个按钮。

### 复制后为什么没有原来的报告

报告属于原来的因子和当时的代码。副本是新的因子，需要重新运行分析。

### 可以复制同一个预设因子多次吗

可以。每个副本相互独立，建议把名称改成能够说明差异的文字，避免以后选错。
