# 新建和编辑多因子合成

多因子合成把 2～5 个已经存在的因子合成一个新的研究对象。它适合回答“几项不同信息放在一起后，历史关系是否更稳定”，不代表系统已经生成一套可以直接交易的策略。

## 开始前

先分别查看准备使用的单因子报告，并打开“因子相关性矩阵”。如果两个因子长期高度相关，它们可能重复表达同一类信息；把它们放在一起不一定增加有效信息。

创建前记录：

- 每个因子的经济含义；
- 数值越大还是越小代表预期方向；
- 单因子在探索样本中的表现和成本；
- 因子之间是否明显重复。

## 创建合成

1. 登录后打开“因子研究”。
2. 点击左侧“因子库”。
3. 点击“新建多因子合成”。
4. 填写名称和不可修改的策略代码。
5. 选择“股票横截面”或“Panel 横截面”研究方式。
6. 选择 Rank 排名或 Z-score 作为截面标准化方法。
7. 选择 2～5 个同一研究方式的成分因子。
8. 为每个成分选择正向或负向，然后点击“保存”。

下图中的标记分别是：

1. 因子库和多因子合成列表。
2. 当前名称、标准化方法和等权规则。
3. 成分因子及其方向。
4. 共同股票池和历史冻结提示。
5. 使用当前定义运行分析。

## 正向和负向

- **正向**：数值越大，合成后的得分越高。例如盈利收益率较高通常按正向处理。
- **负向**：数值越小，合成后的得分越高。系统会先把该成分方向反转，再参与平均。

方向必须在看到合成结果前确定。不要因为第一次结果不好，就把方向反过来再把同一段样本当作独立证据。

## 标准化和等权

不同因子的原始单位可能完全不同，不能直接相加。系统会在每个比较日期先对每个成分做截面标准化，再对齐方向并等权平均：

$$
C_{i,t}=\frac{1}{K}\sum_{k=1}^{K}s_k z_{i,k,t}
$$

其中：

- $C_{i,t}$ 是股票 $i$ 在日期 $t$ 的合成得分；
- $K$ 是成分数量；
- $z_{i,k,t}$ 是第 $k$ 个成分标准化后的数值；
- $s_k$ 为正向时取 $1$，负向时取 $-1$。

V1 只提供等权。这样做是为了先建立简单、可复查的基准，避免在同一段探索数据上根据 IC 反复调整权重。

## 共同研究截面

股票横截面每个日期只保留所有成分都有有效值的股票；Panel 横截面则只保留共同月末所有成分都有值的 ETF。只要一个成分缺失，该标的当期就不会进入合成截面。

因此增加成分不一定增加信息，也可能显著减少样本。运行后必须在研究口径中检查每个成分的覆盖量和最终共同样本量。

## 编辑和删除

- 点击合成定义右上角的编辑按钮，可以修改名称、标准化方法、成分和方向。
- 修改只影响下一次分析，已有历史报告仍保留当时冻结的定义和成分代码。
- 删除合成不会删除历史报告，但不能再用被删除的定义启动新分析。

## 需要知道

- 股票横截面合成当前只用于因子研究，不能直接作为策略代码中的一个 Factor key。
- Panel 合成完成 Holdout 且全部成分均已发布后，可以发布并进入策略 Lab；发布后定义不可修改。
- 合成结果仍需要研究卡、探索样本、保留段和成本检查。
- 成分越多不代表结果越好。
- 低相关不等于一定互补，等权也不等于已经完成组合优化。
