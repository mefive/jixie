# 设置 Factor key

Factor key 是策略代码引用因子时使用的唯一英文索引。它不是页面上的显示名称；新建 Factor 时确定，之后不能修改。

## 开始前

建议先完成以下操作：

1. 想好能长期表达研究含义的英文索引。
2. 确认它不是临时实验编号或显示名称的机械翻译。
3. 如果是修改已发布 Factor，先使用“复制”，再为独立草稿采用页面建议的 `_vN` key。

## 新建时填写 key

1. 在因子页选择“新建”。
2. 选择研究方式。
3. 填写允许中文或英文的显示名称。
4. 填写唯一 key，然后确认创建。

标识名称只能使用小写英文字母、数字和下划线，必须以英文字母开头，最多 32 个字符。例如：

```text
help_book_to_market
```

创建成功后，页面显示的完整 key 就是策略引用值：

```text
help_book_to_market
```

产品不添加 `custom:` 或发布版本前缀。key 不能与自己的其他 Factor 或系统内置 key 重复；冲突时创建会失败，需要明确换一个 key。

## 显示名称和 Factor key 的区别

| 项目 | 示例 | 是否可以修改 |
| --- | --- | --- |
| 因子显示名称 | 账面市值比（自定义） | 可以 |
| Factor key | `help_book_to_market` | 创建后不可以 |

显示名称用于页面阅读，可以使用中文并允许重名。Factor key 用于代码引用，需要长期保持稳定。

草稿可以修改代码并重新分析。Factor 发布后名称、代码和研究定义全部不可修改；需要迭代时使用“复制”，得到独立的新草稿和建议的 `_v2`、`_v3` key。

## 命名建议

- 使用能够说明计算含义的名称，如 `book_to_market`。
- 不要把日期、临时实验编号或“最终版”写进长期标识。
- 不要只写 `factor1`、`test` 等以后难以识别的名称。
- 创建前再次检查拼写，因为之后不能修改。

## 常见问题

### 创建按钮不可用

检查名称和 key 是否已填写、key 是否只使用允许字符、是否以英文字母开头，以及长度是否超过 32 个字符。

### 创建后能删除因子吗

草稿可以删除。已发布 Factor 不可删除，只能归档；归档后不会出现在新策略的补全列表中，已有部署仍按冻结依赖运行。

### 改因子显示名称会影响策略吗

不会。策略使用 Factor key，不使用页面显示名称。
