# 查看多因子合成报告

多因子合成使用与所选研究方式相同的分析管道。阅读时先确认被冻结的成分和共同截面，再查看股票分组结果或 Panel 排序、换手和费后结果。

## 打开报告

1. 在因子库中选择一个多因子合成。
2. 点击“运行分析”。
3. 在看到指标前完成研究卡。
4. 等待报告完成。
5. 以后可以从报告历史重新打开同一份不可变报告。

下图中的标记分别是：

1. 本次使用的合成定义。
2. 报告样本和方向摘要。
3. 冻结的方法、成分数量、标准化和共同样本。
4. Rank IC、收益、回撤和换手等指标。

![多因子合成的真实分析报告](/docs/images/help/zh/factors/factor-composite-report-01.png)

## 先检查研究口径

报告方法卡应显示：

- 口径版本；
- 成分数量和名称；
- 每个成分的正负方向；
- Rank 或 Z-score 标准化；
- 等权规则；
- 每个成分的覆盖量和最终共同样本量；
- 股票池、中性化、异常值、成本和数据截止日。

如果共同样本比单因子样本小很多，先判断是否由某个成分缺失过多造成。样本变化本身可能改变分组收益和 IC，不能把全部差异都归因于“组合更好”。

## 与成分 Factor 比较

比较时保持频率、日期、股票池、中性化和成本一致。至少并列查看：

- 合成与每个成分的 Rank IC 均值；
- IC 正值比例和 ICIR；
- 最高组换手；
- 费前和费后多空收益；
- 最大回撤；
- 有效股票数量。

合成的收益更高但换手、回撤或样本损失也明显增加时，不能只保留收益结论。

## 历史报告不会被编辑覆盖

报告保存了当时的合成定义和每个成分的代码快照。之后修改自定义成分或合成定义，旧报告仍按原快照显示；再次运行会新增报告。

这也是比较定义变体时应从报告历史分别打开结果，而不是只看当前编辑状态的原因。

## 保留段仍由用户决定

合成探索结果不会自动启动或揭示保留段。只有在探索前已经写下假设、方向和主要标准，并且没有反复调整定义后，才适合考虑一次正式保留段验证。

Agent 也不能替用户启动保留段、揭示结果或把合成部署成策略。

Panel 报告还要核对资产类别内／类别间证据和每只 ETF 的上市覆盖。它的 Top／Bottom 诊断组合不等于策略 Lab 的真实 ETF 多头回测。

## 不能怎样使用

- 不要把低相关直接解释为风险已经分散。
- 不要根据同一探索样本反复增删成分。
- 不要只保留表现最好的一组定义。
- 不要把研究组合当作已经包含仓位、交易成本和执行规则的实盘策略。
