# 发布因子版本

发布把当前因子代码和一份匹配的成功分析报告固定为不可变版本，供策略按稳定 key 引用。报告的参数、样本范围和结果一起保留。

## 发布条件

- 当前定义是本人的草稿。
- 选择的是本人、同一因子的一份成功报告。
- 报告与当前代码、分析类型、语言和运行时一致。
- 所用输入满足当前分析类型的数据要求；受控商品研究模板仍不能发布。

平台不要求收益为正或统计显著。发布表示固定一个版本，不代表系统认可其投资价值。

## 操作

1. 检查源码，选定日期和参数，运行分析。
2. 阅读报告，确认它对应当前代码。
3. 点击“发布版本”，核对 key 与报告后确认。
4. 在策略中使用这个确切的因子 key。

发布同时完成固定代码与关联报告，无需单独封存操作。

## 修改与归档

已发布版本不可编辑或覆盖。复制为新的草稿，修改、分析后再发布新 key。发布新版本不会替换旧策略引用。归档用于停止新使用，不会改写已经固定的代码和报告。
