# 发布 Factor 并用于策略

发布把一份已经完成研究的 Factor 锁定为策略可以引用的版本。发布不是“保存草稿”，也不表示 Factor 已经证明未来有效。

## 发布前检查

确认以下内容：

- 当前页面选中的是准备发布的 Factor；
- 报告状态为完成，且报告使用当前代码和当前研究参数；
- Factor key 拼写正确；
- 研究卡、正式保留段和主要判据已经按计划完成；
- 报告的数据截止、适用范围、方向和成本口径已经核对。

代码或参数改动后，页面会提示报告已过期。此时必须重新运行研究，不能用旧报告批准新定义。

## 执行发布

1. 打开准备批准的报告。
2. 滚动到“发布与策略引用”。
3. 核对报告编号和代码 hash。
4. 点击“发布”。
5. 在确认框中再次核对 Factor key，然后确认。

下图中的标记分别是：

1. 发布状态和说明。
2. 报告编号与代码 hash。
3. “发布”按钮。

![Factor 报告中的发布与策略引用区域](/docs/images/help/zh/factors/publish-factor-01.png)

## 发布后会锁定什么

发布后，Factor 的名称、key、代码、研究类型和批准报告都不能修改。策略引用时会同时冻结 Factor ID、key、代码 hash 和批准报告，因此后来打开历史回测仍能确认它实际使用了哪一份定义。

需要修改时点击“复制”。系统会创建独立草稿，并建议 `_v2`、`_v3` 等新 key；新草稿不继承发布状态、批准报告或策略引用。

## 从报告进入策略 Lab

发布成功后：

1. 点击“用于策略 Lab”。
2. 等待回测工作台打开。
3. 核对预填代码中的 Factor key、研究资产和调仓方式。
4. 运行回测。
5. 在结果中的“本次回测使用的因子”核对 Factor ID 和代码 hash 已冻结。

![已发布 Factor 的状态、策略入口和冻结血缘](/docs/images/help/zh/factors/publish-factor-02.png)

研究报告中的多空诊断收益不等于策略回测收益。策略结果还包含实际持仓、现金、成交约束、费用和调仓规则。

## 归档

已发布 Factor 不能删除，只能归档。归档后不会出现在新策略的补全列表中；已经保存的历史回测和部署仍保留原来的冻结记录。
