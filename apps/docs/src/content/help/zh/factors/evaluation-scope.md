# 设置 Factor 研究范围

股票横截面 Factor 可以选择正式研究范围、排序范围和诊断切片。三者回答的问题不同，不能把某个切片中较好的结果当成整份报告的结论。

## 打开范围设置

1. 在“因子研究”中选择“股票横截面因子”。
2. 点击右上方“更多设置”。
3. 找到“研究范围”“排序范围”和“诊断切片（不改变主结果）”。
4. 完成选择后运行分析；范围变更会生成新报告。

下图中的标记分别是：

1. 研究范围。
2. 排序范围。
3. 诊断切片。

![股票横截面 Factor 的研究范围和诊断设置](/docs/images/help/zh/factors/evaluation-scope-01.png)

## 研究范围

页面支持全 A 股、沪深 300、中证 500 和中证 1000。

选择指数时，系统使用各历史日期当时的指数成分，而不是用今天的成分回填整个历史。这样可以避免把后来才进入指数的股票提前放进样本。

改变研究范围会改变研究假设、每期样本和尝试次数。如果准备把某个 Factor 用于沪深 300 策略，应单独运行沪深 300 报告，而不是从全 A 报告中只挑沪深 300 行查看。

## 排序范围

- **全局排序**：把当期全部有效股票放在一起比较。
- **申万一级行业内排序**：先在每个历史行业内部比较，再把行业内位置用于全体分析。

行业内排序适合检查一个 Factor 是否只是在偏向某些行业。它不是“市值+行业中性化”的另一种名称：排序范围决定股票和谁比较，中性化则尝试控制共同暴露，两项需要分别记录。

## 诊断切片

行业、市值分层和流动性分层用于拆开主结果，查看关系是否集中在少数区域。诊断区会显示每个切片的样本、覆盖和 Rank IC 等信息。

![Factor 报告中的正式范围和诊断切片](/docs/images/help/zh/factors/evaluation-scope-02.png)

诊断切片不改变主报告指标，也不会单独产生发布资格。若只在某个行业有效，应先写出新的适用范围和判据，再按该范围重新研究，而不是直接发布原报告。

## 比较报告时检查

1. 研究范围是否相同。
2. 是否都使用历史时点成分。
3. 排序范围是否相同。
4. 中性化、异常值和成本设置是否相同。
5. 诊断差异是否有足够样本，而不是来自少数月份。
