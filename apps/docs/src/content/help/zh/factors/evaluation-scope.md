# 设置 Factor 研究范围

> 标为“历史中文界面示例”的图保留当时的结果或状态，数值未重新计算。历史图片可能包含已退役行业控件；当前操作请以本文步骤为准。

股票横截面 Factor 可以选择正式研究范围和诊断切片。两者回答的问题不同，不能把某个切片中较好的结果当成整份报告的结论。

## 打开范围设置

1. 在“因子研究”中选择“股票横截面因子”。
2. 点击右上方“更多设置”。
3. 找到“研究范围”和“诊断切片（不改变主结果）”。
4. 完成选择后运行分析；范围变更会生成新报告。

下图中的标记分别是：

1. 研究范围。
2. 历史排序范围（当前已固定为全局）。
3. 诊断切片。

![历史中文界面示例：股票横截面 Factor 的研究范围和诊断设置](/docs/images/help/zh/factors/evaluation-scope-01.png)

## 研究范围

页面支持全 A 股、沪深 300、中证 500 和中证 1000。

选择指数时，系统使用各历史日期当时的指数成分，而不是用今天的成分回填整个历史。这样可以避免把后来才进入指数的股票提前放进样本。

改变研究范围会改变研究假设、每期样本和尝试次数。如果准备把某个 Factor 用于沪深 300 策略，应单独运行沪深 300 报告，而不是从全 A 报告中只挑沪深 300 行查看。

## 排序方式

当期有效股票统一全局排序。申万行业数据、行业内排名和行业筛选已移除，旧参数会明确报错。

## 诊断切片

市值分层和流动性分层用于拆开主结果，查看关系是否集中在少数区域。诊断区会显示每个切片的样本、覆盖和 Rank IC 等信息。

![历史中文界面示例：Factor 报告中的正式范围和诊断切片](/docs/images/help/zh/factors/evaluation-scope-02.png)

诊断切片不改变主报告指标，也不会单独产生发布资格。若只在某个规模或流动性切片有效，应先写出新的适用范围和判据，再按该范围重新研究，而不是直接发布原报告。

## 比较报告时检查

1. 研究范围是否相同。
2. 是否都使用历史时点成分。
3. 是否都使用全局排序。
4. 中性化、异常值和成本设置是否相同。
5. 诊断差异是否有足够样本，而不是来自少数月份。
