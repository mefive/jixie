# 查看回测结果

回测完成后，不要只看收益率。先确认区间和成交是否有效，再一起查看收益、风险、成本和净值变化。

## 结果区域

下图中的标记分别是：

1. 主要指标。
2. 净值或回撤图。
3. 交易明细入口，括号中是成交笔数。
4. 本次运行的日志。

![回测主要指标、净值图、交易明细和日志](/docs/images/help/zh/backtesting/results-overview-01.png)

## 建议的阅读顺序

1. 确认顶部日期、资金和策略名称。
2. 查看“成交笔数”，确认规则是否实际触发。
3. 查看累计收益和年化收益。
4. 查看最大回撤和 Sharpe。
5. 查看超额收益、信息比率和基准曲线。
6. 查看显性费用、滑点损耗和换手率。
7. 打开交易明细核对实际成交。

成交笔数为 0 时，收益数字通常不能用于评价交易规则。先检查条件是否触发、资金是否足够和数据是否可用。

## 主要收益指标

- **累计收益**：从起始到结束的账户总收益率。
- **年化收益**：把区间收益换算为年度口径，便于比较不同时长的结果。
- **超额收益**：策略收益相对所选基准的差异。
- **期末权益**：回测结束时账户的总价值。

年化收益不是下一年的收益预测。短区间的年化结果尤其容易被放大。

## 主要风险和辅助指标

- **最大回撤**：净值从阶段高点到之后低点的最大跌幅。
- **Sharpe**：单位波动对应的收益，不能替代对回撤和交易次数的检查。
- **信息比率**：相对基准的超额收益与跟踪波动之间的关系。
- **Calmar**：年化收益与最大回撤的比值。
- **胜率**：盈利交易占已完成交易的比例。
- **盈亏比**：盈利金额与亏损金额的关系。
- **年换手**：组合一年内大致换手的倍数。

某个指标很高不表示策略可靠。至少要同时看区间、样本数量、回撤、成本和交易明细。

## 成本指标

- **显性费用**包括手续费、印花税等计算成本。
- **滑点损耗**来自模拟成交价与计算价格的偏差。

成本很低可能是交易次数少，也可能是成本设置过低。返回启动参数核对后再下结论。

## 修改后重新运行

修改代码、日期、资金或成本后，“运行回测”会重新变为可用。再次运行并等待完成，新的结果才会反映修改。

比较两次结果时记录所有设置，不能只记录收益数字。
