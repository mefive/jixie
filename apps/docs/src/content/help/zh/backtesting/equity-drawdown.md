# 查看净值、回撤和月度收益

图表用于查看收益发生的过程。相同的最终收益，可能来自平稳上涨，也可能经历很深的亏损后才恢复。

## 切换净值和回撤

1. 打开“结果概览”。
2. 点击图表上方的“净值”查看账户价值变化。
3. 点击“回撤”查看每一天相对之前高点的跌幅。
4. 向下滚动查看月度收益。

下图中的 **1** 是回撤图，**2** 是月度收益表。

![回测结果中的回撤图和月度收益表](/docs/images/help/zh/backtesting/equity-drawdown-01.png)

## 阅读净值图

- “策略净值”表示账户价值随时间的变化。
- 默认业绩基准是沪深 300 全收益指数，按策略起始净值归一后比较。
- 两条线在相同日期和相同起点下才有可比性。
- 曲线末端较高不表示过程中没有大幅亏损。

可以使用图表右上方的基准筛选按钮选择其他指数。改变基准会影响超额收益和相对表现的解释。

## 阅读回撤图

回撤从 0% 开始向下：

- **峰值**是回撤开始前的净值高点。
- **谷底**是这段回撤中的最低点。
- **恢复**表示净值重新回到之前高点。
- 显示“尚未恢复”时，说明截至结束日期仍未回到此前高点。

最大回撤越深，历史上需要承受的账户损失越大。回撤持续时间也很重要，不能只看最低点。

## 阅读月度收益

月度收益表按年份和月份显示：

- 红色表示正收益。
- 绿色表示负收益。
- 颜色越深，月度涨跌幅绝对值越大。
- 表中的 `+4.0` 表示当月约 `+4.0%`。
- 最后一列是当年的复合收益。

观察收益是否集中在少数月份。如果大部分收益来自一两个特殊月份，应进一步检查这些月份发生了什么。

## 避免错误比较

- 不要比较不同日期区间的曲线终点。
- 不要把净值金额和收益率直接混为一谈。
- 不要只选择最有利的基准。
- 不要因为某段回撤后来恢复，就假定未来也能在相同时间内恢复。
