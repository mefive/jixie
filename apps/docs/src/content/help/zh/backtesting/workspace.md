# 认识回测工作台

回测工作台用于编写策略、设置历史区间、运行回测和查看结果。第一次使用时，先认识页面各区域，再开始修改策略。

## 打开工作台

1. 登录后，点击顶部的“回测工作台”。
2. 点击“新建”创建策略。
3. 可以在输入框中描述规则，也可以选择直接编写代码。
4. 已经保存的策略可以从“历史”中重新打开。

如果只想先完成一次回测，建议从[第一次运行回测](/help/getting-started/first-backtest)开始。

## 页面分区

下图中的区域分别是：

1. **策略对话和历史**：查看当前策略名称、补充修改要求、打开历史策略或新建策略。
2. **策略代码**：显示当前策略实际执行的规则。直接编辑代码属于进阶操作。
3. **结果区域**：设置启动参数、运行回测、查看指标、图表和交易明细。
4. **日志**：显示系统运行进度和策略中的 `console` 输出。

![回测工作台中的策略区、代码区、结果区和日志区](/docs/images/help/zh/backtesting/workspace-01.png)

拖动分隔线可以调整各区域的宽度或高度。页面较窄时，可以先收起暂时不用的区域。

## 描述和代码的关系

在左侧描述策略后，中间会出现对应代码。真正参与回测的是中间的代码，因此运行前至少要核对：

- 股票或 ETF 代码是否正确。
- 买入、卖出和调仓条件是否符合描述。
- 数量、频率和日期判断是否符合预期。
- 策略中使用的参数是否与页面设置一致。

如果生成的规则与描述不同，应继续说明要修改的内容，再运行回测。不要只根据策略名称判断代码是否正确。

## 打开历史策略

1. 点击左侧的“历史”。
2. 点击要打开的策略。
3. 等待策略名称、代码和上一次结果加载完成。
4. 检查顶部日期和资金是否仍适合本次运行。

策略代码或启动参数发生变化后，需要重新运行回测。上一次结果不能代表尚未运行的修改。

## 常见问题

### 看不到新建页面

如果工作台自动打开了最近使用的策略，点击左上方“新建”即可创建另一项策略。

### 切换策略时提示有改动尚未运行

这表示当前代码或启动参数已经修改，但还没有用于回测。需要保留修改时先运行回测；不需要时才确认放弃。

### 代码看不懂

先核对名称、证券代码、买卖方向、数量和频率，不必一开始理解每一行。需要直接修改代码时，再查看[策略 SDK](/docs)。
