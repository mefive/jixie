# 运行股票与期货混合策略

混合策略同时持有股票和股指期货。常见用途是持有一组股票，并用股指期货空头降低整体市场涨跌带来的影响。对冲只能改变风险来源，不能保证不亏损。

## 认识两个账户

混合策略把初始资金分到两个独立部分：

- **股票账户**用于股票买卖。
- **期货账户**用于期货保证金、盈亏和费用。

例如股票账户 80%、期货账户 20%，两项合计必须为 100%。回测期间两个账户不会自动互相转入资金。

期货账户比例过低时，可能无法建立策略要求的对冲手数；比例过高则会减少股票可用资金。

## 运行前检查

1. 确认股票列表和股指期货品种正确。
2. 确认股票、期货账户比例合计为 100%。
3. 检查期货是做多还是做空。
4. 检查对冲比例。
5. 检查初始资金、日期和成本。
6. 运行回测并等待完成。

如果策略先买股票再计算期货对冲，应检查实际股票成交金额，而不是只根据目标股票数量估计对冲。

## 查看混合策略指标

下图中的标记分别是：

1. 股票账户权益。
2. 期货账户权益。
3. 期货保证金。
4. 净敞口。

![股票与股指期货混合回测中的分账户权益、保证金和净敞口](/docs/images/help/zh/backtesting/mixed-results-01.png)

各项含义：

- **股票账户权益**：股票账户中的现金和股票市值。
- **期货账户权益**：期货账户资金加上期货盈亏。
- **期货保证金**：当前期货持仓占用的保证金。
- **净敞口**：股票多头名义金额与期货方向和名义金额合并后的剩余市场敞口。

净敞口接近 0 表示方向性市场暴露较低，不表示没有选股风险、基差风险、换月成本或交易成本。

## 核对股票和期货成交

下图中的标记分别是：

1. 两类资产合并后的成交汇总。
2. 标的、方向和资产类型筛选。
3. 股票成交。
4. 期货成交和实际月合约。

![混合策略交易明细中的股票记录和股指期货记录](/docs/images/help/zh/backtesting/mixed-trades-01.png)

检查步骤：

1. 确认股票先按预期成交。
2. 检查期货手数和方向是否与对冲目的一致。
3. 查看期货记录中的实际月合约。
4. 使用资产类型筛选分别核对股票和期货。
5. 检查手续费、滑点和总成交额。

股票一笔成交和期货多笔成交并不一定矛盾。主力连续期货发生换月时，会产生额外的移仓记录。

## 为什么对冲后仍会亏损

常见原因包括：

- 股票组合本身表现弱于股指。
- 期货手数只能取整数，无法精确覆盖股票市值。
- 股票和指数的涨跌并不完全一致。
- 期货价格与现货指数存在差异。
- 合约换月、手续费和滑点产生损耗。
- 股票停牌、涨跌停或实际成交数量改变了预期持仓。

因此要同时查看净敞口、分账户权益、交易明细、净值和回撤，不能只看“已经对冲”这个策略名称。

## 比较对冲比例

需要比较不同对冲比例时：

1. 保持股票规则、日期、资金和成本一致。
2. 每次只修改对冲比例。
3. 记录累计收益、最大回撤、净敞口和期货保证金。
4. 查看换月和交易成本是否随期货手数增加。
5. 使用不同市场阶段再次测试。

对冲比例是风险设置，不是保证收益的参数。不要只选择历史收益最高的一组。
