# 比较多组策略参数

参数扫描用于把同一段策略代码中的参数换成多组取值，分别运行回测并比较结果。数值参数适合检查结果是否只在某一个特殊数值上较好；字符串参数可用于对比仓位方案。

## 开始前

策略代码需要在 `params` 中声明有限数值或非空字符串，并通过 `ctx.params` 使用。例如，回看天数、每次买入数量和仓位方案可以分别声明为 `lookback`、`shares` 和 `sizing`。

参数扫描不会改写策略代码，也不会覆盖工作台“结果概览”中的普通回测结果。一次最多扫描两个参数、25 组组合，后台按顺序运行。

## 填写扫描设置

1. 打开已经保存的策略。
2. 确认代码中包含可扫描的数值或字符串参数。
3. 点击顶部的“参数扫描”。
4. 在第一维选择参数，并用逗号填写至少两个数值。
5. 需要比较两个参数时，勾选“扫描第二个参数”，再填写第二组数值。
6. 需要检查样本外表现时，勾选“同时运行样本内 / 样本外”并选择切分日期。
7. 确认组合数量后，点击“开始扫描”。

下图中的标记分别是：

1. 第一组参数和值。
2. 第二组参数和值。
3. 样本内、样本外切分开关。
4. “开始扫描”按钮。

![参数稳健性扫描中的两组参数、样本切分和开始按钮](/docs/images/help/zh/backtesting/parameter-scan-settings-01.png)

例如，第一维填写 `2, 3`，第二维填写 `100, 200`，会运行 `2 × 2 = 4` 组组合。

## 等待扫描完成

扫描期间打开结果区域的“参数扫描”标签。页面会显示当前运行日志。不要刷新后重复提交相同扫描；等待当前任务完成或明确显示失败。

组合越多、日期越长、策略处理的证券越多，所需时间越长。

## 查看扫描结果

下图中的标记分别是：

1. 历史扫描，可以重新打开以前完成的扫描。
2. 对比指标，例如年化收益或 Sharpe。
3. 参数组合图。
4. 每组参数的明细表。

![四组参数扫描结果的指标选择、组合图和明细表](/docs/images/help/zh/backtesting/parameter-scan-results-01.png)

查看结果时：

1. 先确认历史扫描的完成时间。
2. 检查页面显示的组合数量、代码标识和数据截止日期。
3. 选择要比较的指标。
4. 在图表中观察相邻参数的结果是否接近。
5. 在表格中核对每一组具体数值。

示例截图使用较短区间，因此年化收益数值只用于演示页面，不应用来评价策略。

## 使用样本内和样本外

勾选样本切分后：

- **样本内**用于观察和选择参数。
- **样本外**用于检查选定参数在未参与选择的后续区间中是否仍有表现。
- **全样本**显示整个日期范围的结果。

不要根据样本外结果反复修改参数，再把同一段数据继续称为样本外。这样会让样本外区间也参与选择。

## 如何判断参数是否稳健

优先关注：

- 相邻数值是否得到大致一致的方向。
- 收益改善是否同时伴随更深回撤或更多交易。
- 结果是否只在一个很窄的数值上突然变好。
- 样本外结果是否明显弱于样本内。
- 成本提高后结果是否仍能维持。

参数扫描不能证明策略未来有效。它只能帮助发现参数敏感和过度拟合的迹象，还需要结合交易明细、不同市场阶段和合理成本检查。

## 对比仓位方案

同一套进出场条件可以把仓位方法声明为字符串参数：

```ts
params: { sizing: 'atr', riskPct: 0.01, fixedLots: 10 }
```

代码根据 `ctx.params.sizing` 在等权、固定手数和 ATR 风险仓位之间切换。打开扫描弹窗后选择“仓位方案对比”，选择 `sizing`，填写 `equal, fixed, atr`。一次可比较 2～5 个方案，不与样本切分同时使用。

结果会叠画从 1 起步的净值，并列出年化收益、最大回撤、年化波动率、最长水下交易日和 Sharpe。它只比较仓位带来的路径差异，不会自动改写进出场逻辑。

## 测算策略容量

容量测算回答“资金增加后，策略收益会从哪个规模开始被成交冲击侵蚀”。它不要求策略声明参数：打开扫描弹窗，选择“容量测算”，输入 3～7 个以万元为单位的资金档位，例如 `50, 200, 1000, 5000, 20000`。

每个档位使用相同的策略代码、回测日期和成本模型，只替换初始资金。结果同时显示年化收益和年化滑点损耗曲线，并标记：

- 最小资金档位，作为本次小资金基准；
- 年化滑点损耗首次达到 1% 的档位；
- 年化收益首次降至小资金基准一半的档位。

“本次未触发”表示输入的最大资金仍未跨过该阈值，不表示策略没有容量上限。容量结果依赖成交额、换手率、整手约束以及回测成本参数；固定股数策略还可能因为资金变大而自然降低仓位比例，应先确认策略的下单方式符合想研究的资金扩张方式。
