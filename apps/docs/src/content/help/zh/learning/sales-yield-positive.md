# 销售收益率：从正面 Holdout 到因子准入

> 学习路径 · 预计 75～105 分钟 · 建议先完成一次预设因子分析。

这项练习回答一个此前学习路径没有回答的问题：**能否找到一个在冻结定义、去冗余和首次正式 Holdout 中都保持
方向一致，因而值得进入下一轮研究的股票因子？**

答案是可以。销售收益率 `sales_yield` 是目前第一条正面学习路径。它在探索段和 2025-02-05 至 2026-07-30
的原始正式 Holdout 中都通过 `Rank IC 均值 > 0.01`，并在 2026-08-12 准入预置因子菜单。

“正面”在这里表示**因子排序证据支持进入下一轮**，不表示已经得到可部署策略。

| 证据 | 探索段 | 正式 Holdout | 事前要求 | 裁决 |
| --- | ---: | ---: | ---: | --- |
| Rank IC 均值 | 0.03775 | **0.03469** | `> 0.01` | 通过 |
| 年化 ICIR | 1.6504 | **1.5354** | 辅助证据 | 同向 |
| IC>0 比例 | 70.00% | **64.71%** | `> 50%` | 同向 |
| 等权费后多空年化 | 8.58% | **0.66%** | `> 0` | 温和通过 |
| Top 组换手 | 16.10% | **17.75%** | 诊断 | 较低 |

## 学完以后

你应该能够：

1. 解释销售收益率与市销率的关系，以及它为什么只是价值代理；
2. 在看结果前冻结方向、主要标准、股票池、成本和冗余淘汰线；
3. 区分 Rank IC 通过、费后分层为正与“策略已经可交易”；
4. 核对候选代码、探索报告、Holdout 和正式预置之间的哈希血缘；
5. 在给出正面裁决时仍保留市值加权、尾部月份和历史过滤限制。

## 第一步：定义一个不能事后改写的信号

市销率 TTM 把市值与过去十二个月收入联系起来。销售收益率取其倒数：

$$
SalesYield_{i,t}=\frac{1}{PS\_TTM_{i,t}}\approx\frac{TTM\ Revenue_{i,t}}{MarketCap_{i,t}}
$$

数值越高，表示每单位市场价值对应的历史收入越多。它可能捕捉估值折价，也可能捕捉低利润率、周期下行或商业模式
差异，所以不能仅凭“便宜”叙事预设成功。

冻结代码只有一个分支：`PS_TTM` 非正或缺失时不形成暴露。

```ts
export default defineFactor({
  name: '销售收益率(1/PS_TTM)',
  compute: (bar) => (bar.psTtm && bar.psTtm > 0 ? 1 / bar.psTtm : null),
});
```

平台读取形成日对应的历史 `DailyBasic.PS_TTM` 截面，不用今天的市销率回填过去。但这套研究依赖数据供应方保存的
历史日频 TTM 估值，没有在本报告中逐份重建收入报表 vintage；这是必须保留的数据边界。

## 第二步：冻结三道准入门

2026-08-12 的原始准入协议在任何 Holdout 结果出现前固定为：

```text
假设：销售收益率在市值和行业中性化后，与 A 股下一月收益排名保持正向关系。

探索区间：2020-01-01 至 2025-01-27；月频；全 A 股。
股票池：上市满 365 日；剔除历史风险警示和待退市；剔除流动性后 25%；每期至少 100 只。
处理：因子暴露与未来收益双侧 1% 缩尾；市值+行业中性化。
成本：佣金单边 2.5 bp、卖出印花税 5 bp、滑点单边 10 bp。

主判据：rank_ic_mean > 0.01。
冗余门：探索段与 ep、bp 的平均截面 Spearman 绝对值都 < 0.90。
辅助证据：IC>0 比例 > 50%，等权高减低组合费后年化 > 0。

正式 Holdout：只有探索和冗余门通过后才启动；代码、参数、方向和门槛不变，只揭示一次。
```

三道门回答不同问题：预测方向是否存在、是否只是已有价值因子换名、在简单成本下是否仍有经济幅度。主判据不能被
事后换成其中最好看的指标。

## 第三步：先读探索段，不碰保留段

探索报告有 60 个有效月。中性化 Rank IC 为 0.03775，年化 ICIR 为 1.6504，42 个自然月的 IC 为正。
等权 D10−D1 费前年化 10.00%，计入冻结成本后为 8.58%；Top 组平均单边换手为 16.10%。

![销售收益率原始探索报告](/docs/images/help/zh/learning/sales-yield-explore-result.png)

| 探索检查 | 结果 | 怎样解释 |
| --- | ---: | --- |
| Rank IC | 0.03775 | 高销售收益率总体对应更高的下一月收益排名 |
| IC>0 | 70.00% | 方向不是只由少数月份维持 |
| 等权费后多空 | 8.58% | 简单诊断在冻结成本后仍为正 |
| 市值加权费后多空 | -2.62% | 经济结果对权重口径敏感，不能忽略 |
| 有效期 | 60 / 60 | 没有因最低样本要求丢失月份 |

主判据通过，但市值加权多空为负已经提示：这是一个**横截面排序候选**，不是无需组合约束就能兑现的收益曲线。
报告还明确标记历史负净资产和长期停牌过滤不可用；系统没有用当前状态回填过去，但这两项历史可投资性限制仍未
完整排除。

## 第四步：证明它不是已有价值因子的换皮

在 61 个探索形成日上，使用同一批股票计算平均截面 Spearman 相关：

| 比较对象 | 与销售收益率的相关 | 冻结淘汰线 | 结果 |
| --- | ---: | ---: | --- |
| 盈利收益率 `ep` | 0.46954 | 绝对值 `< 0.90` | 通过 |
| 账面市值比 `bp` | 0.59189 | 绝对值 `< 0.90` | 通过 |
| 规模 `size` | -0.01172 | 诊断 | 接近零 |

销售收益率属于价值主题，但没有达到“只是 EP 或 BP 的同义重排”程度。冗余门通过以后，协议才允许生成正式
Holdout。

## 第五步：只读取原始的一次正式揭示

原始 Holdout 报告先计算并保持密封，再于 **2026-08-12 14:08（中国时间）**首次揭示。它沿用同一份代码和
协议，代码 SHA-256 为：

```text
abd0b11b68739b08a71e9348012aff14764fe688310575b9f93e3ce0cf81acca
```

当前教程的自动验收只读取这两份原始不可变报告，并核对后来预置菜单 `sales_yield` 的代码仍为相同哈希。再次打开
或截图不是新的样本外检验，不能把同一保留段重复计为第二次成功。

![销售收益率原始正式 Holdout 报告](/docs/images/help/zh/learning/sales-yield-holdout-result.png)

| Holdout 指标 | 结果 | 裁决 |
| --- | ---: | --- |
| 有效月 | 17 | 完整覆盖冻结窗口 |
| Rank IC | **0.03469** | 通过 `> 0.01` |
| 年化 ICIR | 1.5354 | 与探索段同向 |
| IC>0 | 64.71% | 11 / 17 个月为正 |
| 等权费前多空 | 2.09% | 正 |
| 等权费后多空 | **0.66%** | 成本后仍正，但很薄 |
| Top 组换手 | 17.75% | 与探索段接近 |
| 市值加权费后多空 | -2.78% | 冲突证据 |

最后一个月的 Rank IC 为 0.2550、费后多空收益为 15.05%，对经济曲线贡献很大。作为事后敏感性诊断，排除该月后
前 16 个月平均 Rank IC 仍约为 0.02092，继续高于主门槛；但费后多空累计收益会为负。这说明**排序证据比可交易
收益证据更可靠**。

## 第六步：给出有限但真正正面的裁决

```text
研究结论：支持销售收益率进入下一轮因子研究，并准入预置研究菜单。

主要证据：探索 Rank IC 0.03775，正式 Holdout Rank IC 0.03469，均超过事前 0.01；
IC 正值比例分别为 70.00% 和 64.71%，方向一致。

去冗余：与 ep、bp 的探索截面相关为 0.46954、0.59189，均未达到 0.90 淘汰线。

经济证据：等权费后多空年化从探索段 8.58% 降至 Holdout 0.66%，仍为正但幅度温和；
市值加权为负，且 Holdout 收益依赖最后一个月，不能宣称已经得到稳健策略。

行动：保留 sales_yield 为已准入 Factor，允许进入组合研究；不生成股票名单、不单因子部署、
不把 D10−D1 诊断冒充普通账户可执行策略。下一次正式升级等待新数据和明确组合协议。
```

这就是正面结果应有的边界：它可以晋级，但不能跳级。

## 业务上可以做什么

- 把 `sales_yield` 作为价值组件加入后续多因子组合研究；
- 监控月度 Rank IC、覆盖、换手和与 EP/BP 的相关漂移；
- 在组合层明确股票池、权重、行业/规模约束、持仓数量、成交和容量；
- 等待 2026-07-30 之后的新月份，作为真正新增证据，而不是反复查看已揭示 Holdout。

当前不能做的是把 0.66% 的诊断收益外推成未来回报，或根据已知保留段继续调整阈值再宣布“更强版本”。

## 完成检查

- [ ] 能复述主判据、冗余门、辅助证据和冻结成本；
- [ ] 核对探索、Holdout 与预置代码使用同一 SHA-256；
- [ ] 确认只把 2026-08-12 的原始揭示计为正式 Holdout；
- [ ] 同时记录等权正收益、市值加权负收益和末月敏感性；
- [ ] 最终裁决是“准入研究菜单并进入下一轮”，不是“部署策略”。
