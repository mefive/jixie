# 沪深 300 价值因子：排序、IC、分层与样本外

> 学习路径 · 预计 75～105 分钟 · 建议先完成一次预设因子分析；本练习只使用现有预设和报告，不需要写代码。

这项练习检验一个有限的横截面问题：**在沪深 300 的历史时点成分中，盈利收益率较高的股票，下一月收益排名是否
倾向更高，而且这段关系在冻结口径的正式保留段中是否仍然存在？**

盈利收益率预设的 key 是 `ep`，定义为正 `PE_TTM` 的倒数。它把“同一时点哪些股票相对更便宜”转换成可排序的
数值，但不会自动生成持仓，也不会证明便宜股票未来一定上涨。

## 已实际跑通的固定案例

实际运行先纠正了教程原来不可执行的一处日期：本地沪深 300 历史成分的首个快照是 2016-01-29，系统会拒绝
在 2015 年用今天的成分回填历史。因此固定探索区间从 **2016-02-01** 开始，而不是为了得到更好结果移动日期。

2026-08-25，我们用一个全新账户依次运行了无中性化主报告、事前声明的市值+行业中性化诊断，以及主报告唯一一次
正式 Holdout。探索数据截止为 2025-01-27，共 107 个有效月；Holdout 为 2025-02-05 至 2026-07-30，共
17 个有效月。所有报告固定沪深 300 历史时点成分、月频、全局排序、1% 缩尾、非零成本和
`Rank IC 均值 > 0.02`。

## 学完以后

你应该能够：

1. 解释盈利收益率的方向、缺失规则和研究对象；
2. 区分因子值、下一期收益、Rank IC、十组收益和多空诊断；
3. 在看结果前冻结研究范围、主要标准和唯一一个敏感性检查；
4. 阅读覆盖率、稳健区间、换手、成本和正式保留段中的冲突证据；
5. 用支持下一轮、证据不足或否决收尾，而不是自动发布 Factor 或建立策略。

## 开始前先补齐前置知识

- 如果还没有运行过 Factor，先完成[第一次运行预设因子分析](/help/factors/first-preset-analysis)。
- 先读[因子研究能回答什么](/help/factors/what-factor-research)和[运行前研究卡](/help/factors/research-card)。
- 不熟悉排名相关时，先读[Rank IC、ICIR 和 IC 衰减](/help/factors/rank-ic-icir)。
- 本练习需要一次不可逆的正式保留段揭示。已经在平台内或其他工具中看过相同数据时，不能把它重新称为未观察样本。

## 第一步：先理解预设到底计算什么

在“因子研究”的“因子库”中选择“盈利收益率(1/PE_TTM)”。预设实际计算：

$$
EP_{i,t}=
\begin{cases}
1/PE^{TTM}_{i,t}, & PE^{TTM}_{i,t}>0 \\
\text{缺失}, & PE^{TTM}_{i,t}\leq0\text{ 或不可用}
\end{cases}
$$

所以：

- 因子值越大，正市盈率口径下的股票越便宜，事前方向是正向；
- 亏损股和没有可用 `PE_TTM` 的股票不会被强行排到“最便宜”一端，而是没有本期暴露；
- 盈利收益率是相对排序信号，不是对公司内在价值的完整估计；
- `PE_TTM`、价格和成分必须来自当时可得数据，不能拿今天的成分回填历史。

以某期三只正市盈率股票为例，`PE_TTM` 分别为 10、20 和 40，则盈利收益率为 0.10、0.05 和 0.025。第一只会
排得更高，但“排名更高”不等于“下个月必涨”。研究要检查的是许多月份、许多股票上的平均排序关系。

## 第二步：在看结果前冻结研究卡和协议

新打开工作台时，平台会把结束日期设为当前可用的**探索段结束日**。这个日期会随服务器数据更新，不要把截图中的
旧日期抄进自己的报告。先在“更多设置”中填写以下口径，并把页面显示的实际日期、成本和数据截止记入研究记录：

| 项目     | 本练习的主报告                           | 为什么固定                                   |
| -------- | ---------------------------------------- | -------------------------------------------- |
| Factor   | `ep` 盈利收益率预设                      | 不改代码或因子定义                           |
| 研究范围 | 沪深 300                                 | 使用每个历史日期当时的指数成分               |
| 排序范围 | 全局排序                                 | 回答沪深 300 成分之间的相对排序              |
| 频率     | 月                                       | 因子值对应下一月收益                         |
| 区间     | `2016-02-01` 至页面当前探索段结束日      | 首个成分快照为 2016-01-29；不越过正式保留段 |
| 中性化   | 无                                       | 作为事前主报告                               |
| 样本处理 | 保留当前默认风险、流动性、覆盖和 1% 缩尾 | 避免看结果后改过滤条件                       |
| 成本     | 保留当前非零默认值并记录准确数字         | 费后多空不能按零摩擦解释                     |
| 主要标准 | Rank IC 均值 `> 0.02`                    | 本练习预注册的一条主要标准，不是通用行业门槛 |
| 计划诊断 | 只增加一份“市值+行业中性化”报告          | 检查结果是否主要重复规模或行业暴露           |

点击“运行分析”后选择“假设验证”，填写：

```text
假设：在沪深 300 的历史时点成分中，盈利收益率较高的股票，下一月收益排名倾向高于
      盈利收益率较低的股票。

逻辑：较低估值可能对应更高的后续必要收益，但也可能只是困境、行业或规模暴露。

预期方向：正向。
主要标准：Rank IC 均值 > 0.02。

辅助证据：D1 至 D10 的大致单调性、IC 的 Newey–West 区间、ICIR、IC>0 占比、
          等权／市值加权差异、覆盖率、换手和费后多空。

反证条件：若正式保留段未达到主要标准、方向反转、分组杂乱、稳健区间跨 0，或结果在
          市值+行业中性化、合理成本和市值加权下明显消失，就不能称为稳健候选。

结论边界：股票横截面历史证据；不自动发布，不生成买入名单，不建立或部署策略。
```

`0.02` 只是为了让本练习在运行前有一条明确判据。不同市场、频率和因子的合理数值不同；运行后把门槛降到刚好
通过，会把探索包装成验证。

## 第三步：运行主报告并先核对样本

冻结研究卡并运行。报告完成后，不要先看收益最高的柱子，按以下顺序核对：

1. 顶部是否显示“沪深 300”“月”“无中性化”和预定区间；
2. 研究范围是否注明使用历史时点成分；
3. 数据截止、有效月数和实际分析年份是否符合预期；
4. 从研究范围、因子值、前瞻行情、上市时间、风险状态和流动性过滤前后的样本变化是否合理；
5. 有效股票覆盖是否稳定，是否有少数月份刚好越过最少样本门槛；
6. 代码摘要、异常值处理和单边成本是否与实验卡一致。

如果页面显示“当前报告仍基于旧参数”，屏幕上的结果不是刚修改的草稿。重新打开正确历史报告，或者按新设置运行
一份新报告；不要把两套参数和一套结果写在一起。

把协议记录到固定表中：

| 报告     | 范围     | 区间 | 月数 | 中性化    | 代码摘要 | 数据截止 | 探索变体数 |
| -------- | -------- | ---- | ---: | --------- | -------- | -------- | ---------: |
| 主报告   | 沪深 300 | […]  |  […] | 无        | […]      | […]      |        […] |
| 计划诊断 | 沪深 300 | […]  |  […] | 市值+行业 | […]      | […]      |        […] |

失败、中断或与预期不符的报告也留在历史中。探索变体越多，偶然遇到漂亮结果的机会越大。

## 第四步：把 Rank IC 和十组收益读成两类证据

每个成仓月，系统计算盈利收益率排名与下一月收益排名的 Spearman 相关：

$$
IC_t=\operatorname{Corr}_{Spearman}
\left(\operatorname{Rank}(EP_{i,t}),\operatorname{Rank}(r_{i,t\rightarrow t+1})\right)
$$

主报告的 Rank IC 均值是各有效月份 $IC_t$ 的平均。它回答“高因子排名是否通常对应高后续收益排名”，不是组合
收益率，也不是因果效应。

页面还会把每月股票按因子值从低到高分成 D1 至 D10：

- D1 是盈利收益率最低的十分位，D10 是最高的十分位；
- D10 是一组股票，不是系统推荐的十只股票；
- D10−D1 是假设做多最高组、做空最低组的研究构造；
- 普通账户的融券范围、融券费率、容量和冲击没有被这条诊断完全覆盖。

按下面顺序阅读并记录主报告：

| 证据                 |     记录 | 要问的问题                               |
| -------------------- | -------: | ---------------------------------------- |
| Rank IC 均值         |      […] | 正负是否符合事前方向，是否达到 `> 0.02`  |
| Newey–West 95% 区间  |      […] | 区间是否跨 0，时间相关后的不确定性有多大 |
| 年化 ICIR／IC>0 占比 | […]／[…] | 平均关系是否只由少数月份贡献             |
| D1→D10 等权          |      […] | 是否大致上升，而不是只有一根极端柱       |
| D1→D10 市值加权      |      […] | 换成大市值权重后顺序是否仍存在           |
| 费前／费后多空年化   | […]／[…] | 基础摩擦是否吃掉大部分差异               |
| D10 换手／最大回撤   | […]／[…] | 研究构造的实施难度和路径风险怎样         |
| 覆盖率与有效月份     |      […] | 结果是否建立在稳定、足够的截面上         |

均值达到 `0.02`，但稳健区间跨 0、十组杂乱或市值加权后消失，属于冲突证据，不能被主要标准的一个“通过”标签
抹掉。反过来，十组看起来整齐但 Rank IC 很弱，也可能只是两端或少数时期造成。

## 第五步：只做事前声明的中性化诊断

主报告记录完成后，打开“更多设置”，只把中性化从“无”改为“市值+行业”，其余项目保持不变。再次运行时沿用
同一假设、正向方向和 `Rank IC 均值 > 0.02`，形成第二份、也是本练习最后一份探索报告。

这次诊断回答：盈利收益率在去除对数市值和历史行业共同差异后，剩余排序是否仍与下一月收益排名有关。它不是让
结果变好的开关，也不能用来替换事前主报告。

并排记录两份报告：

| 指标            | 无中性化主报告 | 市值+行业诊断 | 解释                       |
| --------------- | -------------: | ------------: | -------------------------- |
| Rank IC 均值    |            […] |           […] | 方向和幅度怎样变化         |
| Newey–West 区间 |            […] |           […] | 哪一份仍容许 0             |
| ICIR／正向占比  |            […] |           […] | 稳定性是否改变             |
| D1→D10 顺序     |            […] |           […] | 中间分组是否仍有序         |
| 费后多空        |            […] |           […] | 成本后差异是否保留         |
| D10 换手        |            […] |           […] | 中性化是否明显增加实施负担 |

不要继续尝试周频、行业内排序、不同起点、不同缩尾和多个阈值，直到出现最好看的组合。那些都可以成为未来新问题，
但每一次选择都会增加探索变体。完成本练习时，探索设计只有“一个主报告 + 一个预先声明的诊断”。

## 第六步：验证并一次揭示正式保留段

回到**无中性化主报告**。如果它符合资格，研究计数条会显示“验证保留段”。点击后先核对：

1. 正式保留段的实际开始和结束日期；
2. 冻结代码摘要是否属于主报告；
3. 冻结口径仍是沪深 300、月频、全局排序和无中性化；
4. 预期方向仍为正向；
5. 主要标准仍是 `Rank IC 均值 > 0.02`。

确认后，系统使用主报告当时的代码和非日期参数计算。完成时结果仍保持封存；运行日志也不会泄露数字。只有已经
准备接受成功或失败时才点击“揭示结果”。揭示时间会永久写入报告，不能撤销。

如果按钮不可用，按页面给出的原因原样记录：

- 探索报告不是假设验证；
- 探索区间越过保留段；
- 保留段观察期不足；
- 这份主报告已有保留段；
- 同一代码已经观察过这段数据。

不要通过复制同一公式、改名称或微调门槛来制造“新的”未见样本。如果此前已经在别处看过这段数据，也应主动披露，
即使平台无法检测。此时可以继续完成报告阅读，但结论必须写成“没有可用的首次正式保留段证据”。

揭示后先只记录预注册判定，再读取辅助证据：

| 正式保留段证据               |          结果 |
| ---------------------------- | ------------: |
| 首次揭示时间                 |           […] |
| Rank IC 均值及是否 `> 0.02`  |           […] |
| Newey–West 95% 区间          |           […] |
| ICIR／IC>0 占比              |      […]／[…] |
| D1→D10 等权与市值加权顺序    |           […] |
| 费后多空／D10 换手／最大回撤 | […]／[…]／[…] |
| 覆盖率和有效月份             |           […] |

揭示后不能在同一段数据上降低阈值、改方向或重新选择主报告，再称为正式样本外。

## 第七步：裁决证据，不发布或转策略

用下面三类裁决收尾：

- **支持进入下一轮研究**：正式保留段达到事前主要标准，方向、分组、覆盖、稳健区间、权重口径和成本没有出现足以
  推翻主张的冲突；仍只表示值得继续研究。
- **证据不足**：主要标准达到但辅助证据明显冲突，或账户没有可用的首次保留段；保留原因，不挑成功指标代替整体判断。
- **否决当前假设**：正式保留段未达到主要标准、方向反转，或协议／数据问题使报告不能回答原问题。

使用下面结构写最终记录：

```text
本练习事前固定 ep、2016-02-01 起的沪深 300 历史时点成分、月频、全局排序、无中性化和
Rank IC 均值 > 0.02；只预先增加一份市值+行业中性化诊断。

探索主报告的 Rank IC／Newey–West 95% 区间为 […]／[…]；十组、等权与市值加权、
覆盖、费后多空和换手显示 […]。中性化诊断相对主报告 […]。

正式保留段于 […] 首次揭示，[达到／未达到／无法进行]预注册标准；辅助证据 […]。

因此当前证据 [支持进入下一轮研究／不足／否决]。结果只描述沪深 300 历史股票截面；
D10−D1 是研究诊断，未验证普通账户融券、容量和真实成交，也没有发布 Factor、生成股票名单、
创建策略或部署信号。
```

即使裁决为“支持”，这条路径也到此停止。预设 Factor、研究报告和可交易策略是不同对象；策略需要明确持仓、现金、
调仓、成交约束和完整回测，不能复制报告里的多空曲线冒充策略结果。

## 完成检查

- [ ] 说明 `ep` 只对正 `PE_TTM` 取倒数，亏损或缺失样本不会被排到最高组；
- [ ] 在看结果前固定沪深 300、月频、探索段、全局排序、无中性化和 `Rank IC > 0.02`；
- [ ] 核对历史时点成分、数据截止、覆盖、代码摘要、异常值和成本口径；
- [ ] 区分 Rank IC、D1 至 D10、D10−D1 研究构造和真实策略收益；
- [ ] 同时阅读均值、Newey–West 区间、ICIR、方向占比、权重、换手和费后结果；
- [ ] 只运行一个主报告和一个事前声明的市值+行业诊断，不事后扩展搜索；
- [ ] 正式保留段只揭示一次；不可用时记录真实原因，不绕过封存；
- [ ] 用支持、证据不足或否决收尾，不自动发布、转策略或部署。

全部完成后，你得到的是一份带预注册和样本外边界的股票横截面研究记录，不是选股建议。
