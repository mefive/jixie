# 分享和复制公共资产

“公共资产库”展示用户主动公开的策略和已发布 Factor。公开只允许其他用户查看卡片并复制成自己的独立私有副本，不会把双方变成共同编辑者。

## 浏览和复制

1. 打开顶部“公共资产库”。
2. 在“公开资产”查看“公开策略”和“公开因子”。
3. 核对名称、资产类型、作者；Factor 还会显示 key。
4. 点击“复制到我的空间”。
5. 策略会打开回测工作台，Factor 会打开因子研究；复制结果默认私有。
6. 修改前先检查代码、参数、研究范围和已有报告，不要因为来源公开就跳过验证。

复制会生成新的所有者和独立 ID。原作者后续修改或设为私有，不会改写你已经复制的副本；你的修改也不会反写原资产。

![公共资产库中的公开资产和复制入口](/docs/images/help/zh/library/share-copy-01.png)

## 公开自己的资产

1. 打开“公共资产库”的“我的分享”页签。
2. 在“我的策略”或“我已发布的因子”找到资产。
3. 点击“公开分享”。
4. 返回“公开资产”确认卡片和作者信息。

只有自己拥有的策略可以公开。Factor 必须先按因子研究流程发布，草稿不会出现在“我已发布的因子”。公开不会改变策略回测或 Factor 报告内容。

## 设为私有

在“我的分享”或自己公开卡片上点击“设为私有”。新用户之后不能再从公开列表复制，但其他用户此前已经生成的独立副本不会被删除。

## 分享前检查

- 删除代码、名称和说明中的个人信息、密钥或不应公开的内容。
- 确认策略和 Factor 使用的 key、字段与研究范围准确。
- 不要把历史收益写成承诺；公开资产仍需使用者自己验证。
- 公共资产库不是实盘交易市场，也不代表平台推荐。

## 常见问题

### 为什么自定义 Factor 不在“我的分享”

只有已发布 Factor 可以分享。先完成批准报告并发布；仍在编辑的草稿保持私有。

### 设为私有能收回别人复制的版本吗

不能。复制时已经生成对方拥有的独立私有副本。
