# 查看市场页面和切换范围

市场页面把交易热度、市场广度、趋势强度和交易拥挤分开显示。它用于了解当前市场状态，不提供上涨或下跌预测。

## 打开市场页面

1. 登录后，点击顶部的“市场”。
2. 等待左上角出现观察范围，右上角出现更新日期和覆盖数量。
3. 确认页面显示四张指标卡、当日明细和近三年历史图。

下图中的标记分别是：

1. 当前观察范围、数据日期和覆盖股票数。
2. 四项市场指标及近三年百分位。
3. 当日市场明细。
4. 当前指标的近三年历史。
5. 页面计算口径。

![市场页面的主要区域](/docs/images/help/zh/market-valuation/market-overview-01.png)

阅读任何数值前，先看标记 1 的“更新至”。市场数据通常在交易日收盘后更新；页面日期不是今天时，所有指标都对应页面显示的日期。

## 切换观察范围

1. 点击左上角当前范围，例如“全A”。
2. 在弹出的列表中选择范围。
3. 等待页面重新加载。
4. 查看右上角覆盖数量，确认已经切换成功。

范围列表分为：

- 规模宽基：全A、上证50、沪深300、中证500、中证1000、中证2000、中证A500。
- 特色板块：创业板指、科创50。
- 策略风格：中证红利。

下图中的标记分别是：

1. 范围选择按钮。
2. 规模宽基。
3. 特色板块。
4. 策略风格。

![选择市场观察范围](/docs/images/help/zh/market-valuation/market-scope-01.png)

每个选项右侧的“20日”和“广度”用于快速比较范围。选择后，四张指标卡、当日明细、历史图和百分位都会切换到该范围。

## 查看指数范围

下图选择沪深300，并把历史图切换到“趋势强度”：

1. 当前范围、更新日期和覆盖数量。
2. 沪深300的四项指标。
3. 沪深300成分股的当日明细。
4. 历史图指标切换。
5. 当前指标的近三年曲线。
6. 指数范围的计算口径。

![查看沪深300市场状态](/docs/images/help/zh/market-valuation/market-index-01.png)

指数范围使用不晚于观察日的最新月度成分快照并向前保持，不会用今天的成分股直接回填全部历史。趋势强度使用指数官方收盘点位；其余指标由当时的成分股数据汇总。

## 建议阅读顺序

1. 先确认更新日期和观察范围。
2. 看四项指标的当前值，不要先看百分位。
3. 用“站上 MA20”“站上 MA60”“今日上涨”等明细核对当前状态。
4. 切换近三年历史，查看当前值是否只是短期变化。
5. 最后阅读页面底部“口径”。

四项指标不应合并成一个“市场温度”。例如交易热度很高时，市场广度仍可能很低，表示成交活跃但上涨或站上均线的股票并不多。

## 常见问题

### 页面日期不是今天

先确认今天是否为交易日、是否已经收盘，以及最新行情是否已经完成处理。点击页面顶部“刷新”不能生成尚未准备好的市场数据。

### 切换范围后数值差异很大

不同范围的成分股、规模和风格不同。全A、中证红利和创业板指出现不同状态是正常现象。

### 覆盖数量为什么会变化

全A按当日实际交易股票统计；指数范围按历史成分快照统计。上市、退市、停牌和指数调整都可能改变数量。
