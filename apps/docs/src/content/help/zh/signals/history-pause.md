# 查看历史并暂停上线

“今日信号”按部署保存历史。同名策略可能对应多份报告或同一报告的多次部署，请用报告来源和部署编号区分。

## 查看历史

1. 在左侧选择具体部署；运行中和已暂停的部署都会列出。
2. 查看“运行历史”，按信号日选择一次运行，核对状态、指令与因子输入。
3. 查看该部署的模型、模拟和实际账户曲线；人工成交只影响该部署。

完成但有 0 条指令可以是正常结果；“生成中”“失败”“已中断”分别表示未结束、失败和中断。刷新页面不会删除历史。

## 暂停部署

在“今日信号”选择目标部署，点击“暂停部署”。也可以点击报告来源回到 Lab，选择对应报告后点击“暂停上线”。

暂停会阻止此部署新增信号，不影响其他部署。已入队任务可以完成，已有账户继续结算，历史成交仍可回填；暂停不会撤销券商订单或真实成交。已暂停部署的“立即生成”不可用。

## 再次部署

在 Lab 选择准备运行的成功报告并点击“部署上线”。同一报告再次部署会创建新部署和账户，原部署的信号与账户继续保留。也可以部署新报告；它不会自动暂停其他运行中的部署。

旧部署如果显示“未关联报告”，可直接在“今日信号”暂停；要建立新的报告部署，请选择一份成功报告。

## 通知状态

每次运行记录邮件已发送、发送失败或开发环境未发送。通知失败不代表信号计算失败；请结合运行状态与日志判断。
