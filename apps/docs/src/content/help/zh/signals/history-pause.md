# 查看历史并暂停上线

运行历史用于确认每天是否完成以及产生多少条指令。暂停上线会停止这个部署版本继续生成新信号，但不会删除已有历史。

## 查看运行历史

1. 打开“今日信号”。
2. 在左侧选择策略。
3. 向下查看“运行历史”。
4. 核对信号日、状态和指令数量。

下图中的标记分别是：

1. 当前部署及最新日期。
2. 当前结果摘要。
3. 两个信号日的运行历史。

![查看有操作和无操作的运行历史](/docs/images/help/zh/signals/signal-history-01.png)

可能出现的状态：

- 完成：策略和信号计算已结束。
- 生成中：任务尚未结束。
- 失败：任务结束但没有有效结果。
- 已中断：服务重启等原因使任务没有正常完成。

0 条指令可以是正常完成；必须结合状态和“今日无操作”阅读。

## 刷新和重试

### 生成中

先点击右上角“刷新”。如果仍显示生成中，查看日志，不要连续重复点击“立即生成”。

### 已中断

页面会提示重新生成。确认市场数据已经准备好后，再点击“立即生成”。

### 失败

阅读页面错误和日志。先处理市场数据、策略运行或部署状态问题，再重试。

同一个信号日成功结果会持久保存。刷新或重新登录不会删除结果。

## 暂停上线

1. 回到“回测工作台”。
2. 打开对应策略。
3. 点击顶部“暂停上线”。
4. 等待按钮重新变成“部署上线”。

暂停完成后的页面：

1. 当前回测参数。
2. 可以再次“部署上线”。
3. 已有回测结果仍保留。

![暂停已经上线的策略](/docs/images/help/zh/signals/signal-pause-01.png)

暂停后：

- 该部署不再参加后续每日信号运行。
- 已有信号和回测结果不会因此变成真实成交。
- 历史记录仍用于核对过去运行。
- 若要上线修改后的策略，先重新运行回测，再部署新版本。

## 什么时候应该暂停

- 不再使用这个策略。
- 发现代码、参数或数据口径需要修正。
- 真实账户无法按模型假设执行。
- 需要上线一个重新回测过的新版本。
- 信号连续异常，需要先停止后续运行并排查。

暂停不是删除策略，也不会撤销已经执行的真实交易。真实账户操作需要用户单独处理。

## 通知状态

运行结果同时记录邮件通知状态：

- 已发送：系统记录发送完成。
- 发送失败：信号可能已经计算成功，但邮件没有成功发送。
- 开发环境未发送：本地或测试环境明确跳过邮件。

不要只依赖邮件。应定期打开“今日信号”核对页面状态和历史。

## 常见问题

### 暂停后还能看到历史吗

可以。暂停改变后续运行状态，不删除已有运行记录。

### 暂停后怎样恢复

回到策略，确认当前代码和参数已有最新回测结果，再点击“部署上线”。这会创建新的冻结部署版本。

### 修改后的策略为什么不能直接恢复

部署必须对应一次已完成回测。先运行修改后的代码，再检查结果并部署。
