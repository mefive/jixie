# 生成今日信号

策略部署上线后，可以在“今日信号”中使用最近一个已完成交易日的收盘数据生成下一交易日指令。

## 打开已上线策略

1. 点击顶部的“今日信号”。
2. 在左侧选择策略。
3. 核对右侧策略名称、部署日期、代码版本和“运行中”状态。
4. 确认页面提示“使用已冻结的部署版本”。

尚未生成过信号时，页面如下：

1. 已上线策略列表。
2. 当前策略、部署日期和代码版本。
3. “立即生成”按钮。
4. 尚未生成状态。

![尚未生成信号的已上线策略](/docs/images/help/zh/signals/signal-empty-01.png)

左侧“尚未生成”不表示部署失败，只表示这个部署还没有信号运行记录。

## 立即生成

1. 确认最近交易日已经收盘。
2. 点击“立即生成”。
3. 等待按钮完成加载。
4. 查看运行日志。
5. 等待页面出现信号日期、执行日期和结果。

生成使用冻结的部署版本，不读取回测工作台中尚未运行的编辑器草稿。

正常日志会依次显示：

- 生成所用的收盘日期和执行日期；
- 回测起止日期和初始资金；
- 运行进度；
- 最终模型权益；
- 生成的指令数量。

## 信号日和执行日

- 信号日：策略读取收盘数据并作出决定的交易日。
- 执行日：信号日之后的下一个交易日。

例如使用 2026-07-28 收盘数据生成信号，执行日为 2026-07-29。不要在信号日收盘前把结果当作已经完成，也不要把执行日理解为保证成交日。

## 今日无操作

策略完成运行但没有产生买卖变化时，页面显示“今日无操作”：

1. 真实运行日志。
2. 信号日、执行日、模型权益和通知状态。
3. “今日无操作”。
4. 参考价说明。
5. 运行历史中的 0 条指令。

![成功运行但今日无操作](/docs/images/help/zh/signals/signal-no-action-01.png)

“今日无操作”是完整运行的结果，不是空白页面或错误。它表示按冻结策略和当日数据计算后，不需要改变目标持仓。

## 市场数据尚未准备完成

如果页面提示某个日期的市场数据尚未准备完成：

1. 确认是否已经收盘。
2. 等待行情处理完成。
3. 点击右上角“刷新”。
4. 再点击“立即生成”。

不要连续重复提交。刷新只重新读取状态，不能提前生成尚未完成的市场数据。

## 自动运行和手动运行

上线策略可以由每日链路在收盘后运行。“立即生成”用于当日尚未生成、需要重试或验收时手动触发。同一个部署和信号日已经成功完成后，再次触发会读取已有结果，不应被理解为一份新策略。

## 常见问题

### 点击后长时间显示生成中

先看日志，再点击“刷新”。服务重启造成中断时，页面会显示“已中断”，可以重新生成。

### 页面显示失败

阅读红色错误提示和日志。常见原因包括市场数据未准备、部署已暂停或策略运行错误。

### 为什么没有邮件

查看“邮件通知”。开发环境会明确显示未发送；生产环境发送失败时会显示失败状态，但页面结果仍应单独检查。
