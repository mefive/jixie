# 核对今日信号使用的 Factor

使用已发布 Factor 的策略生成今日信号后，页面会显示“本次决策的 Factor 输入”。这里记录信号日当天策略实际读取的值，用于解释订单来源。

## 打开 Factor 输入

1. 在回测工作台完成含 Factor 的策略回测。
2. 部署当前回测版本。
3. 打开“今日信号”，点击“立即生成”。
4. 等待运行完成，在指令上方找到“本次决策的 Factor 输入”。

下图中的标记分别是：

1. 已发布 Factor key。
2. 有效值与观察资产数。
3. 当日有效值均值。
4. 策略决策标的实际读取的值。

![今日信号实际读取的 Factor 输入](/docs/images/help/zh/signals/factor-inputs-01.png)

## 各列含义

- **Factor**：部署版本冻结的已发布 Factor key。
- **有效 / 观察**：信号日能算出有效值的资产数和策略观察的资产总数。
- **均值**：当日全部有效值的简单平均，用于快速检查整体方向，不是仓位。
- **决策标的值**：策略真正用于排序或判断的各资产值。

一个策略可以观察 9 个资产，但只交易其中 2 个。覆盖数说明数据是否齐全，决策标的值说明策略在这次计算中读到了什么；两者都不表示系统已经下单。

## 与研究报告和订单的区别

- Factor 报告验证历史研究关系。
- Factor 输入是某个信号日的实际预测值快照。
- 策略再把输入转换为目标权重。
- 买卖指令是目标持仓与模型当前持仓的差额。

因此 Factor 值为正不一定产生买入，数值最大也不一定持有 100%。阈值、排序、持仓数、现金和交易约束都由冻结策略决定。

## 异常检查

### 覆盖不足

先查看信号日志和 Factor 的适用资产。新上市、历史窗口不足、数据截止或某项输入缺失都可能让部分值为空。系统不会用 0 替代缺失值。

### 页面没有这个区域

普通策略或没有实际读取已发布 Factor 的策略不会显示该区域。旧部署也可能没有新的血缘快照；需要用当前版本重新回测并部署。

### 值与研究报告不同

研究报告展示历史汇总指标，不是某一天的原始分数。还要核对信号日、资产、预测周期和部署冻结的 Factor ID／代码 hash 是否一致。
