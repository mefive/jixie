# 按条件筛选并查看结果

条件筛选用于从股票范围中找出同时满足若干条件的股票。页面会把输入内容转换为可检查、可修改的条件，并显示当前数据下的结果。

## 输入筛选条件

1. 点击顶部的“选股看图”。
2. 点击“新对话”。
3. 在中间输入框中写出条件。例如：

   `筛选市盈率TTM低于15、股息率大于3%的股票，按总市值从高到低排列`

4. 按回车键发送。
5. 等待条件和结果表出现。处理完成前不要重复发送相同内容。

## 核对页面解释的条件

![筛选条件、快照说明和结果表](/docs/images/help/zh/screening/filter-results-01.png)

下图中的 **1** 是页面实际执行的条件。逐项检查：

- 字段：例如“市盈率TTM”“股息率”“总市值”。
- 比较符号：`<`、`≤`、`>` 或 `≥`。
- 数值和单位：例如股息率的 `%`、总市值的“亿”。
- 排序字段和方向：例如“总市值，从高到低”。

页面显示的条件才是本次筛选真正使用的规则。如果它与原输入不一致，应先修改条件，再判断结果。

## 查看快照日期和数量

下图中的 **2** 会显示：

- 快照日期：本次筛选使用的交易日。
- 命中数量：符合条件的股票总数。
- 展示数量：当前表格实际列出的数量。

命中数量可能大于展示数量。表格只展示前若干条，不表示其余股票不符合条件。

## 阅读结果表

下图中的 **3** 是结果表。常见列包括：

| 列 | 含义 |
| --- | --- |
| 名称 | 股票名称和证券代码 |
| 现价 | 快照日期的价格 |
| 涨跌 | 当日涨跌幅；红色为上涨，绿色为下跌 |
| PE(TTM) | 最近十二个月口径的市盈率 |
| PB | 市净率 |
| 股息率 | 当前数据口径下的股息率 |
| 总市值 | 公司总市值 |
| 换手率 | 当日成交活跃程度 |

点击任意一行会在新标签页打开股票详情，原筛选结果仍保留在当前页面。

## 如何判断结果是否正确

1. 先检查快照日期。
2. 再检查每个条件的符号、数值和单位。
3. 抽查表格中一至两只股票，确认对应列确实满足条件。
4. 检查排序字段和第一、第二行的顺序。

筛选结果只表示股票在该快照日期满足规则，不表示它们之后一定上涨。

## 没有结果

依次尝试：

1. 检查是否把“大于”和“小于”写反。
2. 检查条件是否过多或互相冲突。
3. 适当放宽其中一个数值。
4. 删除一个条件后等待页面重新查询。
