# 修改条件和排序

筛选结果出现后，可以直接修改页面顶部的条件，不需要重新输入整句话。每次修改都会使用新条件重新查询。

## 修改现有条件

![条件卡片、加条件按钮和排序控件](/docs/images/help/zh/screening/edit-sort-01.png)

下图中的 **1** 是一条条件。它从左到右包含：

1. 字段，例如“市盈率TTM”。
2. 比较符号，例如 `<`。
3. 数值，例如 `15`。
4. 单位，例如 `%` 或“元”；没有单位时不会显示。
5. 移除按钮 `×`。

### 修改比较符号

1. 点击当前符号。
2. 选择 `>`、`≥`、`<` 或 `≤`。
3. 等待结果表更新。

### 修改数值

1. 点击数值。
2. 输入新值。
3. 按回车键，或点击输入框以外的位置。
4. 等待快照说明和结果表更新。

输入数值时不要重复写单位。例如，股息率输入 `3`，页面右侧已经显示 `%`。

### 删除条件

点击条件最右侧的 `×`。删除后页面会立即使用剩余条件重新查询。

## 增加条件

下图中的 **2** 是“加条件”：

1. 点击“加条件”。
2. 从菜单中选择字段。
3. 页面会加入一组默认的比较符号和数值。
4. 按需要修改符号和数值。
5. 等待结果更新，再检查命中数量。

同一字段已经存在时，不会再次出现在“加条件”菜单中。

## 调整排序

下图中的 **3** 是排序控件：

1. 点击当前排序字段，例如“总市值”。
2. 选择新的字段，或选择“不排序”。
3. 点击右侧方向按钮，在“从高到低”和“从低到高”之间切换。
4. 检查结果表前几行，确认顺序已经改变。

排序只改变结果顺序，不会改变哪些股票满足筛选条件。

## 修改后需要重新保存

如果这条筛选已经保存在左侧，修改条件不会自动覆盖原筛选。需要保留新规则时：

1. 在顶部输入一个便于识别的名称。
2. 点击“保存筛选”。
3. 在左侧“已保存筛选”中确认新记录。

## 常见问题

### 修改后表格短暂变灰

页面正在重新查询。等待加载完成后再继续修改，避免无法判断是哪一次修改产生了当前结果。

### 加条件后没有股票

新条件可能与原条件组合后过于严格。先删除新条件，确认结果恢复，再使用更宽松的数值。

### 排序方向看不出来

查看方向按钮的提示文字，并比较结果表前两行对应字段的数值。
