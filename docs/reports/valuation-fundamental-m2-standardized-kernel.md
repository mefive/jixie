# 估值驱动基本面研究：M2 标准化财务内核

> 状态：完成，待人工审阅
>
> 实现计划：[valuation-driven-fundamental-research.md](../design/valuation-driven-fundamental-research.md)

## 1. M2 交付物

M2 交付的是 API 服务内部使用的 TypeScript 财务计算内核，不是 Research SDK、HTTP API 或页面：

- `resolveFinancialState({ tsCode, asOfDate })` 从数据库选择指定历史日期可用的三张财报版本和市场快照；
- `calculateFinancialMetrics(state)` 生成标准化财务指标、公式、输入版本、诊断和确定性结果指纹；
- `normalizeIncomeFlows` / `normalizeCashFlows` 负责累计转单季和 TTM；
- 数据质量审计增加会计恒等式、跨表净利润、异常值和三表覆盖率检查。

M2 完成后，API 内部代码和测试可以直接调用这些接口。Research 用户还不能调用；M3 才会设计并生成公开
Research SDK Contract、Python Runtime 映射和数据目录。

## 2. 历史版本选择

resolver 只读取 `availableDate <= asOfDate` 的一般工商业合并报表，严格 PIT 默认排除 `reconstructed`：

1. 每张表、每个报告期独立选择，不虚构三表共同版本；
2. 先选最新可得日，同日优先调整后口径 `4`、正式口径 `1`、调整前口径 `5`；
3. 同等级且类型化数值完全一致的供应商副本确定性折叠；
4. 同等级但数值不同且没有顺序证据时不选择，并返回歧义诊断；
5. 更正可得日前继续使用旧版本，可得日后才切换到更正版本；
6. 申万一级行业为银行或非银金融时拒绝工业企业指标模板。

## 3. 标准化和公式

- Q1 使用一季度累计值；Q2/Q3/Q4 单季值分别减去前一个累计期；
- 年末 TTM 直接使用完整年报累计值；中期 TTM 要求连续四个合格季度；
- 收入同比使用当前 TTM 与上年同期 TTM，多年 CAGR 要求起止收入均为正；
- EBIT 代理为 `营业利润 + 利息费用`，NOPAT 为 `EBIT 代理 × (1 - 有效税率)`；
- 营运资本为经营流动资产减无息流动负债；
- 投入资本为 `归母权益 + 少数股东权益 + 有息负债 - 现金 - 交易性金融资产`；
- ROIC 使用 TTM NOPAT 和期初、期末平均投入资本；平均投入资本非正时返回无效；
- 净资本开支为现金资本开支减折旧摊销，再投资为净资本开支加营运资本增加；
- FCFF 为 NOPAT 减再投资；CFO 减资本开支另列为现金自由现金流，不冒充 FCFF；
- 企业价值为市值加有息负债及少数股东权益，再减现金和交易性金融资产。

供应商对不存在的明细科目通常返回空值。只有在父级合计存在时，债务、少数股东权益和交易性金融资产的空明细
才按零处理；父级合计或公式必需字段缺失时，指标保持缺失。

## 4. 输出与失败语义

每个指标包含：

- `value`、`unit` 和 `status`；
- 明文 `formula` 与 `formulaVersion=financial-metrics-v1`；
- 实际参与计算的来源行指纹；
- 缺季、缺字段、零分母、税率越界或负投入资本等失败原因。

整份结果包含 resolver 版本、估值日、会计勾稽诊断和 SHA-256 结果指纹。同一输入版本重复计算必须逐位一致；
增加或替换任一来源版本会改变结果指纹。

## 5. 审计

数据质量审计新增 `financial-statement-accounting`：

- 资产是否等于负债加归母权益和少数股东权益；
- 期初现金加现金净增加是否等于期末现金；
- 利润表净利润与现金流量表调节起点是否一致；
- 总资产、负债、股本和分项合计是否出现不可能关系；
- 严格 PIT 条件下三张表共同覆盖的股票报告期比例。

计算内核本身还会报告非标准报告期、缺少连续季度、异常税率、非正平均投入资本和极端比率。

## 6. 已知限制

- M2 不预测未来，也不决定多少现金属于经营必需现金；这类假设属于 M4 估值情景；
- 中国会计准则下营业利润并非纯粹经营 EBIT，因此输出明确称为 V1 EBIT 代理并保留公式；
- V1 有息负债只汇总短期借款、一年内到期非流动负债、长期借款和应付债券；尚未单列的租赁负债等项目不会
  被静默估算，后续增加科目时必须升级公式版本；
- 中期折旧摊销缺失时，净资本开支、再投资和 FCFF 可以缺失；系统不会用供应商后补字段伪造历史 PIT；
- M2 使用资产负债表总股本，不声称已经得到稀释股本；每股估值属于 M4；
- M2 没有派生指标数据表、公开 Research SDK、HTTP 接口、前端页面或 Factor 字段。

## 7. 验收

- 手算 fixture 覆盖版本切换、同值副本、累计转单季、TTM、平均分母、ROIC、再投资、FCFF 和企业价值；
- 缺季度、零分母、歧义版本和金融企业拒绝均有失败路径测试；
- 真实数据验收使用五粮液，2022 年归母净利润在 2024-04-29 仍读取 2023-05-04 可得的正式口径
  `26,690,661,397.42` 元；到 2024-04-30 才切换为当日可得的调整后口径 `26,689,983,647.20` 元；
- 在 2025-04-28 回看五粮液 2024 年报，收入为 `89,175,178,322.70` 元，EBIT 代理为
  `44,240,512,603.05` 元，有效税率为 `24.8393%`，NOPAT 为 `33,251,475,038.35` 元，ROIC 为
  `252.7463%`；净资本开支为 `1,955,918,634.40` 元，营运资本增加为 `-11,290,811,151.92` 元，
  再投资为 `-9,334,892,517.52` 元，FCFF 为 `42,586,367,555.87` 元；高 ROIC 来自现金净额很大的
  融资口径投入资本，不代表系统对经营必需现金作了主观调整；
- 同一估值日的最新 2025 一季报连接到 2025-04-28 市值 `507,908,407,454.00` 元，企业价值为
  `373,378,868,364.45` 元；因该期缺少折旧摊销累计值，FCFF 返回
  `missing_current_cumulative_value`，而不使用现金自由现金流替代；
- 平安银行按历史申万银行分类被工业企业内核拒绝；
- 隔离库审计核对 48 个可比会计恒等式，零不一致；11/11 个严格 PIT 报告期三表齐全，状态为 `pass`；
- 目标单元测试共 25 项通过；API 全量测试 906 项通过、1 项既有集成测试跳过；根目录类型检查和 API 构建通过；
- 本阶段没有用户界面变化，因此不需要浏览器 E2E 或截图。
