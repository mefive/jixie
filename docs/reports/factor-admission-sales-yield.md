> 状态：已准入（2026-08-12）。探索、去冗余和一次性正式 holdout 均通过；已加入预置菜单
> `sales_yield`。信号有效但经济幅度较温和，不标成强因子。

## 候选定位

- 候选研究键：`candidate_sales_yield`
- 候选菜单名：销售收益率（1/PS_TTM）
- 主题：价值；补充现有盈利收益率和账面市值比，不默认具有独立信息
- 定义：当 `PS_TTM > 0` 时取其倒数，否则返回 `null`
- 预期方向：正；收入相对市值越高，估值越便宜，未来收益应越高
- 文献先验：Barbee、Mukherji、Raines（1996）报告销售市值比对收益的解释力；A 股价值因子受规模、
  壳价值和市场阶段影响明显，因此必须本地中性化并做独立保留段

## 冻结代码

```ts
export default defineFactor({
  name: '销售收益率(1/PS_TTM)',
  compute: (bar) => (bar.psTtm && bar.psTtm > 0 ? 1 / bar.psTtm : null),
});
```

## 冻结研究规则

- 探索区间：2020-01-01 至 2025-01-27；月频
- 主报告：全 A 股正式 V3 口径，市值+行业中性化
- 主判据：`rank_ic_mean > 0.01`
- 冗余门：探索期分别与 `ep`、`bp` 的平均截面 Spearman 绝对值都必须 `< 0.90`；任一达到或超过
  0.90 即视为现有价值因子的换皮，不消耗正式 holdout
- 辅助证据：IC 正值比例应高于 50%，高因子值减低因子值的费后多空年化应为正
- 正式保留段：仅当探索主判据和冗余门同时通过时启动；沿用相同代码、参数、方向和主判据，只揭示一次
