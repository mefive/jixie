## 结论（针对这份合成数据）
1. **全样本统计确实掩盖了阶段变化，而且掩盖得很彻底。** A/B 全样本 Pearson 只有 −0.150、beta −0.103，看着像“几乎不相关”；但切成 2023 年前后，相关系数从 +0.945 直接翻到 −0.955，beta 从 +0.81 变为 −0.55。符号相反的两段被平均成一个“接近零”，这是典型的聚合假象。
2. **B 在这份数据里不是稳定的分散器，而是“换号”的对冲。** “稳定分散”要求相关性低且符号一致；这里的相关性是低且方向翻转，属于状态依赖（regime-dependent），不能在样本外假定它继续有效。滚动相关曲线从约 +0.95 一路降到约 −0.95，说明切换是渐进过程而非单月跳变。
3. **C 与 A 的关系完全不同：它是“前段无序、后段同向增强”。** A/C 全样本 +0.453，主要由 2023 年起贡献（+0.703，beta +0.116）；2023 年前几乎是 0（−0.095，beta −0.015）。也就是说 C 与 A 的正相关是后期才出现的，全样本值既不是前段的写照也不等于后段的真实水平。同时 C 的波动率极低（2.16% 年化，q25–q75 只有 −0.08%…0.63%），Spearman 明显低于 Pearson（0.090 vs 0.453；0.281 vs 0.703），说明 Pearson 被少数极端月放大，C 的“同向”更多是量级上的少数点驱动，而非普遍单调同步。
4. 若这条关系要在策略里用，A/B 的 −0.95 段适合做对冲腿，但必须带状态识别（否则在 +0.95 段会变成同向双倍暴露）——本 Cell 只做了描述，没有做状态检验，也没有给出任何交易信号或收益结论。
