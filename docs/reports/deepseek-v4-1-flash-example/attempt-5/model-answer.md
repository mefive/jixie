## 样本与对齐处理
- 数据：`data.series(asset_type="index", identifier=各代号, start=20181231, end=20251231, measure="market.adjusted_close", frequency="monthly", transform="level")`，即**隔离库里的月末价格 level（CNY）**，与真实行情无关；三个请求分别返回 85 / 82 / 81 行。
- 网格：2018-12–2025-12 共 **85 个自然月**；缺失月**保留为 NaN**，不前向填充、不补零。
- 月收益：只用**相邻网格月**相减（`diff` 后把上一个月缺失的收益置 NaN），所以跨缺口的变化不会被当成单月收益。2018-12 为预热基期，分析区间 2019-01–2025-12。

## 结论（基于上面已执行的数字）
- **B 不能"稳定"分散 A 的风险：全样本统计确实掩盖了阶段变化。** 全样本 Pearson 仅 −0.28、beta −0.31，看起来像对冲；但拆开后是**符号翻转**：2023 年前 Pearson 0.946、beta 1.274（几乎同向放大 A 的波动），2023 年起 Pearson −0.959、beta −0.943（高度反向）。全样本的"弱负相关"是两个相反机制的相互抵消，来自**混样**而非稳定属性；且 B 自身波动率最高（18.05%），反向时是显著的风险来源而不是稳定缓冲。
- **C 与 A 的关系性质不同：更像"弱关联 + 低波动"，而不是可靠的对冲。** 全样本 Pearson 0.50 却只有 Spearman 0.098、beta 0.155——线性尾部相关与秩相关严重不一致，说明不是单调的同涨同跌关系；自身年化波动仅 5.07%、分位数区间最窄（q25/q75 = −0.18/1.47）。它同样在 2023 年前后换号（−0.08 → 0.72），但幅度小得多、秩相关只有 0.29，对 A 的解释力很弱，更多是"低波动、弱相关"的另一条序列。
