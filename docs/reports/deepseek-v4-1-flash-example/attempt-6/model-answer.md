## 3. 结论（基于本次真实执行结果）

1. **B 不能算"稳定分散"**：全样本 Pearson -0.150，看起来像接近无关/弱负相关，但这正是两阶段互相抵消的结果——2023 年前 +0.945（beta 0.81），2023 年起 -0.955（beta -0.55）；滚动相关从约 +0.95 摆到约 -0.95，均值仅 0.06。所以"全样本统计掩盖了阶段变化"在这个合成样本里成立，而且关系是**符号翻转**，不是稳定低相关：事前无法知道当前处于哪一体制，按下注方向使用会得到相反效果。
2. **C 与 A 的关系质地上不同**：全样本 Pearson +0.453，但 Spearman 仅 0.090，说明线性相关主要来自少数极端月（尺度/尾部效应），月度秩上并没有稳定同向；全样本 beta 仅 0.076，远小于 B 的第一阶段 0.81。分阶段看 C 与 A 在 2023 年前基本无关（-0.095），2023 年起才转正（+0.703，但 Spearman 仅 0.281），滚动区间 -0.78~+0.83。可以说 C 更像"低波动、弱且随时间漂移的相关"，而不是真正的负相关缓冲。
3. **样本限制必须显式保留**：B/C 分别有 3/4 个缺失月，不做填充；分段样本只有 33~44 个观测，滚动窗口仅 33~37 个，A-C 滚动序列在后段直接断开——这些都降低了相关系数与 alpha/beta 的稳定性，n 小的分阶段数字不宜当作稳定参数。
4. 这三条序列是隔离库中给定的**合成演示数据**，本次分析不引用、也不推断它们在现实市场中的表现；指数价格为价格指数（不含分红、不可交易），滚动相关也不构成任何已验证的投资结论。
