## 要解决的用户问题

在 Strategy 对话中，用户想先检查三条候选资产序列的关系：B 是否能稳定分散 A 的风险，全样本低相关是否掩盖阶段变化，C 又是否不同？Agent 应查询数据、执行一个可追溯的嵌入式 Python 分析，给出样本诊断、统计表、价格曲线和滚动相关性，并保持策略代码不变。

为能独立核对，本例使用隔离库中的合成月末价格：2018-12 至 2025-12，包含缺失月、相关方向变化及极端月。代码 000300.SH、000852.SH、000905.SH 在此仅作 A/B/C 的代号，**不是真实指数表现**。这是有明确方法和精度约束的模型/运行时验收，不是浏览器用户行为 E2E，也不是新旧模型对照实验。

## 可以相信到什么程度

第四次成功运行的 [模型代码](attempt-4/model-cell.py) 使用完整自然月网格和相邻月份价格比值计算收益，样本标准差 ddof=1、线性分位数、成对完整样本、含截距 OLS，以及要求 12 个完整自然月观测的滚动相关。对留存 stdout 的独立核对，51 个数值全部一致；[运行记录](attempt-4/runs.json) 包含失败后成功的过程、3 份 SDK 输入元数据和两个 image 输出记录。该轮图像文件在错误断言触发后随临时库清理，未导出，不能声称已完成图形目视验收。

正确数值包括：A/B 全样本 Pearson 约 -0.150，2023 年前约 +0.945，2023 年起约 -0.955。合并样本确实掩盖了分段关系；A/C 的全样本 Pearson 约 +0.453，而 Spearman 约 +0.090，需要进一步检查极端观测影响。

但 [模型原始解释](attempt-4/model-answer.md) 必须附带以下纠正，不能原样作为研究结论发布：

- 滚动曲线逐渐变化，不能证明底层关系是渐变；窗口平均可以把突然的变化画成渐变。本合成数据的 B 系数本来就是在切点直接切换。
- 稳定分散不要求相关系数永远同号，应研究组合风险、估计不确定性和不同状态，而不是只看符号。
- 样本内高度负相关不能直接得出“适合用作对冲腿”，还缺成本、可交易性、样本外和组合层面的验证。
- 模型称额外生成了原生交互图，但持久化输出只有 text 和 image；中间表达式的 charts.* 调用没有成为 Cell 的最终输出，不能把调用代码当作已展示事实。

第五次的 [源代码](attempt-5/model-cell.py) 使用 `aligned.diff()`，计算的是价格单位的差值，不是 `price_t / price_(t-1) - 1`。它的图和回答作为失败证据留存，**不可使用其中的波动率、回归或相关性作为本题答案**。
