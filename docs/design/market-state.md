# 市场状态与方向热力

## 定位

市场状态页是日频描述仪器，不是预测模型。它把四个容易混淆的问题分开回答：

1. 估值温度：贵不贵；
2. 交易热度：成交是否活跃；
3. 趋势与广度：行情是否强、参与是否普遍；
4. 交易拥挤：成交是否集中在少数股票或方向。

“景气度”保留给季度基本面指标，不用于价格和成交数据。页面不提供单一市场温度分，避免把
“热而窄”和“热且广”压成同一个数字。

## 预计算表

### `MarketIndicator`

每个交易日一行：

- `return20`：当日实际交易股票的复权价等权 20 日收益；
- `advanceRatio`：当日上涨股票占比；
- `aboveMa20Ratio` / `aboveMa60Ratio`：具备足够历史的股票中，复权收盘站上均线的占比；
- `floatWeightedTurnoverRate`：以流通市值加权的换手率；
- `topFivePercentAmountShare`：成交额最高的前 5% 股票占全市场成交额比例；
- `extremeMoveRatio`：绝对涨跌幅不低于 5% 的股票占比；
- `limitUpCount` / `limitDownCount`：收盘位于涨跌停价的股票数量。

### `IndexIndicator`

每个指数观察范围、每个交易日一行。目前覆盖上证50、沪深300、中证500、中证1000、
中证2000、中证A500、创业板指、科创50和中证红利。

- 成分范围使用不晚于观察日的最新 `IndexWeight` 月度快照，并保持到下一期快照生效；
- `membershipDate` 保存当日实际采用的成分快照日期，便于审计；
- `return20` 使用 `IndexDaily` 官方指数收盘点位的 20 日收益；
- 广度、活动、拥挤、成交额、涨跌停等其余字段与 `MarketIndicator` 同义，但仅在当时的指数成分内聚合；
- 中证2000从其首个可用历史成分快照开始，不以今天的成分补造发布前历史。

### `IndustryIndicator`

每个申万一级行业、每个交易日一行。股票按当日有效的成员区间归属；若上游存在重叠区间，
取 `inDate` 最新的一条，避免重复计算。

- `return20` / `excessReturn20`：行业成分股等权 20 日收益及相对全市场等权收益；
- `positiveReturn20Ratio`：20 日收益为正的成分股占比；
- `aboveMa20Ratio` / `aboveMa60Ratio`：行业内部均线广度；
- `floatWeightedTurnoverRate`：行业流通市值加权换手率；
- `amountShare`：行业成交额占全市场比例；
- `topFiveAmountShare`：行业内成交额前五只股票的成交占比。

价格窗口一律使用 `close × adjFactor`。股票是否进入当日市场样本由当日 `Daily` 决定，不用今天的
上市状态回填历史；行业归属使用 `SwIndustryMember` 的时点区间。

## 读取层指标

页面的四个市场指标可在全A与九个指数观察范围间切换：

- 交易热度：`floatWeightedTurnoverRate` 的 20 日均值；
- 市场广度：`aboveMa20Ratio` 与 `aboveMa60Ratio` 等权；
- 趋势强度：全A使用股票复权价等权 20 日收益，指数范围使用官方指数 20 日收益；
- 交易拥挤：`topFivePercentAmountShare`。

每项独立计算当前值在该观察范围自身近三年可用交易日中的百分位，不横向比较不同指数的原始
换手率。估值页继续使用十年及全历史百分位，两种窗口不混用。

方向热度为三个可见分项的等权平均：

```text
方向热度 = 1/3 × 趋势分 + 1/3 × 广度分 + 1/3 × 活跃分
```

- 趋势分：当日 31 个行业 `excessReturn20` 的横向百分位；
- 广度分：行业三项广度均值在 31 个行业中的横向百分位；
- 活跃分：当前行业换手率在该行业自身近三年历史中的百分位。

权重不根据未来收益调优。方向热度只用于描述当前相对状态，不声称具有择时预测力。

## 运行与接口

全量或区间回填：

```bash
pnpm --filter api sync:market-state 20150101 20260727
```

脚本按自然年切片，并自动向前加载 60 个交易日作为窗口垫片。每日同步完成后只需传新增日期，
不需要重算全历史。

读取接口：

```text
GET /api/app/market/state?scope=all
GET /api/app/market/state?scope=000300.SH
```

`scope` 支持 `all` 以及九个指数代码。观察范围使用文字触发器打开分组弹层；弹层按规模宽基、
特色板块、策略风格分组，并展示每个范围最新的20日趋势和市场广度。底色只跟随趋势正负做轻量
视觉提示，不额外合成“市场热度分”，也不混入覆盖不完整的指数估值。

接口只读取 `MarketIndicator` / `IndexIndicator` / `IndustryIndicator` 预计算表，再在小数据集上
计算近三年百分位和行业分项排名。页面请求不扫描原始 `Daily` / `DailyBasic` / `AdjFactor` 大表。

指数原始行情与历史成分可统一同步：

```bash
pnpm --filter api sync:index market-state 20150101 20260727
```

同步预置包含所有市场状态指数。科创50从 2020-07-31、中证A500从 2024-09-30的首个可信历史
成分快照自然开始，不回填发布前状态。

## 明确边界

- 不使用资金流作为核心热度分项：资金流属于模型化弱证据，且发布可能晚于行情；
- 不把估值、热度、广度、拥挤合成一个市场总分；
- 不输出“高温应卖、低温应买”等预测；
- 不称为行业景气度；基本面景气需另行设计季度 PIT 指标。
