# 《穿透估值》在 jixie 中的使用方法

参考：邹佩轩《穿透估值：读懂估值中的共识与博弈》，用户提供的[EPUB](./穿透估值：读懂估值中的共识与博弈%20-%20full.epub)。本文针对与本项目相关章节提炼，不声称完成全书逐段审校，也不将书中的案例价格或历史共识作为今天的事实。

## 1. 先写能被推翻的假设

第1.1节和第3.2节适合指导 Research：估值的作用是组织关于公司未来的判断，不能用更多小数位掩盖假设。每条判断写出数据起点、来源、增长期限、利润率、再投资要求、资本成本和下一次观察条件。

本项目把历史事实、用户假设、价格反解分列。下一年收入或利润率超出原范围时，保留旧执行记录并写新判断；不覆盖原参数，把事后答案伪装成当时预测。没有经过校准的概率，不能因为引用贝叶斯思想就写成数值胜率。

## 2. 增长多少和增长多久分别检验

第1.2节提醒：价值不仅由增长率决定，也由增长持续期、增量资本回报和买入价格决定。增长必须伴随投入，且新增投入回报超过资金成本才创造价值。

模板增加3/5/10年期限对照，固定历史利润率以避免同时改变利润率爬坡速度。另比较零增长、终值ROIC等于WACC、持续超额回报，并显示终值再投资和终值占比。不能只降低永续增长率就声称完整压力测试。

原五年预测过一年剩四年，和重新给五年成长空间是不同判断。模板分别显示冻结原路径的剩余企业价值、观察到新经营起点后的四年估值和再延长一年后的五年估值。滚动恒等式里的WACC是企业现金流模型关系，不是股东一年实际回报。

## 3. 现金流先对账，经营与资金项目成对处理

第2.2、2.3节用于提醒利润与现金流的时间和口径差异。不能因为净利润平滑，就认为经营现金流的波动等于风险；也不能把经营现金流减全部投资现金流机械称为FCFF。

本项目逐项显示净利润、NOPAT、CFO、现金资本开支、折旧摊销、净资本开支、营运资本变化和FCFF。未解释的残差继续保留，不自动归为维护性或扩张性投入。

本轮美的案例表明：理财产品进入流动资产后，会污染宽口径经营营运资本代理。修正需要同时检查：

1. 流动、长期和一年内到期部分是否重叠；
2. 对经营营运资本与投入资本的影响；
3. 对应利息、投资收益和公允价值变动是否仍在预测利润中；
4. 现金和交易性金融资产是否已经在股权桥接加回；
5. 受限资金、租赁和其他索偿是否完整。

因此附注调整留在可编辑Research，原始数据与公共内核保持原样。不能将美的一项处理直接推广到全市场。集团有效税率分配、必要经营现金、合并金融子业务和租赁投入仍属研究假设或缺口。

## 4. 市场价格是另一项观察，不是裁判答案

第1.2节的价格与价值关系、第3.2节的动态检验，可用于比较原假设、后续经营事实和市场回报。价格上涨不独自证明估值正确，价格下跌也不能自动归因于市场犯错。

本轮三公司对照显示：三者初始基准模型都高于价格，但随后12个月只有宁德时代跑赢所选ETF。这只能说明“模型折价”不足以独立形成选股规则。三家公司和重叠窗口都是事后案例，不是三个独立样本外实验，更不是九个独立样本。

如果以后提出可交易策略，应另行冻结公司范围、估值规则、观察日、退出条件、成本、基准和一次性holdout，再检验费后收益与稳健性。当前仍是探索层，不授予FactorReport准入资格。

## 5. 不同估值方法和行业驱动的适用条件

第2.8节适合用于解释PE、PB、PS与DCF的条件联系，不支持为了得到“便宜”结论而挑选倍数。第4.2、4.3、4.4节的光伏、煤炭、水电案例提醒我们研究产销量、价格、成本、资本开支与资产寿命等实际驱动。

这些章节不会补齐本项目缺少的历史一致预期、销量价格、分部成本或公告版本。现有主营业务构成不能直接自动加总，书中Wind历史共识也不是本地可复现数据。行业模板和M6仍按原设计推进，不因读书而默认完成。
