# jixie 量化学习地图

> 2026-08-12 制定。本文记录“要系统学习什么，以及怎样用 jixie 亲手验证”，不是功能排期，也不要求把
> 每个知识点产品化。执行优先级仍由 `ROADMAP.md` 管理，研究纪律与系统边界见 `docs/philosophy.md` 和
> `CLAUDE.md`。

## 1. 学习目标

jixie 当前阶段用于建立四种能力：

1. 看懂量化理论、论文、策略说明和风险指标；
2. 判断数据是否足以支撑一个结论，识别未来数据、幸存者偏差和口径偷换；
3. 用代码复现结论，并用恰当的统计检验、样本外和真实成本反驳自己；
4. 把跨市场、跨资产证据组合成可解释的策略与风险认识，为未来实盘做准备。

覆盖范围是中国内地、香港、美国的股票、债券与商品。当前不以尽快连接实盘为验收条件；长期目标是在真实
成本和可执行约束下，找到费后正期望、Sharpe / Calmar 良好且回撤能够承受的策略组合。

## 2. 学习不等于产品化

每个主题按成本递增的五级载体推进：

```text
帮助与笔记
  → Agent 对话查询 / 临时计算
  → 可重跑脚本或研究报告
  → 冻结定义 + 样本外验证
  → 反复使用后进入正式产品
```

- **帮助与笔记**回答概念是什么、为什么重要、在系统哪里出现，并同时服务中文和英文使用者；
- **对话式探索**使用 Agent、只读 SQL、`analyzeData` 和计算图卡片快速检查数据与想法；
- **可重跑研究**固定数据范围、代码、参数、币种、基准和输出；
- **正式验证**加入 PIT、holdout、稳健统计、真实成本、报告冻结与失败留痕；
- **产品化**只留给反复使用、需要稳定契约或关系到研究可信度的工作流。

这条路径允许学习范围持续扩展，同时避免正式页面、数据库表和共享类型随每次探索无限增长。

## 3. 响应式研究文档路径

当前 Research 已是 jixie 原生的响应式量化研究文档：

- Markdown Cell 保存问题、事前假设、公式、变量定义、限制和结论；
- Python Cell 使用固定运行环境、平台数据、pandas、NumPy、SciPy、statsmodels 和图表；
- 变量定义与引用形成依赖 DAG，上游变化使下游输出显式 stale；
- Agent 多轮对话可以查询精确 SDK、提出可审核的 Cell 变更并解释真实输出；
- 干净环境完整运行生成不可变 `ResearchExecution`，显式封存后可交接给 Factor 或 Strategy 继续验证。

研究文档需要完整保存以下信息：

1. 原始问题与假设；
2. 引用的理论或文献；
3. 数据查询、数据截止日和市场口径；
4. 计算代码、参数、随机种子和依赖版本；
5. 表格、图形与统计结果；
6. 限制、失败尝试和反证；
7. 结论与下一步。

当前文档已经满足这条原生研究路径。Jupyter 仍不进入产品表面；只有真实研究反复需要平台不支持的本地文件混合、
交互式调试或生态兼容时，才重新评估外部工具衔接，而不是建设一套与 Research 平行的 Notebook 产品。

## 4. 知识版图

### 4.1 数学、统计与计算基础

- 概率分布、期望、方差、协方差和条件概率；
- 抽样、估计、假设检验、置信区间、统计功效与多重检验；
- 线性回归、稳健标准误、截面回归、面板数据和正则化；
- 时间序列平稳性、自相关、异方差、结构突变和状态切换；
- bootstrap、置换检验、蒙特卡洛和数值优化；
- 矩阵、协方差估计、特征分解与组合优化中的病态问题。

系统练习应优先使用可控 fixture 证明方法行为，再进入真实市场数据，避免把数据问题误判成统计规律。

### 4.2 数据工程与研究偏差

- 证券主数据、跨交易所身份、上市/退市和代码变更；
- 交易日历、市场时区、夏令时、跨市场日期对齐；
- 本币收益、统一基准币收益、FX 转换与汇率暴露；
- 分红、拆并股、配股、复权和债券现金流；
- 财务公告日、宏观 vintage、数据修订和 `availableDate`；
- 幸存者偏差、未来数据、选择偏差、数据窥探和样本污染；
- 缺失值、异常值、数据供应商差异、数据版本与质量审计。

目标不是收集最多数据，而是知道每个字段的单位、频率、可得时间、适用资产和失败方式。

### 4.3 市场与资产

#### 股票：中国内地、香港、美国

- 市场结构、交易时段、结算、交易单位、涨跌幅、停牌和卖空差异；
- 财务报表与估值口径差异、行业分类、公司行动和退市处理；
- 规模、价值、质量、动量、低波、流动性、投资和盈利等经典因子；
- 市场、行业、风格和个股风险，以及跨市场共同暴露；
- 税费、ADR / 双重上市、港股通等跨市场特殊问题按真实研究需求展开。

#### 债券

- 价格、收益率、到期收益率、即期与远期利率；
- 久期、凸性、DV01、Carry 和 Roll-down；
- 收益率曲线水平、斜率、曲率与期限溢价；
- 国债、信用债、信用利差、违约和流动性风险；
- 债券指数、ETF、期货和现金债之间的可交易性差异。

#### 商品

- 现货、期货、保证金、逐日盯市和合约乘数；
- 期限结构、基差、Carry、展期收益和连续合约构造；
- 库存、仓单、产能、季节性和持仓数据；
- 趋势、跨品种相对价值、通胀敏感度和危机表现；
- 数据单位、合约换月和不可交易历史拼接造成的偏差。

### 4.4 Alpha 与因子研究

- 横截面、单资产时间序列、跨资产 Panel 和宏观状态四类问题的区别；
- 因子经济逻辑、方向、预测期限、适用范围和失效条件；
- Rank IC、回归系数、分组收益、换手、衰减和覆盖率；
- 中性化、相关性、增量信息、因子合成和风险因子区分；
- 样本内、验证集、holdout、walk-forward 和多重检验；
- 因子拥挤、发表后衰减、容量和交易摩擦。

研究者的目标不是批量生产显著因子，而是知道一个结论为何可能成立、如何失败，以及加入现有组合后是否仍有
增量价值。

### 4.5 策略与回测

- 趋势、均值回归、横截面选股、事件、Carry、相对价值和资产配置；
- 信号、预测、目标权重、订单和成交之间的层次；
- 复权、现金流、成本、滑点、冲击、容量和市场制度；
- 参数稳定性、跨时期表现、基准选择和过拟合诊断；
- 回测引擎、策略运行时、数据加载和撮合规则的一致性；
- Python 与 TypeScript 可以表达不同研究工作流，但撮合和市场规则保持单一真相。

### 4.6 组合构造与风险

- 分散化、相关性、协方差估计和风险贡献；
- 等权、风险平价、波动率目标、均值方差和带约束优化；
- 因子暴露、市场风险、宏观敏感度和 Alpha / Risk 重合；
- 杠杆、保证金、流动性、集中度、尾部风险和压力情景；
- 静态配置、战术配置、再平衡频率和交易成本；
- 单策略有效不等于组合有效，组合评价必须解释收益与风险来源。

### 4.7 绩效评价与研究结论

- 收益、波动、Sharpe、Sortino、Calmar、最大回撤和恢复期；
- Alpha、Beta、信息比率、跟踪误差和基准敏感性；
- 偏度、峰度、尾部损失、胜率、盈亏比和路径依赖；
- 滚动指标、市场状态拆分、归因和压力测试；
- 统计显著不等于经济显著，样本外好看不等于可交易；
- Sharpe / Calmar 是多维证据的一部分，不能被当作单一优化目标。

### 4.8 执行与实盘（后续阶段）

- 模拟盘、实盘小仓、成交回填和 implementation shortfall；
- 订单类型、流动性、成交概率、条件单和算法执行；
- 模型账户、模拟账户与实际账户对齐；
- 策略监控、失效判断、版本冻结和决策日志；
- 券商接口、权限、合规与运行可靠性。

当前只需要让研究从一开始诚实考虑可执行性，不要求立即建设完整实盘基础设施。

## 5. 每项研究的最小记录

无论使用 Agent、脚本、因子工作台还是外部资料，一项准备长期保留的研究至少记录：

| 项目 | 必答问题 |
|---|---|
| 学习主题 | 这次要理解哪个概念或方法？ |
| 假设 | 为什么预期它与未来收益或风险有关？ |
| 来源 | 理论、论文、书籍或市场制度依据是什么？ |
| 数据 | 市场、资产、区间、频率、币种、单位和可得时间是什么？ |
| 方法 | 代码、参数、预测目标、基准和统计检验是什么？ |
| 偏差 | 前视、幸存者、多重检验、修订和成本如何处理？ |
| 结果 | 样本内、样本外、费前、费后和不同状态下分别怎样？ |
| 反证 | 什么结果会推翻原假设？当前最强的替代解释是什么？ |
| 结论 | 接受、否决、保留观察，还是需要新数据？ |
| 去向 | 停留为笔记、形成可重跑报告，还是值得产品化？ |

## 6. 阶段性学习顺序

顺序用于减少前置知识缺口，不代表必须线性完成：

1. **可信研究基础**：统计推断、PIT、偏差、成本和基准；
2. **单市场单资产**：先把股票因子和趋势策略完整复现；
3. **跨市场语义**：中港美身份、日历、时区、币种和公司行动；
4. **债券与商品语言**：曲线、久期、Carry、期限结构和连续合约；
5. **多资产组合**：相关性、配置、风险贡献、宏观状态和压力测试；
6. **稳健候选策略**：跨时期、跨市场、费后、容量与组合增量；
7. **模拟与实盘**：只有前六步形成少量可信候选后再启动长期验证。

学习地图允许不断补充，但每次扩展都应落到一个具体学习问题和可复现练习，而不是只增加名词或数据表。

## 7. 已发布产品学习路径

### 7.1 描述性研究：收益、汇率与相关性

2026-08-25 首条双语路径“可信跨市场研究：收益、汇率与相关性”进入公开帮助。它固定 2015–2025 年沪深 300、
恒生和标普 500 人民币价格指数月收益，用一个练习串联：

1. 看结果前写下问题、预期、反证条件和固定样本；
2. 区分价格指数、ETF、本币收益、人民币收益和统一信息时钟；
3. 用稳定对象 ID 与 `availableDate` 对齐生成共同月度样本；
4. 同时检查全样本相关、36 个月滚动相关和 12 个月区块 bootstrap 区间；
5. 在结论中保留统计不确定性、价格指数限制和可交易代理缺口；
6. 干净运行全文并封存不可变研究版本。

这条路径只覆盖“可信研究基础”的第一项练习，不代表股票、债券、商品、因子、回测、组合和绩效主题已经完成。

### 7.2 策略研究：参数、成本与样本外

2026-08-25 第二条双语路径“沪深 300 趋势策略：参数、成本与样本外”进入公开帮助。它固定可交易代理
`510300.SH`、2015–2025 年样本、2020-12-31 切分和 120 日事前主参数，用一条 long/cash 均线规则串联：

1. 区分不可交易指数、ETF 复权信号、下一开盘成交和现金状态；
2. 先建立同一 ETF、资金、日期与成本下的买入持有基线；
3. 把 120 日设为主参数，20／60 日只作参数邻域敏感性，不事后挑冠军；
4. 同时读取样本内和首次样本外的收益、回撤、Sharpe、换手与成交；
5. 核对费用、滑点、真实成交，并对主参数做更高成本压力；
6. 用支持、证据不足或否决收尾，保留冻结的参数扫描报告但不自动部署。

这条路径进入“单市场单资产”的第一项策略练习。它只完成规则表达与初步稳健性审查，不证明趋势在未来、其他
ETF 或其他市场有效，也不替代 walk-forward、多次尝试校正、容量和真实执行验证。

### 7.3 因子研究：排序、IC、分层与样本外

2026-08-25 第三条双语路径“沪深 300 价值因子：排序、IC、分层与样本外”进入公开帮助。它使用盈利收益率
预设 `ep`、沪深 300 历史时点成分、月频全局排序和动态探索段，用一个股票横截面练习串联：

1. 说明 `ep` 只对正 `PE_TTM` 取倒数，亏损或缺失观测不进入本期排序；
2. 看结果前冻结正向假设、`Rank IC 均值 > 0.02` 主标准、范围、样本处理和成本；
3. 区分 Rank IC、D1 至 D10 分组和不可直接复制的 D10−D1 多空研究构造；
4. 同时读取 Newey–West 区间、ICIR、方向占比、等权／市值加权、覆盖、换手和费后结果；
5. 只增加一份事前声明的市值+行业中性化诊断，不事后扩展参数搜索；
6. 回到无中性化主报告，核对冻结协议并一次揭示约 18 个月的动态正式保留段；
7. 以支持下一轮、证据不足或否决收尾，不自动发布 Factor、生成股票名单或转成策略。

这条路径补齐“单市场单资产”阶段的股票因子练习。正式保留段随服务器最新数据移动；已经观察过同一代码与区间时，
练习要求记录没有可用首次样本外，而不是通过复制、改名或调阈值绕过封存。

### 7.4 债券信号：曲线、证据与运行治理

2026-08-25 第四条双语路径“国债曲线到每日信号”使用 `cgb_yield_decline_20`，把研究证据继续推进到运行治理：

1. 区分收益率水平变化、债券价格、久期、Carry 和 ETF 总收益；
2. 冻结“收益率下降对应更高未来收益”的正向假设与稳健 t 值门槛；
3. 保留探索段支持但正式 Holdout 方向反转的失败证据；
4. 使用同一 Factor key 和代码 hash 运行费后回测，不以工程成功覆盖证据失败；
5. 冻结部署版本并在指定历史日期核对曲线输入、指令、模拟成交和实际回填边界；
6. 最终暂停候选，不把能生成每日信号误写成可以投入运行。

这条路径覆盖“债券语言”和“信号治理”的首个纵向练习，但不等于已经掌握久期、凸性、Carry/Roll-down、信用和
可交易债券组合。

### 7.5 多资产组合：配置、择时、成本与风险归因

2026-08-25 第五条双语路径“股债配置与风险归因”使用不含黄金和商品的股债 Panel Factor，通过四组真实回测
把不同效应拆开：

1. 区分 Factor 资产域、冻结 Panel 研究池和策略实际交易池；
2. 在相同日期、资金和市场数据下运行股票、静态股债、动态零成本和动态真实成本；
3. 用静态对照识别资产配置作用，用零成本对照识别择时作用，再计算真实执行损耗；
4. 从资产和资产类别两层对账平均权重、收益贡献和风险贡献；
5. 结合滚动相关、利率状态、市场/宏观风险和线性压力情景解释组合；
6. 在回撤改善但择时、收益和成本证据不合格时给出否定结论。

这条路径进入“多资产组合”的第一项练习。静态权重和零成本组都是样本内诊断，不是独立样本外基准；组合构造、
协方差估计和滚动稳定性仍需后续研究。

### 7.6 商品研究：期限结构、代理误差与样本外

2026-08-26 第六条双语路径“商品 Carry”使用 AU 黄金、CU 铜、SC 原油和 M 豆粕真实月合约的年化对数期限结构，
把商品数据语义与正式证据纪律接在一起：

1. 用近远月结算价和交割日定义 Carry，区分 backwardation、contango、roll gap、连续收益和真实盈亏；
2. 明确黄金、豆粕代理与有色/能化类别 ETF 的不同基差，不把 ETF 回报冒充期货策略 P&L；
3. 把共同月末 Panel 排序和逐商品时间序列登记为两个 test key，并保留简单假阳性台账；
4. 对重叠 20 日目标使用至少 lag 19 的 Newey-West 推断，四只资产单项结果只作为诊断；
5. 在任一揭示前同时密封两份 2025-02 至 2026-07 Holdout；
6. Panel Rank IC -0.0471、时间序列 t 中位数 0.520 均未通过事前标准，正的 Panel 多空收益不能事后翻案；
7. 最终保留失败报告，不发布 Factor、不开放商品期货交易。

这条路径完成“债券与商品语言”的首个商品练习和一项正式经典复现，但不能推广到其他商品、交易所、库存/仓单
机制或可执行期货组合；后续问题必须重新冻结假设并使用真正未观察数据。
