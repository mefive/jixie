# jixie 量化学习地图

> 2026-08-12 制定。本文记录“要系统学习什么，以及怎样用 jixie 亲手验证”，不是功能排期，也不要求把
> 每个知识点产品化。执行优先级仍由 `ROADMAP.md` 管理，研究纪律与系统边界见 `docs/philosophy.md` 和
> `CLAUDE.md`。

## 1. 学习目标

jixie 当前阶段用于建立四种能力：

1. 看懂量化理论、论文、策略说明和风险指标；
2. 判断数据是否足以支撑一个结论，识别未来数据、幸存者偏差和口径偷换；
3. 用代码复现结论，并用恰当的统计检验、样本外和真实成本反驳自己；
4. 把跨市场、跨资产证据组合成可解释的策略与风险认识，为未来实盘做准备。

覆盖范围是中国内地、香港、美国的股票、债券与商品。当前不以尽快连接实盘为验收条件；长期目标是在真实
成本和可执行约束下，找到费后正期望、Sharpe / Calmar 良好且回撤能够承受的策略组合。

## 2. 学习不等于产品化

每个主题按成本递增的五级载体推进：

```text
帮助与笔记
  → Agent 对话查询 / 临时计算
  → 可重跑脚本或研究报告
  → 冻结定义 + 样本外验证
  → 反复使用后进入正式产品
```

- **帮助与笔记**回答概念是什么、为什么重要、在系统哪里出现，并同时服务中文和英文使用者；
- **对话式探索**使用 Agent、只读 SQL、`analyzeData` 和计算图卡片快速检查数据与想法；
- **可重跑研究**固定数据范围、代码、参数、币种、基准和输出；
- **正式验证**加入 PIT、holdout、稳健统计、真实成本、报告冻结与失败留痕；
- **产品化**只留给反复使用、需要稳定契约或关系到研究可信度的工作流。

这条路径允许学习范围持续扩展，同时避免正式页面、数据库表和共享类型随每次探索无限增长。

## 3. Notebook-like 研究路径

当前系统已经具备类似 Notebook 的关键构件：

- Agent 多轮对话保存问题、推理和结论；
- 只读 SQL 查询项目内市场数据；
- `analyzeData` 在沙盒内执行统计变换；
- 计算图卡片展示表格和图形，并支持按确定性 spec 重跑；
- 因子与策略工作台把探索升级为正式定义和报告。

因此短期不需要复制 Jupyter 的单元格界面。真正缺少、也更值得建设的是一份研究能否完整保存以下信息：

1. 原始问题与假设；
2. 引用的理论或文献；
3. 数据查询、数据截止日和市场口径；
4. 计算代码、参数、随机种子和依赖版本；
5. 表格、图形与统计结果；
6. 限制、失败尝试和反证；
7. 结论与下一步。

当对话分析能够冻结并重跑这些内容时，它已经满足 jixie 的 Notebook 目标。只有真实研究反复需要自由单元格、
本地文件混合或交互式调试时，再评估 Jupyter 集成或新的文档式工作区。

## 4. 知识版图

### 4.1 数学、统计与计算基础

- 概率分布、期望、方差、协方差和条件概率；
- 抽样、估计、假设检验、置信区间、统计功效与多重检验；
- 线性回归、稳健标准误、截面回归、面板数据和正则化；
- 时间序列平稳性、自相关、异方差、结构突变和状态切换；
- bootstrap、置换检验、蒙特卡洛和数值优化；
- 矩阵、协方差估计、特征分解与组合优化中的病态问题。

系统练习应优先使用可控 fixture 证明方法行为，再进入真实市场数据，避免把数据问题误判成统计规律。

### 4.2 数据工程与研究偏差

- 证券主数据、跨交易所身份、上市/退市和代码变更；
- 交易日历、市场时区、夏令时、跨市场日期对齐；
- 本币收益、统一基准币收益、FX 转换与汇率暴露；
- 分红、拆并股、配股、复权和债券现金流；
- 财务公告日、宏观 vintage、数据修订和 `availableDate`；
- 幸存者偏差、未来数据、选择偏差、数据窥探和样本污染；
- 缺失值、异常值、数据供应商差异、数据版本与质量审计。

目标不是收集最多数据，而是知道每个字段的单位、频率、可得时间、适用资产和失败方式。

### 4.3 市场与资产

#### 股票：中国内地、香港、美国

- 市场结构、交易时段、结算、交易单位、涨跌幅、停牌和卖空差异；
- 财务报表与估值口径差异、行业分类、公司行动和退市处理；
- 规模、价值、质量、动量、低波、流动性、投资和盈利等经典因子；
- 市场、行业、风格和个股风险，以及跨市场共同暴露；
- 税费、ADR / 双重上市、港股通等跨市场特殊问题按真实研究需求展开。

#### 债券

- 价格、收益率、到期收益率、即期与远期利率；
- 久期、凸性、DV01、Carry 和 Roll-down；
- 收益率曲线水平、斜率、曲率与期限溢价；
- 国债、信用债、信用利差、违约和流动性风险；
- 债券指数、ETF、期货和现金债之间的可交易性差异。

#### 商品

- 现货、期货、保证金、逐日盯市和合约乘数；
- 期限结构、基差、Carry、展期收益和连续合约构造；
- 库存、仓单、产能、季节性和持仓数据；
- 趋势、跨品种相对价值、通胀敏感度和危机表现；
- 数据单位、合约换月和不可交易历史拼接造成的偏差。

### 4.4 Alpha 与因子研究

- 横截面、单资产时间序列、跨资产 Panel 和宏观状态四类问题的区别；
- 因子经济逻辑、方向、预测期限、适用范围和失效条件；
- Rank IC、回归系数、分组收益、换手、衰减和覆盖率；
- 中性化、相关性、增量信息、因子合成和风险因子区分；
- 样本内、验证集、holdout、walk-forward 和多重检验；
- 因子拥挤、发表后衰减、容量和交易摩擦。

研究者的目标不是批量生产显著因子，而是知道一个结论为何可能成立、如何失败，以及加入现有组合后是否仍有
增量价值。

### 4.5 策略与回测

- 趋势、均值回归、横截面选股、事件、Carry、相对价值和资产配置；
- 信号、预测、目标权重、订单和成交之间的层次；
- 复权、现金流、成本、滑点、冲击、容量和市场制度；
- 参数稳定性、跨时期表现、基准选择和过拟合诊断；
- 回测引擎、策略运行时、数据加载和撮合规则的一致性；
- Python 与 TypeScript 可以表达不同研究工作流，但撮合和市场规则保持单一真相。

### 4.6 组合构造与风险

- 分散化、相关性、协方差估计和风险贡献；
- 等权、风险平价、波动率目标、均值方差和带约束优化；
- 因子暴露、市场风险、宏观敏感度和 Alpha / Risk 重合；
- 杠杆、保证金、流动性、集中度、尾部风险和压力情景；
- 静态配置、战术配置、再平衡频率和交易成本；
- 单策略有效不等于组合有效，组合评价必须解释收益与风险来源。

### 4.7 绩效评价与研究结论

- 收益、波动、Sharpe、Sortino、Calmar、最大回撤和恢复期；
- Alpha、Beta、信息比率、跟踪误差和基准敏感性；
- 偏度、峰度、尾部损失、胜率、盈亏比和路径依赖；
- 滚动指标、市场状态拆分、归因和压力测试；
- 统计显著不等于经济显著，样本外好看不等于可交易；
- Sharpe / Calmar 是多维证据的一部分，不能被当作单一优化目标。

### 4.8 执行与实盘（后续阶段）

- 模拟盘、实盘小仓、成交回填和 implementation shortfall；
- 订单类型、流动性、成交概率、条件单和算法执行；
- 模型账户、模拟账户与实际账户对齐；
- 策略监控、失效判断、版本冻结和决策日志；
- 券商接口、权限、合规与运行可靠性。

当前只需要让研究从一开始诚实考虑可执行性，不要求立即建设完整实盘基础设施。

## 5. 每项研究的最小记录

无论使用 Agent、脚本、因子工作台还是外部资料，一项准备长期保留的研究至少记录：

| 项目 | 必答问题 |
|---|---|
| 学习主题 | 这次要理解哪个概念或方法？ |
| 假设 | 为什么预期它与未来收益或风险有关？ |
| 来源 | 理论、论文、书籍或市场制度依据是什么？ |
| 数据 | 市场、资产、区间、频率、币种、单位和可得时间是什么？ |
| 方法 | 代码、参数、预测目标、基准和统计检验是什么？ |
| 偏差 | 前视、幸存者、多重检验、修订和成本如何处理？ |
| 结果 | 样本内、样本外、费前、费后和不同状态下分别怎样？ |
| 反证 | 什么结果会推翻原假设？当前最强的替代解释是什么？ |
| 结论 | 接受、否决、保留观察，还是需要新数据？ |
| 去向 | 停留为笔记、形成可重跑报告，还是值得产品化？ |

## 6. 阶段性学习顺序

顺序用于减少前置知识缺口，不代表必须线性完成：

1. **可信研究基础**：统计推断、PIT、偏差、成本和基准；
2. **单市场单资产**：先把股票因子和趋势策略完整复现；
3. **跨市场语义**：中港美身份、日历、时区、币种和公司行动；
4. **债券与商品语言**：曲线、久期、Carry、期限结构和连续合约；
5. **多资产组合**：相关性、配置、风险贡献、宏观状态和压力测试；
6. **稳健候选策略**：跨时期、跨市场、费后、容量与组合增量；
7. **模拟与实盘**：只有前六步形成少量可信候选后再启动长期验证。

学习地图允许不断补充，但每次扩展都应落到一个具体学习问题和可复现练习，而不是只增加名词或数据表。
